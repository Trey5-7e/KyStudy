## M2-A 资料研读（2026-09-09）

入口：AI 学习助手 → 资料研读。目标是让用户明确选择已索引 PDF 的物理页码，再启动只读文字研读。左侧为会话、资料、页码和问题；右侧显示运行状态、实际授权范围、工具步骤与带来源的回答。可选用量设置折叠在高级选项，不作为默认发送门槛。

实现使用现有语义色彩/形状 token；模式切换复用 Button。没有新增品牌或通用图标，不引入新的图标来源。React 实现并行加载独立目录数据，轮询仅针对活动 Run，离开组件清理监听和定时器，不取消后台任务；按 revision 丢弃迟到快照。公开答案仅在 Run completed 时展示，避免将未通过来源验证的模型输出当作最终答案。

### 浏览器闭环

- 确定性入口：`http://127.0.0.1:1420/src/preview/agent-study/index.html`，状态参数为 ready/loading/empty/running/completed/error/long。主界面相邻回归为 `http://127.0.0.1:1420/#ai-chat`。
- 已检查 1440×900、1280×800、1024×768、640×800、360×780；覆盖默认、加载、空目录、运行中、完成、错误及长文本，包含窄窗滚动至来源按钮。小屏自动变为单列，长文件名/回答可换行，取消按钮可达。
- 实际操作验证：未选页面时开始禁用；选择合成 PDF、填写 1–3 页及问题后可启动；高级选项可展开且默认只显示用量；浏览器点击开始明确返回“不执行真实研读或写入”。普通对话与研读入口可切换。
- 发现并修正：同步 effect 重置导致重复渲染；历史任务重新进入后表单为空造成范围歧义（增加本轮问题和实际授权页）；主浏览器预览目录缺少新只读命令（返回明确空索引/无旧任务，不假造写入）；现有编译目标不支持 findLast（使用单终态记录语义的 find）。修正后重新渲染对应状态。
- 截图与 AX 状态证据见本任务浏览器工具输出。预览不读取用户存储、不调用 Provider，不等同桌面数据验收。浏览器临时视口已恢复。
