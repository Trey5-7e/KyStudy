## 1. 产品定义

### 1.1 产品愿景

KyStudy 是一个面向中国考研学生的本地学习辅助工具。它不要求用户记录更多数据，也不尝试成为商业化任务管理、日历、知识库或思维导图产品。

它的价值是替用户完成重要但麻烦的步骤：

- 把长期目标和节奏自动展开为清晰的月份计划；
- 从多本习题册和大量错题中自动挑出今天应复习的内容；
- 直接展示题目区域，减少重新翻书和寻找页码；
- 从规划 PDF 或图片中整理出可确认的周期计划；
- 只展示能够帮助下一步行动的进度。

产品北极星是：**输入目标和节奏，系统自动安排；打开软件，只处理今天。**

### 1.2 目标用户

- 正在准备全国硕士研究生招生考试的个人用户；
- 同时管理多门科目、多本习题册和长期周期计划的学生；
- 希望资料与题目本地保存，并自行选择 AI Provider 的用户；
- 不愿花大量时间维护任务字段、表格、标签和统计的人。

### 1.3 核心结果

1. 用户能够在 30 秒内建立一个数量型周期计划并看到月历预览。
2. 用户打开“今日”后不需要筛选书籍、章节或题型，就能开始当日错题。
3. 一道已框选题目在自动分类正确时只需一次保存操作进入错题池。
4. 每道错题复习后只需要“掌握、模糊、不会”三种反馈。
5. AI 不成为额外工作流，只负责减少资料整理和输入步骤。
6. 带结构目录的习题册 PDF 能够自动建立科目、练习册、章节、篇章、题型和题号索引，用户只处理少量异常。
7. 用户完成一组纸面练习后，只输入完成范围、错题和不全对题号即可同步作答历史。

### 1.4 非目标

- 团队协作、商业化后台、账号和云同步；
- 通用 GTD、会议或按小时日历；
- 完整知识库和知识图谱；
- 完整思维导图制作软件；
- 复杂学习分析、打卡排行和时长报告；
- AI 未经确认自动创建、删除或调整计划；
- 在整改完成前准备公开发布。

## 2. 产品原则

### 2.1 少输入

一个字段只有在以下至少一种情况下才允许进入默认流程：

- 系统无法可靠推导；
- 它会直接改变当天应做的内容；
- 它是用户作出决定所必需的信息。

预计时长、优先级、变化原因、详细说明、掌握度和复杂标签不得作为默认必填项。

### 2.2 自动继承与一次设置

- 书籍从 PDF 自动继承；
- 科目从习题册默认值继承，综合资料允许单题覆盖；
- 学习日和休息日使用全局设置；
- 复习方案记住所选科目、书籍和题型配额；
- 月历记住用户选择显示的周期计划。

### 2.3 确定性规则优先

日期展开、休息日跳过、错题队列、进度百分比和冲突判断全部在本地完成。AI 只用于理解非结构化资料或按需解析题目。

### 2.4 AI 主动触发

每次 AI 调用必须由用户主动触发。调用前显示外发范围，调用后缓存可复用结果。AI 不得成为使用计划、习题册和错题系统的前提。

### 2.5 历史真实、未来可调

- 已完成事项不因重新规划而改写日期或状态；
- 未完成的未来事项可以整体顺延；
- 顺延和重新规划必须预览后确认；
- 第一阶段隐藏复杂旧功能，但保留已有数据与迁移兼容；旧版详细规划维护入口只在“设置 → 数据”中按需加载。

## 3. 信息架构

一级导航固定为：

1. 今日
2. 计划
3. 习题册
4. 错题
5. 资料

侧栏底部设置入口包含：

- 全局学习日、休息日和考试日期；
- AI Provider、API Key、模型和 Token 预算；
- 数据备份、恢复与运行诊断；
- 外观和基础偏好。

AI、学习分析、数据管理和思维导图不再拥有一级导航。

## 4. 今日

### 4.1 页面职责

“今日”只回答：今天推进什么计划、今天复习哪些错题。

默认内容：

- 考试倒计时；
- 今日周期计划事项；
- 各份错题复习方案的完成情况和开始按钮；
- 今日总完成数量；
- 不读取或展示旧版详细日程任务，旧任务仅通过设置中的兼容入口访问；
- 打开完整月历的入口。

### 4.2 不展示

- 计划时长与实际学习时长；
- 复杂优先级、任务来源和变化历史；
- 周趋势、科目投入和连续打卡；
- Workspace、Schema 和运行状态；
- AI Provider 状态和 Token 图表。

### 4.3 基础验收

- 用户在 10 秒内看到今天全部计划和错题入口；
- 没有计划时显示明确空状态和“新建周期计划”；
- 休息日明确显示“今天是休息日”，不生成错题队列；
- 窄窗口仍可完成全部操作。

## 5. 周期计划

### 5.1 创建入口

计划提供两种入口：

1. 快速表单，零 Token；
2. “AI 帮我整理”，从自然语言和本地资料生成相同结构的草稿。

快速表单默认字段：

- 做什么；
- 总数量及单位；
- 开始日期；
- 截止日期；
- 节奏，例如“每 2 个学习日 1 套”。

科目为可选字段。休息日直接继承全局设置。说明、预计分钟和优先级放入非默认的更多设置，且不得影响基本创建。

### 5.2 节奏优先

用户同时输入数量、节奏和截止日期时：

- 系统优先保持节奏；
- 截止日期表示最晚完成限制；
- 提前完成是正常结果；
- 超过截止日期时显示冲突，不自动压缩。

用户可以主动切换为“均匀安排到截止日”，由系统重新计算平均间隔。

### 5.3 多学习日事项

当一项内容占用多个学习日，例如一套卷子占 2 个学习日：

- 日历将其视为一个事项；
- 每个学习日显示当前进度，例如“第 1/2 个学习日”；
- 休息日不计入学习日；
- 整项完成后总数量才增加 1；
- 系统不自动拆成“作答、批改、复盘”等用户未指定的子任务。

### 5.4 顺延与重新规划

事项未按期完成时，用户可以一键顺延当前事项及所有未开始事项：

- 已完成历史保持不变；
- 后续继续保持原节奏；
- 自动跳过休息日；
- 写入前显示新的预计完成日期。

顺延后超过截止日期时：

- 默认仍允许按原节奏顺延；
- 明确显示超过天数；
- 计划进入“预计超期”状态；
- 提供加快频率、减少剩余次数和自定义调整；
- 不自动修改数量或节奏。

## 6. 月历

### 6.1 定位

“计划”页面默认打开按月展示的日历。月历借鉴 Apple 日历的月份切换、日期选择和密度处理，但只服务学习计划，不复制通用日历功能。

### 6.2 月历内容

- 一个完整月份的 7 列网格；
- 上一月、下一月和回到今天；
- 今天、休息日和考试日期的明确标记；
- 用户主动选择显示的周期计划；
- 完成、未完成、跳过和预计超期状态；
- 多日事项的连续表示。

月历不得展示错题复习方案或单道错题。

### 6.3 可见性

每份周期计划提供“在月历中显示”开关。月历顶部允许临时筛选显示计划，并记住上次选择。隐藏只影响月历，不暂停计划，也不影响“今日”。

### 6.4 日期交互

点击事项显示轻量操作卡片：

- 完成；
- 顺延；
- 跳过本次；
- 查看整个计划。

首个整改版本不支持拖拽改期。所有状态更新提供短时撤销。

### 6.5 密度与响应式

- 日期格最多直接显示 3 项，其余显示“还有 N 项”；
- 宽窗口显示标题，窄窗口使用色点和数量；
- 点击日期后在右侧或下方展示完整当日清单；
- 不显示小时刻度，不要求开始时间和持续时间。

## 7. 习题册与题目

### 7.1 习题册

题库固定采用“科目 → 练习册 → 章节 → 基础/综合/拓展 → 题型 → 题目”的层级。科目和练习册分类均由用户创建；同一练习册可以同时出现在高等数学、线性代数和概率论等不同科目根节点下。

一个物理 PDF 可以包含多个科目。自动分析后先生成待确认科目分段，用户分别为每段选择科目根节点和练习册，再写入正式索引。底层只保存一份 PDF，不因多科目归类复制文件。

### 7.2 题目区域

- 有结构目录和文字坐标的 PDF 默认自动识别章节、篇章、题型、题号和区域；
- 每道题允许包含一个或多个跨页区域；
- 少量异常可从自动索引分段中直接手动补题，或给当前卡片补充 PDF 区域；
- 行列式、矩阵等高公式按视觉边界修正题目起止位置；已有区域允许移动、缩放和移除；
- 对明确不存在跨页题的做题本，自动索引以题间空白带分隔相邻题目，不把下一页内容自动追加到上一题；区域调整以整道题为单位原子保存；
- 浏览题目索引时可直接在当前题之前或之后补题；系统继承当前题的科目、练习册、PDF 分段、章节、篇章和题型，并自动定位当前页，保存时原子调整后续题目顺序；
- 题目浏览器按同一 PDF 分段、章节、篇章和题型检查纯数字题号连续性，列出可能缺失题号、相邻重复题号和异常大跨度；缺失项可直接进入预填题号的相对补题，诊断完全本地运行且不因页面空白自动创建题目；
- 拼卷范围允许同时勾选多个科目，再叠加练习册、章节、篇章、题型和作答状态条件；
- 练习卷展示期间允许直接编辑题目元数据或校正题目区域，返回练习卷后保留尚未提交的作答选择；
- 页面、坐标、书籍和区域顺序自动保存；
- 自动生成可读默认标题；
- 自动识别科目和题型；
- 自动结果始终允许手动覆盖。

自动解析、归类和校对全部在弹窗中进行。正文浏览页只展示科目树、练习册进度、索引列表和快捷入口。

### 7.3 结构化分类

题目使用固定维度，不先建设自由标签系统：

| 维度   | 规则                         |
| ------ | ---------------------------- |
| 科目   | 题库根节点，由用户确认       |
| 习题册 | 科目下的资料分类，由用户确认 |
| 题型   | 选择题、填空题、解答题、其他 |
| 章节   | 优先从 PDF 目录自动识别      |
| 篇章   | 基础题、综合题、拓展题、其他 |
| 题号   | 对应纸质/PDF 原题号          |

题型高置信度时自动预选；低置信度时必须手动点选一次后保存。手动选择优先于自动识别。已保存题目支持单题和批量修改。

### 7.4 错题进入复习池

- 作答错误：自动加入；
- 作答不确定：自动加入，初始反馈视为模糊；
- 框选历史错题：点击“保存为错题”加入；
- 作答正确：不自动加入，但允许手动加入；
- 同一道题再次出错：更新原记录，不创建重复错题。

大量新导入历史错题进入候选池，由每日配额逐步消化，不一次性全部推送。

### 7.5 现实做题同步

题目当前状态仅显示“未做、做对、不全对、做错”，内部保留每次不可变作答历史。批量登记允许输入：

```text
本次完成：1-20
做错：3,7,15
不全对：8,11
```

其余已完成题自动记为做对；做错和不全对题进入错题候选。当前状态取最近一次结果，同时保留历史错误次数供复习和拼卷权重使用。

### 7.6 本地拼卷

用户可以按科目、练习册、章节、篇章、题型和题目当前状态筛选候选范围，并分别设置选择题、填空题和解答题数量。抽题在本地完成，做错、不全对和历史多次错误题拥有更高权重；同一张卷中不得重复题目。完成后可以直接登记每道题的做对、不全对或做错结果。

## 8. 错题复习方案

### 8.1 方案字段

用户可以保存多份独立复习方案：

- 名称；
- 科目；
- 一本、多本或本科目全部习题册；
- 每日总量；
- 选择题、填空题、解答题和其他题型配额；
- 是否启用。

方案记住选中的习题册。用户可以在开始前使用“本次只刷某一本”，该选择只影响本次，不修改长期方案。

各题型配额之和必须等于每日总量，界面实时计算并阻止不一致配置。

### 8.2 每日候选范围

后台先按方案筛选：

```text
科目 → 习题册范围 → 题型
```

再在每个题型中按以下因素排序：

1. 是否为上次未完成并顺延；
2. 逾期天数；
3. 上次反馈；
4. 连续“不会”次数；
5. 历史错误次数；
6. 距离上次出现的时间。

用户不填写人工优先级或知识薄弱度。

### 8.3 题型不足

某题型没有足够到期题时：

- 不提前抽取未到期的同题型题目；
- 从同一科目和指定习题册范围内的其他到期题补足每日总量；
- 简短说明实际组成；
- 不从方案范围之外的科目或书籍补题。

多本书同时入选时，真实紧急度优先；优先级接近时分散书籍来源。

### 8.4 顺延队列

当天未完成的题保留原顺序，在下一个学习日插入队首：

- 顺延题占用次日配额；
- 3 道顺延加 2 道正常候选仍为每日 5 道；
- 顺延不增加错误次数；
- 顺延题优先于题型比例；
- 休息日不生成队列，顺延到下一个学习日；
- 顺延题多于配额时，新到期题继续等待并自然提高优先级。

### 8.5 反馈和间隔

正式反馈只有三个大按钮：

| 反馈 | 初始行为                                      |
| ---- | --------------------------------------------- |
| 不会 | 次日再次到期，连续失败次数增加                |
| 模糊 | 3 个学习日后再次到期，成功连续次数清零        |
| 掌握 | 按连续掌握次数进入 7、14、30、60 个学习日间隔 |

完成当日队列后可以选择“重看今天不会的题”。该操作是可选巩固，不增加错误次数，也不改变正式间隔决定。

### 8.6 卡片式复习

每道题使用独立卡片：

- 顶部显示书籍、科目、题型和页码；
- 主区域展示一个或多个题目图片区域；
- 支持滚动、缩放、拖动画面和恢复大小；
- 点击图片打开只包含题目的大图弹窗；
- 主流程不打开或跳转整本 PDF；
- 底部从左到右固定“掌握、模糊、不会”和当前进度；
- 快捷键固定为 `1 = 掌握`、`2 = 模糊`、`3 = 不会`；
- 多份启用方案组成一段连续复习流程，完成一份后自动进入下一份；
- 支持键盘快捷键并提供撤销上一次反馈。

每日复习不显示耗时、答案笔记、人工优先级和详细评分原因。

## 9. 资料与 AI 规划

### 9.1 资料范围

资料页保存普通 PDF、图片、规划资料和思维导图源文件。习题册拥有独立入口，但继续复用同一本地文件与受控读取基础设施。

### 9.2 AI 规划入口

AI 规划放在“新建计划”内部：

```text
新建计划 → AI 帮我整理 → 选择资料 → 简单对话 → 计划卡片 → 月历预览 → 确认
```

AI 最终输出 1～5 张简洁周期计划卡片，每张包含：

- 名称；
- 数量和单位；
- 节奏；
- 起止日期；
- 必要的来源说明。

每张卡片可以单独修改、接受或放弃。AI 不输出几百条每日任务，也不直接写入正式计划。

### 9.3 Token 策略

- PDF 和图片先在本地建立可检索信息；
- 规划对话只发送与当前问题相关的页面或片段；
- 保存资料、章节和对话摘要；
- 后续轮次复用摘要和缓存；
- 相同内容不重复提交；
- 每次调用展示外发预览和预算状态。

## 10. AI 错题解析

错题卡片提供可选“AI 解析”按钮：

- 仅用户主动点击时调用；
- 优先发送题目区域图片，不以 OCR 文本作为主要输入；
- 不发送完整页面或整本 PDF；
- 多区域题目按顺序一起发送；
- 书籍、科目和题型可作为少量辅助上下文；
- 图片内容未变化时复用本地缓存；
- 修改题目区域后旧缓存失效；
- 结果明确标注为 AI 解析，提示可能存在错误；
- AI 解析不参与“不会、模糊、掌握”算法。

OCR 继续用于本地搜索和辅助分类，但不是 AI 解题的优先输入。

## 11. 思维导图

### 11.1 定位

思维导图是资料的一种查看方式，定位为“可简单修订的导图阅读器”。不要求用户在 KyStudy 中从零制作完整导图。

### 11.2 导入与副本

- `.xmind`、FreeMind `.mm` 和 OPML 支持结构化导入；
- 原始文件保持不变；
- KyStudy 创建规范化的本地可编辑副本；
- 重新导入生成新副本，不覆盖已有修改；
- 图片和 PDF 导图只支持浏览和缩放，不转换为节点。

### 11.3 基础能力

- 缩放、拖动画布和适应画布；
- 搜索并定位节点；
- 展开和折叠分支；
- 修改节点文字；
- 新增和删除节点；
- 调整父子层级和同级顺序；
- 撤销和重做；
- 保存本地副本。

不提供复杂主题、字体、图标、关联线、概要、外框、附件、掌握度、重要度、知识关系、演示模式和 AI 自动扩写。

### 11.4 技术验证

展示层优先验证 Mind Elixir，但在正式采用前必须验证：

- React 19 和 Tauri 离线运行；
- 中文输入法与键盘快捷键；
- 千节点浏览和编辑性能；
- `.xmind`、`.mm`、OPML 转换保真度；
- 撤销、重做与 SQLite 持久化边界；
- MIT 许可证和依赖清单。

## 12. 进度

### 12.1 计划进度

只保留与执行直接相关的进度：

- 已完成数量 / 总数量；
- 完成百分比；
- 下一项；
- 预计完成日期；
- 是否预计超期。

固定数量计划的完成率为：

```text
已完成数量 ÷ 当前总数量
```

跨多日事项只有整项完成后才增加数量。跳过不算完成。修改总量后按新总量重新计算。

### 12.2 不再作为默认产品范围

- 学习时长和计划时长对比；
- 7/28/90 天趋势；
- 科目投入占比；
- 连续打卡；
- 知识点薄弱图；
- AI Token 趋势图。

已有历史数据暂时保留，不在第一阶段删除。

## 13. 本地、安全与兼容性

- SQLite 和本地文件继续作为事实来源；
- 完整 PDF、题目图片和导图默认不离开设备；
- WebView 不接收数据库路径、原始文件路径、SQL 和内部错误；
- API Key 只保存到系统安全凭据存储；
- 备份继续包含 SQLite 一致快照和 Blob 校验；
- 整改通过增量迁移实施，不删除 v14 历史数据；
- 复杂旧功能先从默认界面隐藏，新体验稳定后再决定清理；
- 用户数据不随未来的源码发布。

## 14. 核心验收场景

### 14.1 周期计划

用户创建“20 套真题、每套 2 个学习日、12 月 21 日前完成”，系统在 30 秒内返回准确月历预览，自动跳过休息日，并明确预计完成日期。

### 14.2 顺延

用户未完成一套卷子，一键顺延后续计划。若超过截止日期，系统仍允许保持原节奏，并提供加快频率或减少次数的可选重新规划。

### 14.3 错题保存

用户框选题目后，系统自动带出书籍、科目和题型。识别正确时一次点击保存；识别不确定时只需点选一次题型。

### 14.4 每日错题

高数方案配置为 5 道、选择 2/填空 1/解答 2。填空题不足时，系统在同一范围内用其他到期题补足，并解释实际组成。

### 14.5 顺延错题

昨日有 3 道未完成，今日配额为 5。系统按原顺序显示 3 道顺延题，再选 2 道正常候选，总量仍为 5。

### 14.6 卡片复习

用户不打开完整 PDF 即可查看题目区域，完成 5 道题并只使用三个反馈按钮。反馈保存后自动进入下一题，误点可以撤销。

从“今日”统一入口开始或继续错题时，系统直接打开复习窗口，不增加二次确认。复习窗口滚动长题目时，三个正式反馈按钮保持可见；关闭后再次进入仍定位第一道未完成题。

### 14.7 AI 题目解析

用户主动点击后只发送题目区域图片。重复打开复用缓存，解析结果明确标注风险，不改变错题间隔。

### 14.8 思维导图

用户导入结构化导图后直接浏览和做基础修改。原文件不变，复杂编辑功能不出现在界面。

## 15. 实施边界

整改按 [产品简化整改实施方案](archive/v0.1.0/SIMPLIFICATION_REDESIGN_PLAN.md) 分阶段进行。每个阶段都必须：

- 保持现有用户工作区可打开；
- 不以删除数据作为界面简化手段；
- 提供对应自动测试和人工验收步骤；
- 不在未通过验收时继续叠加新范围；
- 只在新体验稳定后清理确定无用的旧实现。
