## 2. 人工综合 Smoke

开始前请关闭旧窗口，双击上面的统一 `kystudy.exe`。本清单不会要求查看数据库、系统路径、API Key 或内部 JSON；如果某一步失败，只记录步骤号、界面提示和不含隐私的截图。

### A. 升级与主菜单

1. 启动后确认已有日程、资料、导图、题目、错题和复习数据仍存在，运行状态显示 `Schema v11`。
2. 确认窗口左侧依次显示：今日、日程、规划、资料、思维导图、习题册、错题复习、AI 设置、数据与备份。
3. 逐个点击九个菜单，确认每次只显示对应功能，不再把所有功能堆在一个长页面中。
4. 停留在“错题复习”后关闭并重新启动，确认恢复到“错题复习”；随后切回“今日”。
5. 缩窄窗口，确认菜单变为顶部横向滚动且功能仍可点击；恢复正常宽度后侧栏重新出现。
6. 在“规划”或“思维导图”中打开一个已有 PDF 页码引用，确认自动切到“资料”并打开对应资料页。

### B. 默认 Provider 与离线能力

7. 进入“AI 设置”，确认至少有一个带“当前使用”标记的 Provider，且列表顶部显示配置数量与 `20` 的上限。
8. 如果当前不是离线测试 Provider，请点击离线 Provider 的“设为当前”；断开网络后确认日程、PDF、搜索、导图、习题册和错题复习仍可用。
9. 点击当前离线 Provider 的“编辑”，修改显示名称后保存；切换到其他页面再返回，确认修改仍在。
10. 点击“新增 Provider”，选择“离线测试”，填写名称并保存；确认新卡片出现，但不会自动替换当前 Provider。

### C. 多 Provider 切换、测试与删除

11. 对新建的离线 Provider 点击“设为当前”，确认只有它显示“当前使用”。
12. 点击任一 Provider 的“测试”，确认该 Provider 成为当前项，焦点移动到下方测试文本区域。
13. 点击一个非当前 Provider 的“删除”，确认第一次点击只出现二次确认；点击“取消”后配置仍存在。
14. 再次删除该非当前 Provider并确认，确认卡片消失，当前 Provider不变，既有调用历史仍可展开查看。
15. 删除当前 Provider并确认，确认剩余某个 Provider自动成为当前项。
16. 如方便，可把列表删到只剩一个并删除最后一个，确认应用自动创建新的默认离线 Provider，列表不会为空。

### D. 远程 Provider 配置与密钥边界

17. 新增一个 Responses API Provider：填写容易识别的名称、`https://api.openai.com/v1`、模型 ID、上下文上限和输出上限；保存后确认显示“未保存密钥”。这里不需要真实 Key。
18. 编辑该 Provider，输入一段仅用于本机测试的临时字符串并保存；确认输入框清空，卡片只显示“密钥已保存”，不能回显内容。
19. 再次编辑并点击“删除密钥”，确认卡片回到“未保存密钥”。
20. 重新保存临时字符串，然后把协议改为“离线测试”并保存；确认密钥状态消失，类型变为离线且地址不再显示。
21. 把该配置改回 Responses API，确认状态为“未保存密钥”，证明旧系统密钥没有被复用。
22. 保存一段新的临时字符串后删除整个 Provider，确认需要二次确认，删除后配置消失且调用历史仍保留。

### E. Token 预算、预览与缓存

23. 选中离线 Provider，把预算设为单次 `1000`、每日 `5000`、每月 `20000`、模式“硬阻止”，保存并切页返回，确认数值保留。
24. 尝试把每日上限设得小于单次上限，确认保存被拒绝且刷新页面后原预算不变。
25. 输入不含隐私的短测试文本并生成预览，确认预览显示完整文本、目标、模型、输入预估、输出上限和最坏 Token 值。
26. 不勾选确认时执行按钮不可用；勾选后运行离线测试，确认出现结果且今日/月度用量增加。
27. 保持文本和输出上限完全相同，再次生成预览并运行，确认命中本地缓存且用量不再增加。
28. 生成预览后修改测试文本，确认旧预览立即消失，必须重新生成。
29. 把输出上限调到超过硬预算，确认预览显示预算阻止且不能执行；切换“仅警告”后确认预览允许手动确认。

### F. 历史、备份与隐私

30. 展开最近调用记录，确认只显示 Provider、模型、时间、状态、Token 或缓存，不显示测试原文、请求指纹、路径、SQL、密钥或原始网络错误。
31. 进入“数据与备份”创建完整备份，再恢复到一个新目录；确认恢复副本为 schema v11，Provider 非敏感配置、预算和调用历史存在。
32. 确认备份界面不会声称包含 API Key。系统密钥不进入备份；如果要撤销密钥，应在原工作区使用“删除密钥”或删除 Provider。

### G. 可选真实 Provider Smoke

33. 只有在你愿意消耗少量 Token 时才执行：新建 Responses API Provider，保存有效 API Key，选择短文本和较小输出上限并生成预览。
34. 明确确认后测试连接，确认结果、实际输入/输出 Token 和调用状态可见；任何错误都只显示稳定提示，不显示 Provider 原始正文。
35. 使用完全相同的请求再次测试，确认命中本地缓存而不产生第二次远程请求。
36. 删除 API Key 或整个测试 Provider。不要在截图、反馈或提交中展示 Key。

## 4. 本批次明确不验收

- 规划对话、多轮历史、PDF 片段自动检索、页码引用或规划草案写入；
- OCR、视觉模型、题目识别、答案分析或向量检索；
- Provider 预设库、代理路由、故障转移、余额脚本、导入导出或拖拽排序；
- 自动模型选择、流式输出、工具调用、后台批处理或系统托盘；
- 安装包签名、自动更新、GitHub Release 或公开开源准备。
