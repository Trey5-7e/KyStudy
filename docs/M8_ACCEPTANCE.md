## 2. 人工综合 Smoke

### A. schema v10 与离线能力

1. 启动统一 Release，确认运行状态显示 `Schema v10`，M7 的资料索引、题目、错题和复习数据仍存在。
2. 找到“M8 · AI 基础设施”，确认默认通道为“离线测试”，页面显示今日/本月 Token 用量。
3. 断开网络，确认日程、PDF 阅读、搜索、导图、习题册和错题复习仍可操作。

### B. Provider 与预算

4. 保持离线测试 Provider，修改显示名称、上下文上限和最大输出后保存；重启应用确认配置保留。
5. 把预算设为单次 `1000`、每日 `5000`、每月 `20000`、模式“硬阻止”，保存并重启确认保留。
6. 尝试把每日上限设得小于单次上限，确认保存被拒绝且原预算不变。
7. 切换“仅警告”和“硬阻止”，确认界面状态与实际预览结果一致。

### C. 外发预览与明确确认

8. 输入一段不含隐私的测试文本并生成预览，确认预览逐字显示将发送的完整文本、目标、模型和 Token 数值。
9. 不勾选确认时，执行按钮不可用；勾选后可以运行离线测试。
10. 生成预览后修改测试文本，确认旧预览立即消失，必须重新生成。
11. 把输出上限调大到超过单次预算，确认“硬阻止”模式下不能执行，且调用历史不新增 Provider 调用。

### D. 用量、缓存与历史

12. 在预算允许时运行一次离线测试，确认显示确定性结果，今日与本月用量增加。
13. 不修改文本、模型和输出上限，再次生成预览并执行，确认显示“命中本地缓存，新增 Token 为 0”。
14. 确认第二次执行后今日与本月用量没有再次增加。
15. 展开最近调用记录，确认只显示 Provider、模型、时间、成功/失败、Token 或本地缓存，不显示测试原文、请求指纹、路径或 SQL。
16. 创建完整备份并恢复到新目录，确认恢复副本是 schema v10，非敏感 AI 配置、预算和调用历史存在。

### E. API Key 安全边界

17. 切换到 Responses API，输入模型 ID 与 `https://api.openai.com/v1` 后保存，确认状态为“未保存”。
18. 输入一段专用测试 Key 并保存，确认输入框被清空，界面只能显示“已保存”，不能回显 Key。
19. 创建备份；不要分享备份文件，只确认界面与日志中没有出现 Key。备份只保存不可用作鉴权的凭据引用；同一 Windows 用户下的恢复副本仍可能解析到原系统凭据，因此密钥撤销必须使用“删除密钥”。
20. 点击“删除密钥”，确认状态回到“未保存”；不配置密钥时尝试调用应得到稳定提示，不显示网络正文。

### F. 可选真实 Provider Smoke

21. 仅在你愿意消耗少量 Token 时，保存有效 API Key，使用不含个人资料的短文本和较小输出上限生成预览。
22. 明确确认后调用，确认结果、实际输入/输出 Token 和调用状态可见。
23. 使用完全相同的请求再次调用，确认命中本地缓存而不产生第二次远程请求。
24. 删除 API Key，确认其从 Windows 凭据管理器移除。不要在截图或反馈中展示 Key。

## 4. 本批次明确不验收

- 规划对话、多轮历史、PDF 片段自动检索、页码引用或规划草案写入；
- OCR、视觉模型、题目识别、答案分析或向量检索；
- 自动模型选择、价格账单真值、流式输出、工具调用或后台批处理；
- 安装包签名、自动更新、GitHub Release 或公开开源准备。
