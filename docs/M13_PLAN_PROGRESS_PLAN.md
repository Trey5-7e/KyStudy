# M13：计划执行进度实施计划

| 项目    | 内容                                                   |
| ------- | ------------------------------------------------------ |
| 状态    | implemented，等待人工验收                              |
| Schema  | v14，不新增迁移                                        |
| 目标    | 用 M12 已确认的阶段任务呈现真实完成率、逾期和学习投入  |
| AI 消耗 | 无；进度由本地 SQLite 正式记录即时聚合                 |

## 1. 本批次交付

1. 在“个人规划”中为每份已保存计划增加“执行进度”；
2. 展示计划总完成率、已完成/有效任务、待完成、逾期、计划投入和实际投入；
3. 按计划阶段展示相同口径的进度条与关键数量；
4. 单独展示每阶段已生成、已取消和回收站数量，不把清理行为伪装成完成；
5. 从进度区直接进入日程处理待完成或逾期任务；
6. M12 新任务确认成功后只刷新进度区域；切换计划、增删阶段或重新进入页面时重新聚合；
7. 后端一次返回受限 DTO，前端校验计划汇总必须等于阶段之和；
8. 不新增主菜单、数据库表、第三方图表依赖或后台任务。

## 2. 指标口径

| 指标       | 口径                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 已生成     | 仍关联到现存阶段的全部 M12 来源任务                                  |
| 有效任务   | 未进回收站且状态不是已取消的来源任务                                 |
| 已完成     | 有效任务中当前状态为 `done`                                          |
| 待完成     | 有效任务中当前状态为 `todo` 或 `in_progress`                          |
| 完成率     | `已完成 / 有效任务`，按最接近整数舍入；没有有效任务时显示“—”         |
| 逾期       | 待完成任务中当前计划日期早于工作区今日日期；延期后按新日期判断       |
| 计划投入   | 有效任务的预计分钟合计；无预计时长按 0                               |
| 实际投入   | 来源任务全部未删除学习记录的分钟合计                                 |
| 已取消     | 未进回收站且当前状态为 `canceled`                                    |
| 回收站     | 当前 `deleted_at` 非空，不再同时计入其他状态分类                      |

`已生成 = 有效任务 + 已取消 + 回收站`，`有效任务 = 已完成 + 待完成`。后端和前端都会验证这两个守恒关系，避免部分状态静默丢失。

## 3. 来源边界

- 只统计 `plan_stage_task` 明确关联的任务，手工创建的普通日程不进入计划完成率；
- AI 对话回复和待确认规划草案不进入统计；
- 任务延期只改变逾期判断，不改变原始阶段来源；
- 任务取消、恢复、回收和恢复会立即反映到当前分类；
- 阶段删除后已生成任务继续保留，但来源阶段已置空，因此不再归入计划进度；
- 计划切回草稿或归档后仍可查看既有历史进度，但不能借此继续生成任务。

## 4. 实际投入边界

真实学习投入属于已经发生的历史事实。只要学习记录本身没有删除，即使来源任务后来取消或进入回收站，其分钟仍保留在计划和原阶段的实际投入中。这样不会因为整理日程而抹掉已经完成的学习。

计划投入采用当前有效任务的预计分钟，因此取消或回收任务会从计划投入中移除。两者口径不同，允许实际投入高于计划投入。

## 5. 性能与安全

- 进度仓储是独立只读适配器，不复用 WebView 传入的任务列表；
- SQLite 先按任务聚合学习记录，再按阶段聚合，避免一项任务的多个 Session 放大任务数；
- 现有 `plan_stage_task(stage_id, generated_date)` 和 `study_session(task_id, ...)` 索引覆盖主要联结；
- 前端按规划页面懒加载，长阶段列表使用 `content-visibility`；
- Command 不返回任务 ID、学习记录明细、内部 SQL、数据库路径或来源表行；
- 不调用 Provider，不产生 Token，不写入任何业务数据。

## 6. 本批次不包含

- AI 自动解释进度、预测考试结果或调整计划；
- 按知识节点计算计划完成率；
- 手工把普通任务补挂到计划阶段；
- 自定义指标公式、趋势图、燃尽图或报表导出；
- 跨计划对比、跨设备同步和公开发布准备；
- M9 AI 对话体验优化、自动切题和图片导图识别。
