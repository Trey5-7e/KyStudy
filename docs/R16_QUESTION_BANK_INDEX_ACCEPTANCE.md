# R16 科目题库、PDF 自动索引与拼卷验收

本轮把原来的“按 PDF 手动框题”扩展为科目优先的本地题库。测试不需要我操作你的电脑；请在新构建的 `kystudy.exe` 中集中完成以下步骤。

## 1. 科目与练习册根层级

1. 打开“习题册”，默认进入“题库索引与拼卷”。
2. 点击“新建科目”，创建“高等数学”“线性代数”“概率论与数理统计”（已有则跳过）。
3. 点击“新建练习册”，创建“880”。
4. 确认页面树的根节点是科目，练习册位于科目下一层。

## 2. 高数 PDF 自动索引

1. 点击“自动解析 PDF”，选择高数 880 完整 PDF。
2. 点击“分析目录和题目”，等待本地解析完成。
3. 确认返回一个“高等数学”科目分段，并显示 PDF 页码范围和识别题数。
4. 将它归入“高等数学 / 880”，点击“确认归类并建立索引”。
5. 确认题库树出现“高等数学 → 880”，题目索引可以按章节、基础/综合/拓展和题型筛选。

## 3. 混合 PDF 自动索引

1. 再次点击“自动解析 PDF”，选择线代概率 880 完整 PDF。
2. 确认系统返回“线性代数”和“概率论与数理统计”两个独立分段。
3. 两个分段均选择练习册“880”，分别归入对应科目。
4. 建立索引后确认两个科目根节点下都出现 880，但资料库中没有复制 PDF。

## 4. 题目卡片与跨页

1. 在题目索引中选择任意题目，确认题目在弹窗中显示原 PDF 图片区域，而不是跳回整本 PDF。
2. 检查至少一道包含多个区域的题目，确认多个区域按顺序出现在同一题目卡片。
3. 如果页面提示“有少量待校对”，确认不会阻止其他高置信度题目使用。

## 5. 快速登记现实练习

1. 点击“快速登记做题”，将范围选到具体科目、练习册、章节、篇章和题型。
2. 输入“本次完成 1-10、做错 3,7、不全对 8”并保存。
3. 确认 3、7 显示“做错”，8 显示“不全对”，其余已完成题显示“做对”。
4. 再次登记其中一道错题为做对，确认当前状态变为做对，但题目详情仍保留历史做错次数。

## 6. 智能拼卷

1. 点击“智能拼卷”，选择一个或多个科目范围和允许抽取的状态。
2. 分别设置选择题、填空题和解答题数量，生成练习卷。
3. 确认题目不重复、题型数量不超过可用候选，并在同一个大窗口中依次显示原题图片。
4. 为部分题目选择“做对 / 不全对 / 做错”并保存，确认题库状态与错题候选同步更新。

## 7. 离线与 Token

1. 断网后重复打开题库、筛选题目、快速登记和拼卷。
2. 确认上述功能全部可用，且 PDF 自动索引过程中没有 AI 外发确认或 Token 消耗。

验收时只需回复失败的步骤编号和截图；如果全部正常，可回复“R16 全部通过”。
