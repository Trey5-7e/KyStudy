# R9 今日错题入口与 API 管理简化

| 项目 | 内容 |
| --- | --- |
| 状态 | ready for acceptance（2026-07-30） |
| Schema | v16，不新增迁移 |
| 重点 | 一次开始全部错题方案；API 配置减少重复操作 |
| 自动门槛 | 前端 28 个测试文件、119 项测试；Rust 199 项测试；Clippy 与 Release 通过 |

## 1. 今日错题

- “今日”页面成为错题复习的统一起点；
- 点击一次后，按顺序为全部已启用、非休息日且尚无今日队列的方案生成队列；
- 已存在的队列保持不变，继续上次未完成位置；
- 暂停方案和休息日方案不会生成队列；
- 仍可在错题页为单份方案临时选择某一本习题册；
- 今日进度使用实际队列题数或当前到期题数，不用方案上限虚增分母。

## 2. API 管理

- Provider 列表保留名称、模型、地址、密钥状态、当前配置与基础操作；
- 新增 Provider 时可以同时填写 API Key，一次保存完成配置；
- 编辑时留空 API Key 表示保留原密钥；
- API Key 仍只进入 Windows 凭据管理器；
- 上下文上限和单次输出收进“高级限制”；
- 连接测试默认折叠，只允许当前 Provider 测试；
- Token 预算保持可见，调用记录继续默认折叠。

## 3. 集中人工验收

1. 准备至少 2 份已启用的错题方案，并确保今天没有为它们逐份点击开始。
2. 回到“今日”，点击“开始今日错题”，确认直接进入错题页且两份方案都已出现今日题目。
3. 完成其中一题，返回“今日”再点击“继续今日错题”，确认已有队列与进度未被重建。
4. 暂停一份方案或将今天设置为休息日，确认统一入口不会为它创建队列。
5. 打开“设置 → AI”，确认默认只看到 Provider 卡片、Token 预算、折叠的测试和调用记录。
6. 新增一个临时 Responses API 配置，在同一个弹窗填写名称、地址、模型和 API Key；展开“高级限制”确认仍可修改上限。
7. 保存后确认卡片显示“密钥已保存”，再编辑并留空密钥保存，确认原密钥仍保留。
8. 只有当前 Provider 应显示“测试连接”；点击后确认测试区自动展开。
9. 删除临时 Provider，确认原有学习数据不受影响。

通过标准：今日只需一次操作即可准备全部错题；重复进入不重建队列；API 基础配置无需在多个页面或表单之间往返。
