# R27 题库 PDF 分段安全移除验收

本轮面向现场把同一份 PDF 的三个科目分段误归入“1000 题”练习册的场景。目标是让用户按 PDF 分段一次移除整段索引，避免逐题删除 1109 道题，同时保留原 PDF、题目来源区域和历史记录。本文区分 schema 20 的现场只读证据与实现验收；自动定向检查已有记录，桌面人工验收已由用户于 2026-08-03 通过。

## 1. 用户场景与验收边界

用户将紧凑版 880 题 PDF 的高数、线代和概率论范围误归入“1000 题”。三段没有作答或复习历史，但每段已经建立了正式题目和区域。用户应能在题库树中逐段点击“移除分段”，在二次确认中核对来源后完成一次软删除；不需要打开题目浏览器逐题处理。

本轮只覆盖：

- 题库树中每个 PDF 分段的独立移除入口；
- 二次确认中的科目、练习册、标题、PDF、页码、实际题数和作答历史摘要；
- segment、关联题目的软删除、恢复和下游可见性；
- 同一唯一分段重新分析时的恢复边界；
- 通用题目回收站和复习方案不重新暴露批量移除的题目。

不提供立即硬删除，不删除 PDF/Blob，不把分段移除变成逐题网络或本地调用循环。

## 2. 现场数据库只读证据

### 2.1 安全边界

证据来自 2026-08-03 对默认工作区 SQLite 的只读核验，以 `mode=ro` URI 打开，仅执行 `SELECT` 和只读元数据查询。现场数据库为 schema 20，`PRAGMA integrity_check` 为 `ok`；本次查询没有执行 `INSERT`、`UPDATE`、`DELETE`、迁移、备份恢复或桌面操作，也没有自动写回用户数据库。

## 3. UI 验收

### 3.1 逐段入口与二次确认

每个树节点都显示独立的“移除分段”按钮；按钮不能依赖整行点击，也不能只有无文字图标。按钮的可访问名称应包含科目、练习册、分段标题和 PDF 页码。点击入口后打开“移除题库分段”确认框，用户还必须再次点击“确认移除分段”才提交。

确认框至少显示：

- 科目 / 练习册；
- 分段标题；
- PDF 文档；
- PDF 页码范围；
- 按当前快照 `segmentId` 过滤得到的实际题数；
- 有作答题数 / 作答总次数。

警告正文应明确：分段会从题库树、题目浏览和拼卷中移除；原 PDF 不删；题目区域、作答和复习历史保留；重新分析同一 PDF 分段可以恢复可见索引。取消、Esc、busy 和错误路径不能产生部分删除；成功后用后端返回的 snapshot 刷新树、统计和所有打开范围。

### 3.2 键盘与错误状态

- “移除分段”按钮支持 Enter/Space；不增加全局 Delete 快捷键。
- 确认框空闲时可用 Esc 取消；提交期间禁用确认、取消和关闭，避免异步事务中卸载对话框。
- 错误消息保留在对话框内并使用 `role="alert"`；重复删除或陈旧快照应显示可行动的“已移入回收站/刷新后重试”提示，而不是 generic unavailable。
- 关闭后焦点返回触发该分段按钮；确认成功后也恢复焦点，避免键盘用户回到页面顶部。

## 4. Schema 20 与事务语义

迁移 `0020_question_bank_segment_trash.sql` 为 `workbook_document_segment` 增加可空 `deleted_at`，并新增 `workbook_segment_question_trash(segment_id, question_id, deleted_at)` tombstone 表。tombstone 记录这次批量移除实际触及的题目，不能用普通题目回收站的单一时间戳推测恢复范围。

分段移除在一个 SQLite `Immediate` 事务中完成：

1. 校验分段存在且仍为 active；不存在和已移入回收站分别返回明确错误；
2. 为该分段当前未删除的题目写入 tombstone；
3. 仅将 tombstone 集合中的题目设置 `question.deleted_at`，不删除区域、作答或复习历史；
4. 设置分段 `deleted_at`，将 `question_count` 置零并标记为待建立状态；
5. 提交后返回完整 `QuestionBankSnapshot`，前端不得自行拼接部分快照。

重新保存同一 `(document_id, subject_id, workbook_id, page_start, page_end)` 唯一分段时，后端清除 segment tombstone 状态并恢复该次 tombstone 中、且当前 `question.deleted_at` 仍等于该批次删除时间的题目。先前由用户单独放入题目回收站的题目不属于本批次 tombstone，因此不会被重新分析复活。

## 5. 下游可见性与回收站边界

- 题库树、题目浏览器和智能拼卷只读取 active segment 与 active question；移除后整段不再出现在这些范围中。
- 复习方案的候选统计、待处理队列和 carryover 必须过滤挂在已删除 segment 下的题目；已经完成的历史事件仍保留为历史记录。
- 通用“题目回收站”排除存在 `workbook_segment_question_trash` tombstone 的题目，避免把批量分段移除错误展示为可逐题恢复；分段恢复只能通过同一唯一分段重新分析。
- 单题删除仍沿用既有题目回收站语义；分段恢复不得清除其独立删除状态。

## 7. 人工验收步骤（用户已通过）

以下定向桌面步骤已由用户于 2026-08-03 通过；现场数据库摘要与只读边界见第 2 节。

1. 在隔离工作区确认 schema 20 与三段误归类记录可按表中 ID 和数量定位。
2. 在题库树逐段打开确认框，核对科目/练习册、标题、PDF、页码、实际题数和作答摘要；取消与 Esc 后快照未变。
3. 确认移除误归类分段后，分段从树、浏览、拼卷和复习候选消失，1000 题与 880 的 live 计数不变，PDF、regions 和历史记录仍可读取。
4. 确认通用题目回收站不列出批量移除题目；单题独立删除后再恢复分段时，该题不会被错误复活。
5. 重新分析同一 PDF 的同一唯一范围，确认 segment 和对应 tombstone 题目按既定边界恢复，题号、区域和历史没有重复。
6. 对陈旧快照和重复点击确认显示明确错误，事务没有产生部分移除。

R27 桌面步骤已通过；代码级结果仍不能替代后续 R28 导入归类 guard 的最终自动门禁与人工验收。

## 8. 安全边界与结论

- 本轮证据查询只读，不自动写用户 SQLite、Blob、PDF、OCR、备份或迁移文件。
- 生产操作是可恢复的 soft-delete，不提供立即硬删除；硬删除仍属于清空回收站/后续数据维护边界。
- 只有 schema20 tombstone 能定义批量移除的可恢复集合；普通题目回收站不能替代它。
- R27 桌面人工验收已由用户通过；R28 的导入归类 guard 另行记录最终自动门禁和桌面验收状态。
