## 1. 本批次结果

M7 在不接 AI、不做 OCR 的前提下建立了完全本地的资料检索链路：

```text
受控 PDF Range 读取 -> PDF.js 逐页文字层 -> Rust 校验、分片与哈希
                                              |
                   页码跳转 <- 有界摘要 <- FTS5 本地搜索
```

文字索引由用户主动触发，可以取消、继续、强制重建和清除。扫描页只记录“无文字层”，不会上传或自动调用 OCR。前端不接收文件路径、SQL、存储键、片段 ID、内容哈希或完整页面载荷。

## 3. 人工综合 Smoke

建议准备两份你有权使用的测试资料：一份可以复制文字的普通 PDF，一份扫描版或纯图片 PDF。测试不需要联网，也不需要打开开发者工具。

### A. schema v9 与旧数据

1. 启动统一 Release，确认运行状态显示 `Schema v9`。
2. 确认 M6 的任务、规划、思维导图、习题册、题目、作答、错题和今日复习队列仍存在。
3. 找到“学习资料”中的“M7 · 本地文字索引”，确认已有 PDF 都显示索引状态，图片和导图源文件不进入 PDF 索引列表。

### B. 普通 PDF 文字索引

4. 选择一份可复制文字的普通 PDF，点击“建立文字索引”。
5. 确认逐页进度持续增加，期间 PDF 阅读、任务和错题等其他本地数据没有变化。
6. 完成后确认状态为“可以搜索”，并显示总页数、有文字页数和片段数量。
7. 关闭应用后重新启动，确认该 PDF 仍显示“可以搜索”，没有无提示地重新解析。
8. 对已完成资料点击“重新建立”，确认进度从第一页重新开始，完成后仍可搜索且不会出现重复结果。

### C. 搜索与页码跳转

9. 搜索 PDF 正文中一段至少 3 个字的明确短语，确认出现资料名、正文摘要和页码。
10. 点击“打开第 N 页”，确认阅读器打开同一份 PDF 并定位到结果页。
11. 搜索 1～2 个汉字，确认短查询仍可返回包含该文字的页面。
12. 搜索一段英文词组，确认英文单词之间没有被错误拼接。
13. 搜索只存在于资料标题、不存在于正文的词，确认显示“资料标题匹配”并可打开资料。
14. 搜索不存在的词，确认显示明确的无结果状态，而不是报错或保留旧结果。
15. 断开网络后重复步骤 9～14，确认搜索和页码跳转完全可用。

### D. 取消、继续与清除

16. 对页数较多的 PDF 重新建立索引，在尚未完成时点击“取消索引”。
17. 确认状态变为“上次索引已中断”，已经完成的页数得到保留。
18. 点击“继续索引”，确认从剩余页继续，而不是重新处理第一页。
19. 完成后点击“清除索引”，第一次点击只进入确认状态；点击“取消”确认不会清除。
20. 再次进入确认并点击“确认清除索引”，确认状态回到“尚未索引”，原始 PDF 仍能正常阅读。
21. 搜索刚被清除的正文，确认不再命中；重新建立后再次可以命中。

### E. 扫描 PDF、重启与恢复

22. 对扫描版或纯图片 PDF 建立索引，确认最终显示“未检测到文字层”，不会伪造文本或自动启动 OCR。
23. 索引过程中直接关闭应用；重新启动后确认状态为“上次索引已中断”，可以继续。
24. 创建完整备份并恢复到新的空目录；确认恢复副本显示 schema v9，索引状态和搜索结果可读取。
25. 在恢复副本中清除并重建索引，确认索引确实是可重建派生数据，且原 PDF、题目和规划引用不受影响。

## 4. 通过标准

步骤 1～25 全部符合预期即可回复：`M7 全部通过`。若某份特殊 PDF 失败，请提供“步骤编号 + PDF 类型（文字型/扫描型/加密型）+ 界面提示 + 截图”；不要发送含版权内容的整份 PDF、数据库或个人路径。

## 5. 本批次明确不验收

- OCR、公式识别、目录分析、题目区域检测或答案提取；
- AI Provider、API Key、对话、摘要、向量索引或 Token 预算；
- 自动索引全部资料、后台定时扫描或云端同步；
- 安装包、签名、自动更新、GitHub Release 或公开开源准备。
