# R8 核心界面与规划流程优化

| 项目 | 内容 |
| --- | --- |
| 状态 | accepted（2026-07-29） |
| Schema | v16，不新增迁移 |
| 重点 | 月历优先、资料辅助与周期计划合并、核心页面降噪 |
| 自动门槛 | 前端 28 个测试文件、118 项测试；Rust 199 项测试；Clippy 与 Release 通过 |

## 1. 计划页

- 月历成为首屏主体，休息日移入右侧折叠设置；
- 月份只需要 5 行时不再强制展示空的第 6 行；
- 选中日期详情压缩为空间可控的侧栏卡片；
- 周期计划卡片后置，历史详细规划弱化为兼容入口；
- 新建和编辑仍全部在弹窗中完成。

## 2. 周期计划弹窗

- 表单按“目标”和“日期与节奏”分组，桌面端最多 3 列，窄屏自动单列；
- AI 辅助改为默认收起的可选区域，不妨碍手动快速创建；
- 可搜索已索引资料，并明确勾选最多 6 个 PDF 页码；
- 仅将所选页的受限文字片段放入完整外发预览，不包含本地路径和资料 ID；
- AI 生成的是可编辑卡片，采用卡片只回填表单，不直接保存正式计划；
- 上一轮卡片可作为下一次调整参考，避免重新描述全部要求。

## 3. 其余核心页面

- 今日：缩短顶部说明和空状态高度，提高行动内容密度；
- 资料：去掉重复标题层级和 SHA 指纹展示，收紧搜索区与资料行；
- 习题册：收紧工具栏，PDF 工作区改为视口内滚动，减少到题目区的长距离滚动；
- 错题：压缩休息日设置区域，保持复习方案和三按钮反馈为主操作；
- 全局：统一卡片圆角、阴影、间距和窄屏表单布局，并保留可见焦点与减少动画偏好。

## 5. 集中人工验收

1. 打开“计划”，确认月历位于页面首屏最上方，月份切换、回到今天和日期选择正常。
2. 展开右侧“每周休息日”，修改并保存后确认周期计划仍正常重排。
3. 新建周期计划，确认输入框不再贴挤，窗口缩窄后表单变为单列。
4. 展开“AI 辅助规划”，不选资料时生成一次外发预览；取消后不应产生正式计划。
5. 搜索已建立文字索引的 PDF，勾选 1～6 页，确认第 7 页不可继续勾选；核对外发预览只包含已选片段。
6. 确认发送并采用一张 AI 卡片，检查表单被回填但计划尚未保存；点击“生成并保存”后才出现在月历和卡片区。
7. 打开“今日、资料、习题册、错题”，确认卡片更紧凑；习题册 PDF 在固定工作区内部滚动。
8. 关闭应用并断网重启，确认本地页面和已有数据正常。

通过标准：核心操作无回归；计划页层级清楚；弹窗无明显拥挤；AI 不绕过预览和保存确认；本地能力不依赖网络。
