# KyStudy v0.1.2

KyStudy v0.1.2 重点优化组卷体验、逐题学习和 Windows 升级流程。

## 主要优化

- 组卷新增“单题浏览”模式，支持上一题/下一题按钮和左右方向键；首尾不循环，题型筛选与作答进度会保留。
- 每道组卷题都支持 AI 解析，只发送当前题目区域；解析结果支持缓存、历史记录、重新解析、复制和长内容查看。
- 组卷草稿升级为 v2，自动保存浏览模式、当前位置、筛选条件和作答结果，并兼容旧版草稿。
- 增加题号总览、下一道未作答题、题图失败重试和连续模式延迟加载，长卷浏览更稳定。
- 修正刷新组卷、离开确认、底部操作栏遮挡和自动暂存状态提示等问题。
- 正式版数据目录迁移到安装路径旁的 `data`，支持旧 AppData 工作区校验、备份和迁移。

## AI 与隐私

AI 请求仍需用户明确确认，题目图片不会默认上传；AI 输出仅作为参考解析，不会替代标准答案或改变错题推荐。

## 升级说明

- 支持从 v0.1.1 自动更新到 v0.1.2。
- Windows x64 提供 NSIS 安装包和便携版 ZIP。
- 卸载默认保留安装目录旁的 `data`；如需删除，请在卸载确认页勾选删除应用数据。
- OCR 组件继续复用独立的 `ocr-v0.1.0` Release。
