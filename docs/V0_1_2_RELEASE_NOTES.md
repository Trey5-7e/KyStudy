# KyStudy v0.1.2 发布说明（候选）

## 已交付

- 练习卷支持连续浏览和单题浏览，单题模式提供上一题/下一题按钮及左右方向键导航；首尾不循环。
- 题型筛选、筛选内位置、全卷题号和作答标记在浏览模式切换后保持。
- 每道组卷题目均可独立打开现有 AI 预览/确认/执行链路，只发送当前题区域图片。
- 练习卷草稿升级为 v2，保存模式、筛选、当前题和作答结果；旧 v1 草稿可兼容读取。
- 自动暂存显示 `saving`、`saved`、`failed` 状态；暂存失败时保留离开确认并提示使用保存记录。
- 刷新组卷区分未提交临时作答和已写入记录，避免出现不可执行的“请先保存后刷新”提示。
- 题号总览支持跳转任意题和下一道未作答题，连续模式题图按可见性延迟生成。
- 题图加载失败时提供单题重试，不阻断其余题目浏览。
- 每道题成功的 AI 解析会按题目与图片区域指纹持久化；再次刷到同一题时自动读取上一份解析，不重复消耗 Token，并可主动重新解析、复制解析和滚动查看长内容。
- 题目下方新增“历史解析”入口，按时间倒序查看该题保存的多次 AI 解析；已有最近解析会在数据库升级时一并纳入历史记录。
- AI 解析确认框允许编辑提示词指令并保存为本机共享偏好；组卷题和错题复习会使用同一份指令，题目上下文仍由当前题目自动同步。
- 正式版默认数据根目录改为安装路径旁的 `data`；NSIS 安装阶段会创建并检查该目录可写，启动时按迁移链初始化工作区，并在目标为空时备份、校验和迁移旧 AppData 工作区。

## 已知限制

- 安装器仍需由用户在 Windows Release EXE 上验收目录选择和实际权限提示；卸载默认保留安装目录旁的 `data`，卸载确认页的“删除应用数据”选项才会删除该目录。

## 候选资产校验

发布工作流会在 Tauri 签名资产和 Windows x64 portable ZIP 均生成后，生成并上传
`kystudy-windows-x64-release-manifest.json`。清单的 `artifacts` 数组记录同一候选提交生成的
NSIS 安装包、对应签名文件、`latest.json` 和 portable ZIP 的文件名、字节数与 SHA-256。
当前文档不预填 GitHub Draft Release 的哈希；候选提交固定后，以该清单作为发布前复核依据。

## 验证状态

自动化验证通过后，仍需由用户完成 v0.1.1 → v0.1.2 自动更新、非系统盘干净安装、旧 AppData 迁移和桌面交互验收；自动化不会启动 Release EXE 代替该验收。
