# R19 题目区域可靠性集中验收

本轮集中解决 4 个问题：区域调整保存失败、相邻题目误合并、页尾或题间框选过多，以及拼卷过程中无法顺手校正题卡。

## 1. 区域保存

1. 打开“习题册 → 浏览题目索引”，选择一题并点击“调整题目区域”。
2. 移动或缩放已有橙色框；如有需要，再新增一个区域或移除多余区域。
3. 点击“保存区域调整”。应正常返回题目浏览窗口，不再出现“找不到这道题目”。
4. 再次打开同一道题，确认全部区域一次性保存成功，顺序和坐标保持不变。
5. 故意把所有区域删除时，保存按钮应不可用或阻止保存；一道题至少保留 1 个区域。

## 2. 重新自动解析

1. 对 880 高数篇或线代篇重新执行“自动解析 PDF”。
2. 重点抽查含行列式、矩阵、分段函数的页面，以及一页有多道题的页面。
3. 相邻两题之间有明显空白时，上一题应在空白带中结束，下一题应从自身公式或题号附近开始。
4. 不应再因为下一页存在 `(I)`、`(II)` 等小问，把下一题追加成上一题的第 2 个区域。
5. 页尾最后一题不应把页码及其上方的大段空白全部收入卡片。

说明：重新解析会更新仍由自动索引维护的区域；已经手动校正并保存的题目会保留人工区域，不被自动结果覆盖。

## 3. 拼卷科目选择

1. 打开“智能拼卷”。
2. 科目卡片应按“科目名称在上、勾选标记在下”展示，中文名称不再挤成竖排。
3. 使用鼠标点击整张科目卡片，或使用键盘聚焦后切换勾选状态。
4. 同时选择多个科目并生成练习卷，确认抽题范围只包含已选科目。

## 4. 边刷边校正

1. 生成一张练习卷，为前几题选择“做对 / 不全对 / 做错”。
2. 在任意题目右上方点击“校正区域”，调整框体并保存。
3. 返回练习卷后，确认题目图片立即更新，之前已选择的作答结果仍保留。
4. 点击“编辑题目”，修改题号、章节、篇章、题型或标题并保存；返回后题目说明立即更新。
5. 完成整张卷后保存结果，确认题库状态和错题候选正常更新。
