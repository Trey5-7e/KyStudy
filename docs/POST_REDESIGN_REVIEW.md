## 1. 当前已经形成的核心闭环

- 输入数量、日期和节奏，自动生成周期计划与月历；
- 给习题册设置科目，保存 PDF 题目区域并自动/手动分类；
- 按科目、书籍和题型配额生成每日错题队列；
- 只用“不会、模糊、掌握”完成反馈并自动计算下次优先级；
- 导入并浏览导图，在本地副本上完成基础修改；
- 按需发送题目图片获得 AI 参考解析，并受缓存与 Token 预算约束。

## 2. 仍然存在的高价值缺口

### 2.1 资料驱动规划仍被拆成两个入口（R8 已解决）

新周期计划弹窗支持一句话生成结构化卡片，但不能直接选择已上传的规划 PDF；旧版资料规划对话可以引用 PDF 页码，却位于兼容弹窗且输出仍偏对话式。用户需要在两个入口之间来回切换。

建议把两者合并到新周期计划弹窗：

- 选择 0～6 个已索引的规划资料页；
- 输入自己的基础、可用时间和目标；
- 先展示完整外发内容与 Token 估算；
- 返回 1～5 张结构化周期计划卡片；
- 每张卡片可编辑、忽略或采用；
- 采用后展示本地月历预览，最后才保存；
- 只发送选择的文字片段，不发送整本 PDF。

这是当前最明显的“已有能力但仍不够省步骤”的地方，建议作为下一批优先项。

R40 后续证据（2026-08-10）：上述资料选择与结构化周期计划卡片已收进同一个“新建周期计划”窗口。窗口直接读取本地规划资料，按已选资料过滤页片段，保留无资料关键词路径，并在外发前展示可取消的显式预览；prompt 不包含本地路径或资源 ID。原始问题描述与历史建议保留不变，R40 focused gate 已通过，桌面验收待用户执行。

### 2.2 每日错题仍需逐个方案点击开始（R9 已解决）

现有算法已经能够决定题目，但用户进入错题页后仍需为每个方案生成队列。后续可在“今日”提供一个统一的“开始今日错题”入口，自动准备所有启用方案并从上次位置继续；临时只刷某本书仍保留为次级操作。

### 2.3 API 管理仍偏工程面板（R9 已解决）

基础能力已经完整，但页面仍包含较多上下文上限、调用历史与预算细节。后续可收敛为 Provider 卡片、地址、模型、API Key、启用和连接测试；高级限制默认折叠。

### 2.4 样式表仍保留部分已删除页面的旧规则（R10 已处理）

旧组件已经不会进入生产 Bundle，但单体样式表仍有历史选择器。它不影响运行，适合在没有产品功能变更的维护批次机械清理，不应抢占核心体验优先级。

## 3. 推荐顺序

1. 合并资料规划对话与结构化周期计划卡片；
2. 统一“开始今日错题”入口；
3. 简化 API 管理页面；
4. 清理无引用样式与历史文档状态。
