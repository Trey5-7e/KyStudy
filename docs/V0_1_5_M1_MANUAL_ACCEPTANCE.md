## 3. 从隔离目录启动

先确认第二节副本已准备好。以下命令由你在 PowerShell 中手动运行；若使用了不同副本路径，修改 `$acceptanceData`。不会启动正式目录，也不会设置永久环境变量。

```powershell
$acceptanceData = 'F:\develop\KyStudy\artifacts\manual-acceptance\schema31-20260907\data'
$acceptanceExe = 'F:\develop\KyStudy\src-tauri\target\release\kystudy.exe'
$previousDataOverride = $env:KYSTUDY_APP_DATA_DIR
if (-not (Test-Path -LiteralPath "$acceptanceData\workspaces\default\kystudy.sqlite3" -PathType Leaf)) {
    throw '未找到测试副本数据库，请先完成复制并核对目录层级。'
}
if ((Get-FileHash -LiteralPath $acceptanceExe -Algorithm SHA256).Hash -ne 'ff53487e994bf72bc5aacb69fd193fa0d265f30fc1e586769e3271d095c5092e') {
    throw '程序已不是本文对应构建，请先索取更新后的验收清单。'
}
try {
    $env:KYSTUDY_APP_DATA_DIR = $acceptanceData
    Start-Process -FilePath $acceptanceExe -Wait
} finally {
    $env:KYSTUDY_APP_DATA_DIR = $previousDataOverride
}
```

启动后第一件事：在“设置 → 数据”核对“数据目录”确实是测试副本。点击“导出诊断摘要”打开预览，核对 `workspace.schemaVersion` 为 31（不是只看应用版本 0.1.4 或 `runtime.schemaVersion`），不必实际导出。如路径不是副本，立即退出，勿做数据操作。此环境变量会同时跳过旧数据目录的自动搬迁；不要脱离以上命令直接双击新 EXE。

重开验收时仍运行同一段命令，确保继续使用同一个副本。正式目录保持不动。
