# M2 阅读体验增量：人工验收

更新：2026-09-10。状态：构建及门禁通过，待用户桌面验收。此前“功能基本正常”的反馈仅作为 M2-A 的部分实测证据，不代替全部用例通过。

## 本批变化

- 开始前紧凑配置；开始后隐藏配置，以居中答案为主，过程默认折叠。
- Markdown 标题、列表、表格及公式渲染；研读答案不加载远程图片、不启用外链或练习操作卡。
- 来源点击后显示本轮实际读取的索引文字对照；关闭或 Escape 回到来源按钮，可再打开 PDF 核对。
- 重新进入时恢复所选资料、页码和问题。调整范围属于新研读，不隐式携带旧回答。
- 完成后可以追问：仅复用上一轮问题和公开答案的短摘录，重新核对同一授权范围的证据。资料版本、会话或模型配置不一致时拒绝沿用。
- 长页按 Unicode 字符游标继续读取；界面合并实际读取区间，缺段或旧记录不能证明覆盖时提示“部分原文”。模型仍可能提前结束，需实测教学质量；不会保证任意长页面都在一轮内读完。

未包含扫描页视觉研读、完整 PDF 内嵌分屏、多轮全文历史、跨重启私有协议恢复或练习审批。本批仍使用 Schema 32，无新迁移。

## 验收清单

| 编号 | 操作                                                                                 | 预期                                                                                                  |
| ---- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| R1   | 在已有会话选择已索引 PDF、物理页码和问题并开始                                       | 配置收起；运行摘要、取消操作可见；完成后答案居中，不被挤在右侧                                        |
| R2   | 用含列表/公式的问题，缩小窗口并滚动到底                                              | 标题、列表和公式可读；页面无横向溢出；底部来源、过程和追问可用                                        |
| R3   | 点击来源，关闭对照，再次打开；按 Escape；点击“在资料库打开 PDF”                      | 仅按需出现对照，内容是已读取片段；关闭回到来源按钮；PDF 定位正确物理页                                |
| R4   | 对一页超过 2400 字符的非敏感文本要求“完整说明这一页，包括最后一段”，预先记下页尾事实 | 过程可看到多次读取，回答包含页尾事实；若未覆盖全部原文，界面明确提醒部分证据，不得误报完整读取        |
| R5   | 对完成的回答追问“把第二步展开讲讲”，再离开/返回页面                                  | 新一轮沿用原授权页，理解短摘录范围内的指代；问题显示为当前追问，不显示原始 JSON；结果仍有新核对的来源 |
| R6   | 点击“调整范围 / 新问题”，检查字段；修改范围再开始                                    | 资料、页码、问题正确回填；新范围明确，不默认携带上一轮回答                                            |
| R7   | 仅在副本中重建所选资料索引，或修改模型配置，再追问旧结果                             | 提示版本变化，不沿用旧证据；可通过调整范围重新开始                                                    |
| R8   | 运行中取消；随后在普通对话发送非敏感问题；检查原资料并创建完整备份                   | 取消完成后不新增步骤，普通对话正常，原资料未被修改，备份校验通过                                      |

R4 若模型因运行保护停止，应记为“未达到完整研读预期”并反馈，不能只因界面提示正确就算教学质量通过。旧记录没有游标覆盖信息时提示部分证据属于兼容行为。
