# R24 习题册 PDF 扫描兼容性验收

本轮针对两份 EduEditer 来源习题册 PDF 的文字坐标索引做兼容性验收设计。目标是让本地规则可以建立可校对的题目索引，同时保留 R19～R23 已确认的边界：空白本身不创建题目，异常题号只提示检查，题目区域和最终补题仍由用户确认。本文件是验收方案，不代表桌面验收已经完成。

## 1. 来源 PDF 的版式记录

以下观察来自随本轮提供的两份样本及其 PDF.js 文字层抽样，不复制 PDF 正文。

| 来源样本 | 页面基线 | 版式特征 |
| --- | ---: | --- |
| 高等数学习题册 | 296 页 | A4 竖版；有可读取的文字层和坐标；顶层题号使用 `1.`、`2.` 等十进制编号；同一页可出现基础部分结束、强化部分开始以及强化部分重新从 `1.` 编号；大公式可能位于题号上方；页眉和页脚重复出现。 |
| 线性代数/概率论混合习题册 | 214 页 | A4 竖版；有可读取的文字层和坐标；线代内容位于 PDF 第 3～91 页，概率论内容从第 92 页起；顶层题号使用十进制编号；综合测试题中出现 `(1)`、`(2)` 小问；矩阵或分段公式可能先于题号的视觉起点；同样带重复页眉、页脚及可能的水印文字。 |

两份样本都不是“一个题号对应一行文字”的简单格式：公式、矩阵和选项会把一个题目拆成多个坐标项；一题可能跨页；`(1)`、`(2)` 在题干内表示小问，不能直接当成新的顶层题目。

## 2. 适配范围

### 2.1 顶层题号与编号风格

- 以左侧题目区域中的十进制题号为主，接受 PDF 文字层常见的 `1.`、`1．`、`1、` 及其周围空格；题号后没有正文分隔时不应把普通小数或公式中的 `1.0` 当成题号。
- 在同一页或同一题目区域已经发现十进制顶层题号时，括号编号 `(1)`、`（1）` 只作为小问文本，不再创建顶层题目。若保留旧版括号题号兼容，只能在该区域没有十进制锚点时作为显式的低优先级回退，并产生可校对提示。
- 题号锚点仍需满足左侧边界和同一行约束；页眉中的书名、年份或右侧标题不能成为锚点。
- 连续性诊断继续只对纯数字题号生效。换到同页的另一篇章、基础/强化部分或新章节时，题号可以合法重置，诊断不得跨分段推断缺题。

### 2.2 章节和篇章分段

- 章节标题识别应容许 `第 1 章`、`第1章`、中文数字和阿拉伯数字之间的空格，并保留完整的打印标题（例如章节名的正文部分）。
- `基础部分` 映射到 `basic`；`强化部分` 映射到 `comprehensive`。已有的 `基础题`、`综合题`、`拓展题` 仍保持兼容，`综合篇`/测试卷等篇章标题也按 `comprehensive` 处理。
- 同一页先出现基础题号、随后出现“强化部分”并从 `1.` 重新编号时，标题在下一个锚点前更新上下文；题目的分段键至少包含章节和篇章，不能只用 PDF 页码。
- 页面没有新的可见标题时，沿用最近的章节/篇章上下文；如果书签定位提供了更可靠的章节，应在页面文字缺失时补回该上下文。

### 2.3 无题型大标题时的区域推断

题型判定按以下优先级执行，输出题型和置信度；显式标题与区域线索冲突时保留冲突警告并以显式标题为准：

1. 页面文字或书签路径中的 `选择题`、`填空题`、`解答题`；
2. 题目区域中有成组的 `A.`～`D.`（含全角标点）等选项标签，判为 `choice`；
3. 区域中有明确的填空线/占位线，且没有选项组，判为 `blank`；
4. 区域中有 `(1)`、`(2)` 等小问、证明/计算的多行正文，判为 `solution`；
5. 信号不足时保留 `other` 或低置信度题目并计入 warning，不因页面空白自动创建或强行伪造题型。

区域推断应在题目边界确定后执行，而不是把整页第一个题型套到所有题目。这样可以覆盖样本中的基础选择题、基础/强化填空题以及综合题，而不会把线代综合卷的 `(1)`、`(2)` 当作两道新题。

### 2.4 页眉、页脚和水印

- 先按相对坐标过滤页眉、页脚，再做题号和题型检测；页面编号文本应识别常见的“第 n 页/共 n 页”、`Page n of m` 等变体。
- 对跨页重复的固定位置文字建立通用重复项集合，可过滤任意来源的重复水印或页眉；不得只硬编码本次 PDF 的公众号、网址或 `EduEditer` 字样。
- 水印若位于正文中且不能通过重复位置、字体/透明度或跨页频率与题干区分，保守保留并计 warning，交给人工框选；不能为了删除水印而丢失公式或选项。
- 页脚及大段题间空白不参与题目区域终点计算；仍遵守 R19/R22 的规则：空白不是缺题证据。

### 2.5 标题/书签与科目分界

科目分段按证据强度从高到低处理：

1. 书签中的明确科目根节点（高等数学/高数、线性代数/线代、概率论/数理统计）优先；同一科目后代章节不重复建立根分段。
2. 书签只有章节时，使用来源文件标题（`descriptor.title`）中的科目关键词；文件名没有扩展名也应正常识别。
3. 文件名含义不明确时，对章节标题做词汇评分：函数/极限/微积分等偏向高等数学，行列式/矩阵/特征值/二次型等偏向线性代数，随机变量/分布/数理统计等偏向概率论与数理统计。
4. 章节关键词出现连续科目转换时，以章节书签的 PDF 页码作为分界；页码范围使用 PDF 1-based 页码，后一科目起始页的前一页为前一科目终点。样本应得到线代 PDF 第 3～91 页、概率论第 92 页至末页的候选分段。
5. 既没有科目文件名也没有可靠章节词汇时，只返回一个“待确认科目”范围并给出 warning；不能凭章节序号猜科目。

显式科目根节点的范围计算仍应去重同名后代，并将范围裁剪到 `[1, pageCount]`。书签只提供章节而没有根节点时，页面解析和书签上下文匹配不能依赖不存在的 `sourceHeading`；应按候选分段的科目或页范围匹配章节。

### 2.6 题目区域与跨页边界

- 公式或矩阵位于题号上方时，题目区域从视觉起点（向上追溯相邻公式）开始；下一题的视觉起点前用题间空白切分，不能把下一题公式并入上一题。
- 题目跨页且下一页没有新的顶层题号时，只有在连续上下文明确时才追加为同一题的有序区域；无法确认时保留 warning，要求用户在 PDF 上框选，不根据大段空白自动合并。
- 题干中的 `(1)`、`(2)`、`(I)`、`(II)` 等小问留在当前题目区域；它们不是新的 `questionNumber`。

2. `第 1 章` 的空格、全标题保留、`基础部分`/`强化部分` 的映射；同页 `22、23 → 强化部分 → 1` 的上下文和分段键重置。

## 4. 人工验收步骤

1. 导入高等数学样本，确认文本层解析成功、仅出现一个高等数学候选分段；抽查页 3、9、16、171、295 等包含章节切换、基础/强化切换、长公式或页尾的页面。
2. 导入混合样本，确认线代范围从 PDF 第 3 页开始、概率范围从第 92 页开始；抽查行列式/矩阵页面和综合测试卷，确认 `(1)/(2)` 不会增加顶层题数。
3. 在题库浏览器按科目、章节、篇章和题型筛选，运行 R21/R22 诊断；同一篇章内的纯数字题号可诊断缺漏，分段重置和非数字小问不应跨界推断。
4. 对公式高于题号、跨页连续题、重复页眉/水印和页脚的页面打开题目卡片，检查区域覆盖；不确定的跨页或水印由用户手动调整，并确认 R19 的人工区域保护仍有效。
5. 用 R20 流程在前后各补一题，确认题号、题型、章节和 PDF 页继承正确；用 R23 流程确认重复/跳号/非数字指纹不因重新索引而意外复用。

## 5. 风险和人工校对边界

- PDF.js 文字层可能把公式拆成多个 item，或把公式保存为图形；自动规则只能依据坐标，无法保证数学语义完整。
- 同一页编号重置是篇章边界的强信号，但没有标题时不能单凭数字跳回 `1` 猜测分段；应保留 warning 并由用户确认。
- 选择项被做成图片、填空线缺少文字层、复杂水印与题干重叠时，题型和边界置信度会下降；系统应让用户改题型或框选区域，而不是静默丢题。
- 文件名或章节关键词可能含“数学”等泛词；科目推断必须有明确关键词或多章一致证据，混合范围不确定时宁可返回待确认分段。
- 页码范围是 PDF 页号，不是书页印刷号；封面、目录和前言可能造成两者偏移，人工验收必须记录使用的页号体系。
- 空白、OCR/目录缺陷、异常跳号不能直接创建题目；这与 R21/R22 的防误补边界一致。人工校对是最终决定题号、题型、章节、篇章和区域的步骤。
