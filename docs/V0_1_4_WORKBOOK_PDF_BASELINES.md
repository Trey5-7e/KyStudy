## 解析契约

- 所有已适配 profile 均启用 `allowUnpunctuatedQuestionNumbers`，只在题号位于左侧内容边界且后接中文正文时识别无标点题号。
- 普通 PDF 默认使用 `generic-text-pdf`。
- `填空部分`、`选择部分`、`解答部分` 映射到稳定题型元数据；900 题本的 `A 类`、`B 类`、`C 类` 分别映射到基础、综合、拓展篇章；“篇”“章”“单元”均可作为章节标题。
- `基础篇第N章 X` / `强化篇第N章 X` 作为章节标题处理，并分别携带基础/综合篇章属性。
- `基础部分 - 子专题`、`强化部分 - 子专题` 书签或页内标题生成“子章节”（如 `第2章 矩阵·矩阵运算`），子章节内题号重启不再判重。
- `测试卷N` 标题作为子章节，保证每卷题号可从 1 重启。
- 书签叶子标题在无既有规则命中时回退为章节名（用于 660 线概的 `行列式`、`随机事件和概率` 等主题）。
- 题号 `0` 在任何风格下都不作为题目（消除公式碎片产生的 0 号幻影题）。
- 无标点/十进制题号在同一“章节|篇章|题型|子章节”上下文内必须保持递增且步长 ≤ 5，否则视为换行碎片幻影并丢弃；括号题号不受该序列约束；双栏页面跳过序列检查。
- 题号风格证据只采信左侧内容边界；证据优先级默认 decimal > parenthesized > plain，逐页持久化（无候选页不复位）。`plainBeforeParenthesized` profile 开启后 plain 优先于 parenthesized，用于答题区布满 `(1)` 空格标签的做题本。
- 同一题号列中纯数字文本项的拆分重建（裸 `(` + 数字 + `)`）仍受同线数字簇约束：单栏同一行出现多个独立数字时整簇不算题目。
- 重复水印判定排除长度 ≤ 6 的含中文短词（如题干开头的“设”“已知”“若矩阵”），避免统一版式下跨页同位置的正文起始词被误删。
- 页眉、页脚和重复水印继续沿用通用过滤规则；文字层稀疏时才触发本地 OCR。

## 回归范围

仓库内保留脱敏的 `PageItem` fixture 和 profile 单元测试，覆盖：

- 六个文件名到 profile 的确定性匹配；
- `1设...`、`161设...`、`1在...` 以及拆分成独立数字文本项的题号；
- 通用 profile 对无标点题号的保守拒绝；
- 题号 `0` 在括号、十进制、无标点三种风格下全部拒绝；
- 换行碎片幻影（如 `13 [10] 14` 序列中的 `10`）被序列检查丢弃；
- `强化部分 - 子专题` 子章节上下文切换允许题号重启并生成组合章节名；
- 书签主题叶节点回退为章节名；
- 三种分区标题和跨页/页眉页脚通用规则不回归。
