## 1. 本批交付

### 1.1 导图阅读器

- 使用成熟的 Mind Elixir 画布替换自研树形展示；
- 支持缩放、拖动画布、折叠、适应窗口和节点搜索；
- KyStudy 的 SQLite 节点仍是唯一正式数据源，第三方库只负责展示；
- 新建空白导图、导入导图、编辑导图信息、添加节点和编辑节点全部使用弹窗；
- OPML 与 FreeMind `.mm` 仍先生成草案，确认后才形成可编辑本地副本；
- 原导图源文件保持不变；图片与 PDF 继续由资料查看器浏览；
- 继续保留本地撤销、重做、节点资料关联和旧数据兼容。

### 1.2 一句话周期计划

- 新建周期计划弹窗内可输入一句自然语言要求；
- 调用前显示 Provider 与预计 Token，并再次确认；
- AI 只返回 1～5 张结构化计划卡片，不生成逐日任务；
- 卡片可单独修改、采用或忽略；
- 采用只回填原表单，不直接保存正式计划；
- 正式日历仍由 KyStudy 的确定性排程算法生成；
- 相同请求复用现有本地 AI 缓存与 Token 预算。

复杂的 PDF 资料规划继续使用已有“资料规划对话”：只发送用户选中的页码文字片段，不发送整本 PDF。

### 1.3 错题 AI 解析

- AI 入口位于每日错题图片卡片内；
- 未点击时只本地显示题图，不发起远程请求；
- 点击后才按区域顺序重新截取题目图片；
- 首次点击只生成外发预览，再次确认才发送；
- 每张图片限制 4 MB，单题最多 6 张、合计最多 12 MB；
- 图片使用 Responses API 的 `input_image`，OCR 文本不替代图片；
- 外发前把超大题图最长边压到 1600 像素，保留可读性并降低视觉 Token；
- 相同题图与提示命中本地缓存时显示 0 Token；题图变化后请求指纹变化，旧缓存不会误用；
- 解析明确标记为“AI 参考解析”，不冒充练习册标准答案；
- 结果不回写题目评分，也不参与错题优先级算法。

## 2. 人工验收

只需完成以下一次集中验收。

### A. 导图

1. 打开“资料 → 思维导图”，确认已有导图出现在左侧。
2. 选择导图，确认画布可以缩放、拖动和“适应窗口”。
3. 搜索一个节点名称并选择结果，确认画布定位且右侧显示当前节点。
4. 点击“添加子节点”，确认在弹窗保存后画布刷新。
5. 点击“编辑节点”，修改名称后保存；再测试撤销与重做。
6. 点击“导入导图”，确认导入操作位于弹窗，已有 OPML 或 `.mm` 可先预览后确认。

### B. 一句话计划

1. 打开“计划 → 新建周期计划”。
2. 在 AI 区输入“从今天到 12 月 21 日刷 20 套卷，两天一套，每周日休息”。
3. 点击“生成草案”，确认先出现 Provider、预计 Token 和确认按钮。
4. 使用真实 AI Provider 时确认发送，检查返回的卡片可以修改、忽略和采用。
5. 采用一张卡片，确认只是回填下方表单；只有点击“生成并保存”后才新增正式计划。
6. 若当前为离线测试 Provider，能完成预览和预算边界即可；离线 Provider 不生成真实计划卡片。

### C. 错题 AI

1. 打开“错题”，开始任意有题目图片的复习方案。
2. 确认不点击“AI 解析”时没有任何 AI 调用提示。
3. 点击“AI 解析”，确认先显示图片数量、目标 Provider 和预计 Token。
4. 确认发送后，检查解析结果带有“AI 参考解析”与非标准答案提示。
5. 收起后对同一道题再次解析，确认缓存命中显示“0 Token”。
6. 点击“不会 / 模糊 / 掌握”，确认复习仍正常进入下一题。
