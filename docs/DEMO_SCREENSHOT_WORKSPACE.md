# README 截图演示工作区

这套演示工作区用于制作 README、社交媒体和发布说明中的操作截图。它使用仓库内置的浏览器预览后端，数据全部由项目生成，不读取、不写入 Windows 桌面端工作区，也不会暴露个人资料、文件路径或 API Key。

## 启动

在仓库根目录执行：

```powershell
pnpm install --frozen-lockfile
./scripts/start-demo-preview.ps1
```

然后在浏览器打开对应页面。脚本默认使用 `127.0.0.1:1420`；如果端口被占用，可以指定其他端口：

```powershell
./scripts/start-demo-preview.ps1 -Port 1422
```

脚本会优先寻找 Windows 的 `pnpm.cmd`，找不到时再尝试 Corepack。如果两者都不可用，请先执行 `corepack enable`，或安装 pnpm 后重新运行。

## 推荐截图顺序

建议使用浏览器窗口 1440 × 900、缩放 100%，每张截图只保留一个明确操作目标。页面刷新即可恢复初始数据。

1. `http://127.0.0.1:1420/#planning`
   - 截取周期计划卡片、进度摘要和阶段日历。
   - 用于 README 的“计划与今日执行”说明。
2. `http://127.0.0.1:1420/#workbook`
   - 截取习题册列表、题目筛选和题目范围选择入口。
   - 这是展示“多本书、章节和题型组合组卷”最重要的一张图。
3. `http://127.0.0.1:1420/#library`
   - 截取资料列表、PDF/导图条目和资料阅读入口。
   - 用于说明资料统一管理和本地阅读。
4. `http://127.0.0.1:1420/#today`
   - 截取今日页的页面标题、周期计划入口和下一步行动卡片。
   - 如果需要强调“只处理今天”，优先使用这一张图。
5. `http://127.0.0.1:1420/#settings`
   - 截取工作区状态和数据管理入口。
   - 不要打开或展示任何真实 API Key、备份路径或本机路径。

## 截图注意事项

- 当前已保存的候选截图见 [`docs/screenshots/demo-workspace/`](screenshots/demo-workspace/)，后续再和本地工作区截图一起筛选；
- 保留 KyStudy 左侧导航和页面标题，让读者知道截图属于哪个模块。
- 不要把浏览器地址栏、开发者工具、终端窗口或个人桌面通知截入图片。
- 关闭系统深色模式、缩放变化和浏览器扩展浮层，保证不同截图视觉一致。
- 需要展示错误状态时，只使用预览页面已有的稳定中文提示，不要展示内部堆栈、数据库内容或本机路径。
- 截图文件先放在本地 `artifacts/demo-workspace/screenshots/`；该目录已被 Git 忽略，不会进入提交。

## 与真实桌面工作区的边界

浏览器预览只用于页面布局和文案截图，写入操作、真实 PDF 阅读、OCR、AI 请求和桌面端数据持久化不会在此预览中执行。需要制作真实导入或阅读截图时，请在 KyStudy 中先创建一个新的本地工作区，再使用 `artifacts/demo-workspace/materials/` 中的合成资料；不要把个人资料复制到仓库或截图目录。
