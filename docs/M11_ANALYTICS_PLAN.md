# M11：学习分析实施计划

| 项目     | 内容                                                   |
| -------- | ------------------------------------------------------ |
| 状态     | implemented，等待人工验收                              |
| Schema   | v12，不新增迁移                                        |
| 目标     | 用正式本地记录呈现进度、投入、薄弱点与当前积压         |
| AI 消耗  | 无；分析页面不调用 Provider                            |

## 1. 本批次交付

1. 增加独立的“学习分析”主菜单，并按页面懒加载；
2. 支持最近 7 天、28 天和 90 天三个固定周期；
3. 每个周期都与紧邻的等长上一周期比较，不跨出空档；
4. 汇总任务完成率、计划分钟、实际学习分钟、题目正确率、复习完成率和 AI Token；
5. 展示每天的计划分钟与实际学习分钟，长周期允许横向滚动；
6. 展示当前逾期任务、活跃错题、到期复习和今日队列剩余，并提供对应页面入口；
7. 按科目汇总任务完成情况和实际学习投入，保留“未分类”；
8. 展示有关联题目的知识节点正确率与活跃错题数；
9. 展示累计多次出错或连续未掌握的活跃错题；
10. 所有统计由 Rust 后端一次聚合为受限 DTO，前端不接收 SQL、路径、内部审计数据或原始错误。

## 2. 指标口径

| 指标         | 分子 / 数值来源                         | 分母 / 范围                                      |
| ------------ | --------------------------------------- | ------------------------------------------------ |
| 任务完成率   | 当前状态为 `done` 的任务数              | 计划日期在周期内，排除取消和回收站任务           |
| 计划分钟     | 上述任务的预计时长合计                  | 没有预计时长的任务按 0 分钟处理                  |
| 实际学习     | 正式 `study_session` 的时长合计         | 记录日期在周期内，排除已删除记录                 |
| 题目正确率   | 结果为 `correct` 的真实作答次数         | 周期内正式 `question_attempt`，排除回收站题目    |
| 复习完成率   | 状态为已完成的正式每日复习队列项        | 队列日期在周期内的全部正式队列项                 |
| AI Token     | 实际输入 Token 与输出 Token 合计        | 按上海日期归入周期；缓存命中新增 Token 为 0      |
| 当前积压     | 当前时点查询                            | 不受 7/28/90 天周期切换影响                      |

分母为 0 时比率显示“—”，不显示 0%，避免把“没有记录”误解为“表现为 0”。百分比按最接近的整数四舍五入。

## 3. 聚合边界

- 科目只汇总任务和实际学习时长。题目可以关联多个知识节点，不把它们重复累计为科目总数；
- 知识节点只展示正式关联题目的当前周期作答与当前活跃错题，不声称这是完整知识掌握度；
- 反复出错题来自当前活跃错题状态，不由 AI 推断；
- 当前与上一周期使用同样长度，例如“最近 7 天”包含今天和之前 6 天；
- 页面读取工作区时区计算“今天”，AI Token 依照当前中国考研单机版的上海日历边界汇总；
- 当前产品尚未建立计划、阶段与任务之间的自动进度关系，因此本批次不显示虚假的“计划完成百分比”。

## 4. 性能与安全

- 页面按需加载，导航进入后才查询；
- 后端在阻塞线程中执行只读 SQLite 聚合，避免占用桌面事件线程；
- 每日序列最多 90 行，知识节点最多 20 项，反复出错题最多 12 项；
- 不增加第三方图表库，柱状图由现有 React 与 CSS 实现；
- 不创建新表、不复制分析快照，备份恢复后直接从正式记录重新计算；
- 分析不会发起网络请求，不产生 Token，也不会修改任何学习数据。

## 5. 本批次不包含

- M10 OCR、图片识别、题目区域候选或 AI 错因分析；
- M9 AI 对话体验优化；
- AI 自动制定或改写日程；
- 计划阶段与任务的自动关联进度；
- 可自定义报表、数据导出、排行榜、连续打卡或预测分数；
- M11 后续的批量操作与专项性能治理。
