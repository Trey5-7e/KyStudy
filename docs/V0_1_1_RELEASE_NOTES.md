# KyStudy v0.1.1

KyStudy v0.1.1 是 Windows 首版 v0.1.0 的稳定性与发布体验修订版，重点收敛真实使用中的界面、数据隔离和安装体验问题。

## 主要变化

- 资料页的 PDF/图片阅读器改为当前窗口内的受控大尺寸弹窗，不再挤在资料列表下方；
- Debug 与 Release 使用独立的工作区目录和 AI 凭据服务，开发数据不会再污染正式安装版；
- Release EXE 使用 Windows GUI 子系统，启动时不再额外弹出命令行窗口；
- 设置页移除旧版兼容入口、内部 Schema 信息和离线测试 Provider，保留面向用户的隐私与问题排查内容；
- 设置页新增“关于”分区，展示版本、许可证和 GitHub 仓库；Windows 正式版支持后台检查签名更新，用户确认后下载安装，Debug 构建不会参与更新；
- 主页面标题结构统一，删除习题册“题库”、错题“每日复习队列”等冗余眉题，压缩重复副标题；
- 整理仓库文档与可再生成实验输出，继续保留源码、构建脚本、许可证和必要的开发文档。

## 下载

- NSIS 安装包：`KyStudy_0.1.1_x64-setup.exe`
- Windows x64 便携版：`kystudy-windows-x64-portable.zip`
- 可选 OCR 组件：继续使用 `ocr-v0.1.0` 公开组件 Release

- 应用不内置受版权保护的教材、试卷或题库，首次使用请导入自己有权使用的资料；
