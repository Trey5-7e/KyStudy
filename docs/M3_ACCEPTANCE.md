## 1. 本批次结果

M3 完成了一个不依赖网络、AI、OCR 或全文索引的最小闭环：

```text
导入 PDF/图片 -> 受控阅读 -> 保存 PDF 页码进度
                            |
个人计划草案 -> 阶段安排 -> PDF 页码引用 -> 回到原页复核
```

正式前端只持有 document ID、显示元数据和页码。PDF 由 `kystudy-pdf` 单 Range 协议读取，图片由独立只读协议加载；两者都不会把绝对路径、storage key、SQL 或整本 Base64 返回给 WebView。

## 2. 自动验证范围

- schema v1/v2/v3/v4 可升级到 v5，未来 schema 会被拒绝；
- v2/v3 历史备份可验证、迁移并恢复为 v5；
- 计划、阶段、PDF 引用和阅读页数可跨 Repository 持久化；
- 已知 PDF 页数时，越界引用会被拒绝；
- 自定义协议只接受根路径直接 UUID，拒绝嵌套路由和编码路径；
- PDF 协议只接受 GET 和单 Range，单响应不超过 1 MiB；
- 无效 Range 返回 `416` 和 `Content-Range: bytes */总长度`；
- PDF RangeSource 发出精确闭区间请求，越界请求在 fetch 前失败；
- 快速新渲染会先取消旧 RenderTask；
- PDF.js 显示层和 Worker 均为本地独立 chunk，不进入首屏主 chunk；
- 6 页确定性 PDF 的文字页与无文字扫描降级页经 Poppler 144 DPI 渲染并视觉检查，无裁切、黑块或尺寸异常；
- Rust 测试、Clippy、前端格式/Lint/类型/测试/build 与 Tauri Release 构建均需通过后才交付。

## 3. 人工综合 Smoke

请只使用本次提供的 M3 Release EXE，按顺序执行。整个 Smoke 预计 12-18 分钟，不需要联网，也不需要开启开发工具。

### A. 迁移与原有功能

1. 关闭其他 KyStudy 窗口，启动 M3 Release；确认窗口正常打开且运行状态显示 `Schema v5`。
2. 确认 M2 已有科目、任务、学习记录和资料仍存在；任选一个旧任务打开详情，确认内容可读。
3. 若当前工作区为空，先创建默认工作区，再继续。

### B. PDF 与图片阅读

4. 导入 `experiments/tv-04-pdf-viewer/public/fixtures/mixed-samples.pdf`；导入完成后把用途改为“规划资料”。
5. 点击该 PDF 的“打开阅读”；确认显示第 1/6 页，页面清晰且没有空白或黑块。
6. 依次测试“下一页”“上一页”、输入页码 `6` 后“跳转”、“放大”“缩小”“旋转”；确认控件有效且窗口不会卡死。
7. 在第 6 页关闭阅读器，再次打开同一 PDF；确认恢复到第 6/6 页，资料列表显示上次阅读页。
8. 输入页码 `7` 并跳转；确认应用提示页码应在 1 到 6 之间，仍停留在当前有效页。
9. 导入任意一张你有权使用的 PNG/JPG/WebP，点击“打开阅读”；确认图片完整显示且没有暴露文件路径。
10. 把 PDF 用途依次改为“习题册”和“规划资料”，重启应用后确认最终用途仍保留。

### C. 个人计划与阶段

11. 在“个人备考规划”点击“新建草案”，填写标题、目标考试、考试日期和总体思路，保存。
12. 添加两个日期不重叠或相邻的阶段，填写阶段重点；确认阶段按顺序显示。
13. 编辑其中一个阶段的名称或重点并保存；删除另一个阶段；确认列表即时更新。
14. 点击“确认为当前计划”；确认计划列表标记为“当前计划”。
15. 再新建第二份草案并确认；确认第二份变为当前计划，第一份自动回到草案，日程任务没有被自动新增或修改。
16. 将第二份计划归档；确认标记为“已归档”，仍可查看内容。

### D. 资料引用回跳

17. 选择一份未归档计划，在“资料页码引用”中选择 6 页样本，填写起始页 `2`、结束页 `3` 和引用说明，添加引用。
18. 点击引用的资料标题；确认页面滚动到资料阅读器，并直接打开 PDF 第 2/6 页。
19. 再添加起始页 `6`、结束页 `7`；确认保存被拒绝并提示检查页码范围。
20. 删除步骤 17 的引用；确认引用消失，但原 PDF 和计划仍存在。

### E. 离线与重启

21. 关闭 KyStudy，断开网络后重新启动同一个 EXE。
22. 确认计划、阶段、用途分类和 PDF 阅读进度仍在；再次打开 PDF，确认可以离线渲染。
23. 创建一次完整备份；确认备份成功。此步骤用于证明 schema v5 新数据已进入既有完整备份边界。

## 4. 通过标准

步骤 1-23 全部符合预期即可回复：`M3 全部通过`。若失败，请提供“步骤编号 + 界面提示 + 截图”；无需发送工作区数据库、原始个人资料或绝对路径。

- 思维导图、练习作答、错题优先级和每日复习队列；
- 删除资料、移动资料或修改原始 PDF；
- 安装包、签名、自动更新、GitHub Release 或公开开源准备。
