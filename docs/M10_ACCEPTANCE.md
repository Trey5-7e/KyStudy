## 2. 人工验收前准备

1. 先在“数据与备份”创建一份完整备份；
2. 准备一份你有权使用的习题册 PDF，至少包含一处清晰中文和一处公式、矩阵或表格；
3. 在“资料”中把该 PDF 用途设为“习题册”，在“习题管理”中至少保存一道题及其来源区域；
4. 本次开发构建会读取已经打包好的 TV-07 OCR 组件，不需要配置 API Key，也不需要联网；
5. 关闭旧 KyStudy 窗口后再启动本次统一 Release；测试过程中不要直接修改 SQLite 或 Worker 文件。

## 3. 人工综合 Smoke

### A. 升级、组件与原功能

1. 启动应用，确认运行状态为 `Schema v13`，原有日程、资料、导图、题目、复习、AI Provider 和学习分析数据仍存在；
2. 进入“习题管理”并选择已有习题册，确认 PDF 仍能翻页、缩放、旋转、框选和回跳；
3. 选择已有题目，确认题目详情中出现“本地文字识别”，组件状态为“可用 · 完全离线”并显示大致体积；
4. 点击“重新检测”，确认状态保持可用，页面不显示组件路径、模型路径或 Worker 原始输出。

### B. 首次识别与草稿

5. 在一个清晰中文来源区域点击“识别区域”，确认按钮切换为“取消识别”，应用窗口仍能响应；
6. 识别完成后确认出现“待确认草稿”、平均置信度和可编辑文本框；
7. 核对草稿内容大致对应原始区域，换行可以与原文不同，但不能混入其他 PDF 页或其他题目的内容；
8. 修改草稿中的一小段文字，确认可以正常输入、换行，且题目标题、个人解析和作答记录不被联动修改；
9. 切换到其他题目再返回，确认未确认草稿仍然存在；关闭并离线重启后再次确认草稿仍在。

### C. 确认、重新识别与丢弃

10. 编辑草稿后点击“确认文本”，确认草稿消失并出现“已确认文本”，内容是人工修改后的版本；
11. 点击“重新识别”，确认新草稿出现时旧“已确认文本”仍同时保留，没有被提前覆盖；
12. 修改新草稿并再次确认，确认页面只显示新的当前确认文本；
13. 再次识别，然后点击“丢弃草稿”，确认草稿消失，已有确认文本保持不变；
14. 离线重启应用，确认当前确认文本和题目区域仍然存在。

### D. 多区域、公式与原图边界

15. 给同一道题增加第二个来源区域，分别识别两个区域，确认各自草稿和确认文本不会串位；
16. 点击来源区域的页码按钮，确认始终能回到原 PDF 图片；OCR 文本不能取代或隐藏原图；
17. 对包含公式、矩阵或复杂表格的区域执行识别，确认页面仍提示以原始区域为准；不要以文字草稿是否“看起来正确”作为公式语义通过条件；
18. 删除一个允许删除的来源区域，确认该区域从题目和 OCR 列表中一起消失，其他区域不受影响；
19. 确认最后一个来源区域仍受现有保护，不能单独删除。

### E. 取消、失败与隔离

20. 对一个较大区域开始识别后尽快点击“取消识别”，确认最终显示取消提示或返回空闲状态，不生成新的半成品草稿；已有确认文本不变；
21. 连续快速点击识别、取消、切换题目，确认应用不崩溃、不出现两个互相覆盖的进度状态；
22. OCR 失败或被取消后，确认 PDF 阅读、手动框选、题目编辑和作答记录仍可继续使用；
23. 保持网络断开，再完成一次识别，确认无需联网且 AI 调用历史与 Token 用量没有增加；
24. 识别期间可在任务管理器观察到 OCR Worker 按需出现；识别结束或取消后应退出，不长期常驻；
25. 将窗口逐步缩窄，确认区域标题、按钮、确认文本和草稿编辑框不重叠，长文本能换行或在文本框内滚动。

## 4. 通过标准

A～E 的 1～25 全部符合即可回复：`M10 OCR 全部通过`。如果某项失败，请提供步骤编号、页面中的稳定提示和不含隐私的截图；不要展示完整习题内容、文件路径、API Key、数据库内容或 Worker 原始错误。

## 5. 本批次明确不验收

- 自动切题、答案区域检测、整本 PDF 批量 OCR；
- 图片规划资料或思维导图图片识别；
- 公式结构化、手写体、自动判题、AI 标签或错因分析；
- OCR 组件下载、安装、升级和卸载页面；
- M9 AI 对话体验优化；
- 非 Windows 平台。
