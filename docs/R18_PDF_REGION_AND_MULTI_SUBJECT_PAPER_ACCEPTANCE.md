# R18 PDF 区域校正与多科目拼卷集中验收

## 1. 自动框题

1. 重新自动解析线性代数 PDF。
2. 在“浏览题目索引”中检查包含行列式、矩阵和分段公式的相邻题目。
3. 确认下一题公式高于题号时，上一题不会包含下一题的公式顶部，下一题自身也不会漏掉该部分。
4. 普通选择、填空和解答题仍应从题号附近开始，并在下一题视觉起点之前结束。

自动框选仍属于本地启发式识别。PDF 如果把公式保存为纯矢量图形而不是文字坐标，系统无法完全推断语义，应使用下述手动调整功能校正。

## 2. 调整已有题目区域

1. 打开“浏览题目索引”，选择一道框选不准的题，点击“调整题目区域”。
2. 拖动橙色框内部，确认整个区域可以移动。
3. 拖动四角圆点，确认区域可以向上、下、左、右扩展或收缩，且不会越过 PDF 页面。
4. 聚焦框体或圆点后使用方向键微调；按住 Shift 时应加快移动。
5. 可继续在空白位置框选新区域，也可在左侧移除多余区域；一道题至少保留 1 个区域。
6. 点击“保存区域调整”，关闭后重新打开该题，确认移动、缩放、新增和移除结果均已保存。

## 3. 多科目拼卷

1. 点击“智能拼卷”。
2. 在“可拼入的科目”中同时勾选高等数学与线性代数，并取消概率论。
3. 保留需要的练习册、章节、篇章、状态和题型数量条件后生成练习卷。
4. 确认结果可以同时包含高等数学和线性代数，且不包含未勾选的概率论。
5. 取消全部科目时，“生成练习卷”按钮应不可用。
