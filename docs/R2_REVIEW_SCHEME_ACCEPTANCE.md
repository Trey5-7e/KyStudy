## 1. 本批交付

1. 习题册可设置默认科目，题目默认继承且允许单题覆盖；
2. 题型固定为选择题、填空题、解答题、其他，支持自动识别和手动修改；
3. 自动识别不确定时保留“待分类”，旧题可以按当前习题册批量补分类；
4. 支持创建多份复习方案，并按科目、一本/多本习题册和每日题型数量限定范围；
5. 某题型到期题不足时，只用同一方案范围内其他题型补足；
6. 多本书紧急度接近时尽量分散来源；
7. 全局每周休息日不生成错题队列；
8. 未完成题顺延到下一个学习日队首，并占用当天配额；
9. 开始当天复习时可临时只刷某一本书，不改变长期方案；
10. 正式反馈只有不会、模糊、掌握，下一次日期由系统自动安排；
11. 不会、模糊、掌握分别按 1、3 和渐进学习日间隔安排，自动跳过休息日；
12. 今日页读取新复习方案的到期量与完成进度。

## 2. 本批明确不包含

- 题目图片卡片、大图弹窗、快捷键和自动下一题，属于 R3；
- AI 图片解析，属于 R6；
- 新月历与周期计划，属于 R4；
- 删除旧错题表、旧优先级或历史数据。

因此当前复习区域显示题目标题、习题册和来源页码是正常现象；R3 会把它替换为图片优先的卡片体验。

## 3. 启动准备

1. 关闭正在运行的旧 `kystudy.exe`；
2. 启动 `F:\develop\KyStudy\src-tauri\target\release\kystudy.exe`；
3. 直接使用现有工作区，不要新建隔离副本；
4. 建议准备至少 2 本属于同一科目的习题册，并确保其中有若干已框选题目；
5. 本批不需要联网，也不需要调用 AI。

首次启动旧工作区时会自动从 v14 升级到 v15。原有资料、题目、OCR、作答和错题记录都应继续存在。

## 4. 习题册默认科目

1. 打开“习题册”，选择一本已有习题册；
2. 在习题册分类区域选择默认科目并保存；
3. 打开一本已有题目，确认其显示继承的科目；
4. 将该题科目改成另一科目并保存；
5. 再次打开，确认单题覆盖仍保留；
6. 恢复为跟随习题册默认科目，确认继承关系恢复。

验收：设置一次习题册科目即可覆盖大多数题目，不要求逐题填写。

## 5. 自动与手动题型

### 5.1 自动识别

1. 框选一段包含明显 A、B、C、D 选项的题目并完成 OCR 确认；
2. 保存题目；
3. 确认题型自动显示为选择题。

### 5.2 手动选择

1. 新建或编辑一道题；
2. 直接点击选择题、填空题、解答题或其他；
3. 保存并重新打开；
4. 确认手动题型没有被后续 OCR 覆盖。

### 5.3 待分类与批量设置

1. 找到题型为待分类的旧题；
2. 使用当前习题册的批量分类功能；
3. 选择一个题型并确认；
4. 确认待分类数量下降，已有手动分类不被误改。

## 6. 创建多份复习方案

进入“错题”，创建两份示例方案：

```text
方案一：高等数学，每日 5 道，选择 2、填空 1、解答 2、其他 0
方案二：线性代数，每日 5 道，可使用另一组题型数量
```

逐项确认：

- [ ] 每份方案必须选择科目；
- [ ] 可以选择本科目全部习题册，也可以只选一本或多本；
- [ ] 4 种题型数量之和不等于每日总量时不能保存；
- [ ] 保存后两份方案相互独立；
- [ ] 可以暂停并重新启用方案；
- [ ] 归档前有确认步骤，归档后不再生成新队列。

## 7. 今日队列与范围

选择一个已有到期错题的方案：

1. 点击开始今天的复习；
2. 确认生成数量不超过每日总量；
3. 确认题目全部属于该方案的科目和习题册范围；
4. 当某一种题型数量不足时，确认可由范围内其他到期题补足；
5. 确认不会从未选择的习题册补题；
6. 如果方案包含多本书，观察来源是否在条件接近时有所分散。

若当天没有足够到期题，队列少于每日总量是正常行为；系统不会为了凑数提前抽取未来题目。

## 8. 临时只刷一本

1. 在包含多本书的方案中，将“本次范围”选为其中一本；
2. 生成今日队列；
3. 确认本次只出现该书题目；
4. 第二天或重新查看方案设置，确认长期习题册范围没有改变。

## 9. 休息日

1. 把今天对应的星期设置为休息日并保存；
2. 尝试生成今日队列；
3. 确认界面提示休息日且不生成题目；
4. 取消今天的休息日，或改设为另一天；
5. 再次生成，确认功能恢复。

每周至少需要保留 1 个学习日，因此不能把 7 天全部设为休息日。

## 10. 顺延队首

此项需要跨两个自然日验证，或在日常使用中观察：

1. 第一天生成队列，故意留下 3 道未反馈；
2. 第二个学习日打开同一方案并生成队列；
3. 确认前一天 3 道题保持原顺序出现在队首；
4. 确认它们占用第二天每日配额；
5. 如果顺延数已经达到每日总量，确认当天不再加入新题。

## 11. 三种反馈与间隔

对不同题目分别点击：

- 不会：下一次安排到 1 个学习日后；
- 模糊：下一次安排到 3 个学习日后；
- 掌握：从 7 个学习日起，后续逐步延长到 14、30、60 个学习日。

验收：反馈只需点击一个按钮，不要求填写耗时、笔记、优先级或薄弱度；间隔中的休息日应自动跳过。

## 12. 今日页

1. 返回“今日”；
2. 确认错题区域显示新方案的今日总量和已完成数量；
3. 完成一道错题后刷新今日；
4. 确认完成进度同步更新；
5. 休息日时确认今日页不会要求完成错题计划。
