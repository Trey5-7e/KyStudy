## 1. 可安全删除

以下代码已经没有活动入口，且业务数据仍由其他页面或后端保留：

- `AnalyticsPanel`：旧复杂统计页面，当前“今日”只展示行动所需进度；
- `TodayTaskPanel` 及其专用的科目、任务详情、拆分、改期和历史子组件：旧任务管理器入口已经被“今日 + 周期计划”替代；
- `MindMapTree`：已由 Mind Elixir 阅读器替代；
- `analyticsClient` 前端适配器及其测试：只被已删除的旧复杂统计页面使用。

删除这些文件不会删除 SQLite 数据，也不会删除 Rust Command。

## 2. 明确保留

### 历史计划兼容

- `LegacyPersonalPlanPanel`、`PlanningChatPanel`、`PlanProgressPanel`、`PlanSchedulePanel`；
- 旧计划、阶段、资料引用和规划对话的前端客户端；
- 理由：用户仍可在计划页弹窗查看历史计划，资料驱动规划对话仍有实际用途。

### 历史日程兼容

- `ScheduleOverviewPanel`、周日程、学习记录、基础统计和回收站；
- 任务、科目、学习记录相关 Tauri Command 与 Rust 用例；
- 理由：周期计划生成的历史任务、回收和备份恢复仍依赖这些数据结构。

### 数据与恢复

- SQLite v1～v16 全部迁移及校验和；
- 旧表、软删除记录、备份恢复、启动恢复和升级测试；
- 分析、任务、旧复习队列等未在默认页面展示的后端能力；
- 理由：它们是已有工作区兼容边界，不以界面是否显示判断是否删除。

## 4. 集中人工验收

1. 启动应用，依次打开“今日、计划、习题册、错题、资料、设置”，确认一级页面均可进入。
2. 在“计划”新建一个临时周期计划并保存，再将它归档。
3. 在计划页打开“旧版详细规划与资料对话”，确认历史计划仍可查看；若已有历史日程，再打开“已有日程”。
4. 在“资料”切换“资料文件 / 思维导图”，确认 PDF、图片和导图入口仍正常。
5. 开始一次错题复习，确认图片与三个反馈按钮正常；AI 解析无需重复测试答案质量。
6. 打开“设置 → 数据”，确认备份、恢复和运行状态入口仍在。
7. 关闭应用并断网重新启动，确认首页和本地数据正常显示。

通过标准：没有空白页面或旧入口报错；历史计划与日程仍可查看；本地核心流程不依赖网络。
