# 技术验证（Spikes）

Spike 是为了消除技术不确定性而编写的短期实验，不等于正式实现。

## 规则

- 一个 Spike 只回答一个主要问题；
- 开始前写明样本、环境和通过标准；
- 同时记录成功与失败情况；
- 验证代码默认可丢弃，不直接复制进正式模块；
- 结论必须是“通过 / 有条件通过 / 不通过”之一；
- 产生架构选择时，另行创建 ADR；
- 依赖版本、测试设备和样本特征必须可复现。

创建报告时复制 [模板](TEMPLATE.md)，文件名建议为 `TV-NN-short-title.md`。
