## 本轮调整

- 从计划主页面移除始终可见的“历史详细规划（兼容）”卡片；
- 旧版计划、阶段、资料引用与规划对话迁移到“设置 → 数据 → 历史详细规划数据”；
- 旧数据和原有维护能力全部保留，没有数据库迁移或删除；
- 计划页直接懒加载周期计划模块，不再下载和解析旧版详细规划代码；
- 日常计划页面的前端模块从约 61.8 KB 降为约 23.0 KB；
- 旧版阶段和资料引用的删除操作增加二次确认。

## 集中人工验收

1. 打开“计划”，确认月历位于首位，页面底部不再显示旧版兼容卡片；
2. 新建、编辑一份周期计划，确认月历与完成进度不受影响；
3. 打开“设置 → 数据”，确认能看到“历史详细规划数据”；
4. 点击“打开兼容工具”，确认旧计划、阶段、资料引用和规划对话仍可读取；
5. 从旧资料引用打开 PDF，确认仍能跳转资料页；
6. 删除旧阶段或资料引用，确认必须再次点击“确认删除”才会执行；
7. 关闭兼容弹窗并返回计划页，确认新的周期计划页面保持简洁。

通过标准：日常计划页面不暴露旧版复杂规划；只有主动进入设置数据页时才加载兼容工具；历史数据与访问能力保持完整。
