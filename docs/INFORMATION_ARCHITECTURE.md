# KyStudy 页面信息架构与低保真线框

| 项目     | 内容                     |
| -------- | ------------------------ |
| 版本     | v0.2                     |
| 状态     | 已确认产品方向，等待实施 |
| 更新时间 | 2026-07-28               |

## 1. 设计目标

KyStudy 的界面必须减少用户思考下一步的次数。一级页面围绕用户行为组织，不围绕工程模块、数据库对象或 AI 能力组织。

默认界面遵循：

- 当前行动优先于历史数据；
- 目标和规则优先于逐日任务录入；
- 自动继承优先于重复选择；
- 三个明确按钮优先于复杂表单；
- 需要时展开优先于一次展示全部字段；
- 本地规则优先于 AI；
- 异常才打断，正常流程保持连续。

## 2. 全局导航

### 2.1 一级导航

```text
KyStudy

今日
计划
习题册
错题
资料

────────
设置
```

一级导航固定为 5 项。以下能力不再拥有一级入口：

- AI 对话；
- 学习分析；
- 思维导图；
- 数据与备份；
- 日程与规划室的重复入口。

### 2.2 设置

侧栏底部使用齿轮按钮进入设置，按以下顺序分组：

1. 学习与考试：考试日期、时区、学习日、休息日；
2. AI：Provider、模型、API Key、Token 预算；
3. 数据：备份、恢复、诊断和本地存储；
4. 应用：外观、快捷键和基础偏好。

Schema、运行状态和内部恢复信息只在诊断区域显示，不进入学习页面。

### 2.3 页面记忆

- 应用默认打开“今日”；
- 正常退出时可以记住合法一级页面；
- 从错题或计划完成操作后返回原上下文；
- 任何深层页面都提供清晰返回路径，不依赖浏览器后退。

## 3. 今日

### 3.1 页面结构

```text
┌──────────────────────────────────────────────────────┐
│ 距离考研还有 147 天                    [打开月历]     │
├──────────────────────────────────────────────────────┤
│ 今日计划                                             │
│ ○ 数学真题 · 第 4 套 · 第 1/2 个学习日              │
│ ○ 英语阅读 · 2 篇                                    │
│                                                      │
│ 今日错题                                             │
│ 高等数学                         0 / 5    [开始]      │
│ 线性代数                         0 / 5    [开始]      │
├──────────────────────────────────────────────────────┤
│ 今天完成 0 / 4                                      │
└──────────────────────────────────────────────────────┘
```

### 3.2 交互

- 计划事项可以直接完成、顺延或跳过；
- 错题方案点击“开始”进入卡片复习；
- “打开月历”切换到计划页并保持当前月份；
- 倒计时只显示最近的主要考试；
- 今日无内容时显示休息或空状态，不展示空图表。

### 3.3 不允许出现

- 预计分钟、实际分钟和计时器；
- 任务优先级；
- AI Provider 和 Token 信息；
- 复杂统计图；
- Workspace 和数据库状态；
- 错题筛选表单。

## 4. 计划

### 4.1 默认月历

```text
┌──────────────────────────────────────────────────────────┐
│ 计划       [‹]  2026 年 8 月  [›]  [回到今天] [新建计划]│
│ 显示：[数学真题 ×] [英语阅读 ×]             [筛选]      │
├──────────────────────────────────────────────────────────┤
│ 周一    周二    周三    周四    周五    周六    周日    │
│  27      28      29      30      31       1       2      │
│                                          真题1    休息   │
│   3       4       5       6       7       8       9      │
│ 真题2   英语2篇  真题3                    周复盘   休息   │
│ ...                                                      │
├──────────────────────────────────────────────────────────┤
│ 8 月 5 日                                                │
│ 数学真题 · 第 3 / 20 套 · 第 1/2 个学习日               │
└──────────────────────────────────────────────────────────┘
```

### 4.2 月份切换

- 左右按钮切换月份；
- “回到今天”恢复当前月并选中今天；
- `PageUp` 和 `PageDown` 可作为桌面快捷键；
- 月份标题和日期使用工作区时区；
- 周起始日默认周一，可在设置中调整。

### 4.3 日期格

- 今天使用圆形或描边高亮；
- 休息日使用低对比背景；
- 考试日期使用独立标记；
- 已完成事项降低饱和度并显示勾选；
- 预计超期只使用小型警示，不整格染红；
- 每格最多显示 3 项，更多显示“还有 N 项”；
- 多学习日事项使用连续色条或一致颜色；
- 月历绝不显示错题队列。

### 4.4 计划可见性

每份计划提供“在月历中显示”开关。顶部筛选器支持临时显示或隐藏计划，选择持久化到本地偏好。

隐藏不等于暂停：隐藏计划仍进入“今日”，也继续计算进度。

### 4.5 事项弹出卡片

```text
数学真题 · 第 4 / 20 套
8 月 12 日—8 月 13 日

[完成] [顺延] [跳过]
[查看整个计划]
```

- 不支持拖拽改期；
- 完成、顺延和跳过后提供短时撤销；
- 单次操作不改变整个规则；
- 未完成需要调整后续时，进入“顺延后续计划”预览。

### 4.6 计划详情

计划详情只显示：

- 名称、数量、节奏和日期；
- 完成数量与百分比；
- 下一项和预计完成日期；
- 是否预计超期；
- “在月历中显示”；
- 修改规则、顺延后续和归档。

阶段、版本、时长统计、任务来源关系和内部历史默认隐藏。

### 4.7 新建计划

```text
┌──────────────────────────────┐
│ 新建周期计划                 │
│ 做什么      [数学真题      ] │
│ 总数量      [20] [套]        │
│ 开始日期    [今天]           │
│ 截止日期    [12月21日]       │
│ 节奏        每 [2] 学习日 1套│
│                              │
│ [预览月历]                   │
│                              │
│ ───── 或 ─────               │
│ [AI 帮我整理]                │
└──────────────────────────────┘
```

预览必须显示预计完成日期、总学习日、休息日跳过结果和截止冲突。确认前不写入正式计划。

### 4.8 AI 帮我整理

AI 流程留在新建计划的抽屉或子页面：

```text
选择资料 → 对话 → 1～5 张计划卡片 → 单独修改/接受 → 月历预览
```

不显示独立聊天主页面，不允许 AI 回答直接写入日历。

## 5. 习题册

### 5.1 页面结构

```text
主页面：科目 → 练习册 → PDF 分段与索引进度

题目索引窗口：筛选与题目列表 │ 当前题目卡片
                              │ 上一题 / 下一题
                              │ 编辑 / 调整区域 / 删除
```

题目不在主页面连续堆放。浏览、编辑和前后题切换都在独立窗口完成；大列表使用独立滚动区，窄窗口改为上下布局。

### 5.2 框选保存

```text
选择已建立的科目 / 练习册 / PDF 分段
→ 填写章节、篇章、题型与题号
→ 在原 PDF 中框选遗漏题目
→ 创建题目卡片
```

- 手动补题必须归入半自动解析已经建立的 PDF 分段；
- 从题目卡片进入时，可移动、缩放、移除已有区域，也可追加遗漏区域；
- 元数据校对在题目浏览窗口内完成，不重新选择 PDF；
- 删除题目需要二次确认，并同步更新分段题目数。

### 5.3 批量分类

现实做题结果继续通过“快速登记做题”按范围与题号批量记录；题目结构校对保持逐题完成，避免一次误改大量索引。

## 6. 错题

### 6.1 首页

```text
错题

复习方案
┌──────────────────────────────┐
│ 高等数学每日错题       0 / 5 │
│ 660题、880题                  │
│ 选择2 / 填空1 / 解答2        │
│ [开始] [本次选择习题册] [编辑]│
└──────────────────────────────┘

┌──────────────────────────────┐
│ 线性代数每日错题       0 / 5 │
│ 李永乐线性代数                │
│ [开始] [编辑]                │
└──────────────────────────────┘

[新建复习方案] [临时复习]
```

不在首页展示后台评分、长列表统计和复杂积压图表。

### 6.2 复习方案编辑

字段顺序：

1. 名称；
2. 科目；
3. 习题册范围；
4. 每日总量；
5. 各题型数量；
6. 启用状态。

界面实时显示各题型合计，合计不等于每日总量时提供就地错误提示。

### 6.3 卡片复习

```text
┌─────────────────────────────────────────────────────┐
│ 《660题》 · 高等数学 · 选择题 · 第 42 页            │
├─────────────────────────────────────────────────────┤
│                                                     │
│                 题目图片区域                        │
│              可缩放、滚动、拖动                    │
│                                                     │
├─────────────────────────────────────────────────────┤
│ [AI 解析]                              第 2 / 5 题   │
│                                                     │
│ [不会]              [模糊]              [掌握]      │
└─────────────────────────────────────────────────────┘
```

- 点击图片打开轻量大图弹窗，不打开完整 PDF；
- 三个反馈按钮是唯一正式反馈；
- 从“今日”开始或继续错题时直接打开复习窗口，不要求在错题页二次点击；
- 长题目滚动时三个反馈按钮固定在复习窗口底部；
- 提交后自动进入下一题；
- 支持键盘 `1 / 2 / 3`；
- 提交后短时显示“撤销上一次反馈”；
- 耗时、答案笔记和人工优先级不出现。

### 6.4 完成页

```text
今天的高数错题已完成 5 / 5

掌握 2    模糊 1    不会 2

[重看今天不会的题（2）]    [结束复习]
```

“重看”是可选巩固，不改变正式反馈和下一次到期时间。

### 6.5 队列说明

当实际题型与方案不同，只显示一句可执行说明：

```text
填空题今日没有足够到期题，已补入 1 道解答题。
```

昨日未完成题使用“顺延”标识并固定在队首，但不展示内部分数。

## 7. 资料

### 7.1 内容类型

- 普通 PDF；
- 图片；
- 规划参考资料；
- 思维导图源文件与本地副本。

资料页提供导入、搜索、用途筛选和打开，不承担计划、错题与 AI 的全部操作。

### 7.2 思维导图入口

结构化导图在资料列表中标记类型，点击后进入导图阅读器。图片和 PDF 导图仍使用普通资料查看器。

### 7.3 导图阅读器

```text
┌─────────────────────────────────────────────────────┐
│ 408 知识结构     [搜索] [适应画布] [撤销] [重做]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│                   导图画布                          │
│                                                     │
├─────────────────────────────────────────────────────┤
│ 原文件已保留 · 当前编辑本地副本                    │
└─────────────────────────────────────────────────────┘
```

节点操作仅包括修改文字、新增、删除、移动、排序和折叠。样式、附件、掌握度、重要度和知识关联不出现。

## 8. 全局弹窗与状态

### 8.1 弹窗

- 大图、确认和简短编辑使用弹窗或抽屉；
- 弹窗必须有明确标题、关闭按钮和键盘关闭；
- 关闭前存在未保存输入时提示；
- 弹窗内部滚动不得带动背景页面。

### 8.2 异步状态

- 保存、生成和 AI 调用显示明确进行中状态；
- 状态变化使用可访问的礼貌播报；
- 错误信息包含下一步动作，不暴露内部 Provider、SQL、路径和 JSON；
- 破坏性操作需要确认或撤销窗口。

### 8.3 输入与键盘

- 所有输入有可见标签；
- 三个错题反馈从左到右为“掌握、模糊、不会”，快捷键依次为 `1 / 2 / 3`；
- 今日错题默认跨启用方案连续进行，方案管理保留为次级视图；
- 月历与导图交互有清晰焦点状态；
- 图标按钮有可访问名称；
- 中文输入法组合输入期间不触发快捷键。

## 9. 响应式策略

- 首要目标是普通 Windows 笔记本宽度；
- 月历宽屏显示事项标题，窄屏显示色点与数量；
- 选中日期详情在宽屏位于右侧，窄屏位于月历下方；
- 习题册始终优先保证 PDF 阅读宽度；
- 错题卡片在窄窗口中保持三个反馈按钮可见；
- 导图画布占据主要区域，工具栏可收起；
- 核心操作不得依赖鼠标悬停。

## 10. 跨页面主流程

### 10.1 创建并执行周期计划

```text
计划 → 快速创建或 AI 整理 → 月历预览 → 确认
→ 今日执行 → 完成/顺延 → 计划百分比更新
```

### 10.2 习题册到每日错题

```text
习题册 PDF → 自动识别科目分段 → 确认科目与练习册
→ 自动建立章节/篇章/题型/题号索引 → 批量登记现实做题结果
→ 做错与不全对题进入复习方案候选池 → 今日错题卡片 → 三按钮反馈
→ 本地算法安排下一次
```

### 10.5 题库到拼卷

```text
多个勾选科目 → 练习册 → 章节/篇章 → 题型与状态筛选
→ 本地加权抽题 → 窗口内连续作答 → 批量保存结果
→ 更新当前状态、历史记录与错题候选
```

### 10.3 资料到计划

```text
资料 → 新建计划中的 AI 帮我整理 → 选择资料并对话
→ 少量计划卡片 → 单独接受 → 月历预览 → 确认
```

### 10.4 导图浏览与轻量修改

```text
资料 → 导入结构化导图 → 保留原文件 → 创建本地副本
→ 浏览/搜索/基础编辑 → 自动保存副本
```

## 11. 旧功能过渡

第一阶段只从默认界面隐藏以下旧入口，不删除数据：

- 独立日程页；
- 独立规划室；
- 独立思维导图主菜单；
- 独立分析页；
- 独立 AI 设置主菜单；
- 独立数据主菜单；
- 任务详情中的时长、优先级、拆分和复杂历史默认入口。

设置、备份和恢复仍可访问。旧版详细规划兼容工具统一收在“设置 → 数据”并按需加载，不出现在计划主页面。旧数据继续用于兼容、恢复和必要的进度计算。新体验通过验收后再决定永久清理范围。

“今日”不再读取或展示旧版详细日程任务，只显示周期计划事项与错题。旧日程可从“设置 → 数据 → 查看旧日程”直接进入。

## 12. 原型验收问题

1. 用户能否在 10 秒内找到今日计划和错题入口？
2. 用户能否在 30 秒内建立一个数量型周期计划？
3. 月历是否清楚展示一个月的计划，同时不出现错题噪声？
4. 用户能否理解“隐藏计划”不会暂停计划？
5. 框选题目后，识别正确时是否只需一次保存？
6. 低置信度题型是否只增加一次明确选择？
7. 用户能否不打开完整 PDF 完成一轮错题复习？
8. 顺延题是否固定在队首且不使每日总量翻倍？
9. 用户是否只需三个按钮即可完成正式反馈？
10. AI 调用是否始终由用户主动触发，并明确展示外发内容？
11. 导图是否足以浏览和简单修正，又没有完整编辑器的负担？
12. 旧工作区和备份能否在整改后继续打开和恢复？
