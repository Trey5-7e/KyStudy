# KyStudy v0.1.5 发布说明

v0.1.5 是一次以界面体验、做题与错题复习为主的稳定功能更新。本版本不包含仍在设计中的通用 Agent Harness，也不包含“资料研读”、错题诊断 Agent 或练习草案 Agent。

## 主要更新

### 错题本与复习

- 新增独立错题本工作台，支持概览、科目/题型/错误频次筛选、沉浸式分栏浏览和题目预览。
- 支持错题批量管理、归档、PDF 错题卷导出、快速掌握状态调整和单题特训。
- 新增错题标签编辑与批量标签操作，并提供基于艾宾浩斯遗忘曲线的排序参考。
- 新增题目作答轨迹，按时间展示作答结果、复习反馈、耗时和下次复习日期。
- 连续复习改进为直接显示解析和反馈操作，新增完成总结、错题重试和快速再次复习。
- 修复今日错题任务在部分情况下被错误归零，以及从今日页面进入复习时定位不准确的问题。

### 做题本与组卷

- 快速记录支持保存后继续、直接入口和已有作答状态颜色。
- 组卷支持完成总结、错题重做、继续下一批，并避免下一批重复抽取上一批题目。
- 新增做题本内错题特训、手动索引快捷操作和题目连续提取体验。
- 修复手动索引可能覆盖分段题目的问题，并补充题目恢复能力。
- 改进题目导航、题区校对、分段管理、导出和辅助解析入口。

### 界面与操作效率

- 更新侧边导航、移动端底部导航和主要页面的响应式布局。
- 新增全局命令面板，支持 `Ctrl+K` 快速跳转页面和常用操作。
- 统一按钮、对话框、工具栏、卡片和 Material Symbols 图标样式，减少图标字体闪烁。
- 优化今日、周期计划、资料库、PDF 阅读器、思维导图、模型设置和复习方案页面。
- 新增显示密度设置，适应不同屏幕和信息密度偏好。

### AI 对话衔接

- 题目辅助解析结果可以带着题图和已有解析进入普通 AI 对话继续讨论。
- 保留 v0.1.4 的普通 AI 对话、模型/API 管理和资料附件能力。

## 发布边界

- 本版本不包含 Agent Harness、资料研读模式、Agent Run/Grant/Step/Event 数据表或相关命令。
- 数据库 Schema 沿用 v0.1.4 的版本，不新增 Harness 迁移。
- OCR 组件继续使用独立的 `ocr-v0.1.4` 发布资产。
- Windows 安装版和便携版均由 GitHub Actions 构建；更新器资产使用项目既有签名配置。

## 升级建议

- 升级前建议在“设置 → 数据”中创建完整备份。
- 便携版请保留原 `data` 目录，替换程序时不要删除或覆盖该目录。
- 从 v0.1.4 可以直接升级到 v0.1.5。
