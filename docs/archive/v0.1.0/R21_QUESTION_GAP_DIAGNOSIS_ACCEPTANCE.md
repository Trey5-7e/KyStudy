# R21 题目缺漏诊断集中验收

## 1. 发现缺失题号

1. 打开“习题册 → 浏览题目索引”。
2. 点击题目数量旁边的“诊断缺漏”；如果当前筛选范围存在问题，按钮上应显示诊断数量。
3. 诊断窗口应分别统计“可能缺题”和“需要检查”。
4. 在同一 PDF 分段、章节、篇章和题型内，如果题号从 3 跳到 5，应显示“可能缺少第 4 题”，并说明建议检查的 PDF 页附近位置。
5. 切换浏览器的科目、练习册、章节、篇章或题型筛选后重新诊断，结果应只针对当前筛选范围。

## 2. 从诊断直接补题

1. 在缺失项上点击“补第 4 题”。
2. 补题窗口应自动定位到后一题所在页，并继承科目、练习册、章节、篇章和题型。
3. 题号和卡片标题应预填为第 4 题；框选 PDF 中的实际题目后保存。
4. 返回浏览器后，新题应位于第 3 题和第 5 题之间。
5. 再次运行诊断，刚刚处理的第 4 题缺漏提示应消失。

## 3. 防止误补

1. 连续出现相同题号时，应显示“重复题号”，只提供“定位检查”，不直接创建题目。
2. 题号发生过大的跳跃时，应显示“异常跳号”，提醒先确认是否更换小节或存在批量缺漏。
3. 当前范围题号连续时，应显示“当前范围未发现明显缺漏”。
4. 非纯数字题号不参与自动连续性判断，仍保留人工抽查提示。

该诊断只读取本地题目索引，不调用 AI、不消耗 Token。页面存在大块空白本身不会被视为缺题，最终仍由用户查看 PDF 并框选确认。
