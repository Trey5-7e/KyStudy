# R64 思维导图空白页与父节点返回修复验收

R64 修复了“选中节点后再次进入同一思维导图出现空白页”的问题，并增加预览导航中的父节点返回入口。

## 1. 根因与修复

旧版在选中节点后调用 MindElixir `focusNode`，该 API 会把画布内部数据切换成当前节点的子树。再次选择同一导图时，应用仍会尝试在子树中查找原根节点；MindElixir 的查找异常未被处理，造成页面空白。

本轮改为：

- 预览始终保留完整导图数据；节点选择只执行选中和滚动定位，不再切换内部树；
- 节点查找增加安全保护，折叠分支未渲染时不会让应用崩溃；
- 选中非根节点时显示“返回父节点”，点击后选中并定位到直接父节点；
- 正式导图数据、节点层级和右侧编辑面板不受影响。

## 3. 桌面验收（由用户执行）

1. 使用本批最新 Release 启动应用，进入“资料 → 思维导图”。
2. 点击一个子节点，再点击左侧当前思维导图；确认页面仍正常显示，不出现全屏空白。
3. 选中一个子节点，点击画布顶部“返回父节点”；确认当前节点回到直接父节点，导图数据没有被修改。
4. 重复选择不同节点、切换不同思维导图，再返回原导图；确认画布、搜索、缩放和平移仍可用。

本轮不启动 Release EXE，也不替代桌面人工验收。
