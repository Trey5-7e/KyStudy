## 1. 本批交付

1. 一级导航从 10 项收缩为今日、计划、习题册、错题、资料；
2. 设置移动到侧栏底部，并聚合学习与考试、AI、数据三个分类；
3. 今日页替换为简洁概览，不再显示 Workspace、Schema、优先级、预计时长和复杂任务表单；
4. 今日页直接显示已有今日任务和当前错题队列摘要；
5. 今日任务可以直接完成或重新打开；
6. 旧日程保留为计划页中的兼容入口，不再占据一级导航；
7. 旧 AI、数据、导图和分析页面代码仍保留，但从默认主导航隐藏；
8. 旧导航记忆自动迁移到对应新页面；
9. 页面状态写入 URL Hash，支持浏览器式前进、后退和刷新；
10. AI、备份和运行诊断改为打开设置后按需加载，不再影响首页启动。

## 2. 本批明确不包含

- 新月历和周期计划规则，属于 R4；
- 新错题标签、复习方案和顺延算法，属于 R2；
- 图片卡片式三按钮复习，属于 R3；
- Mind Elixir 和导图资料入口，属于 R5；
- 情境化 AI 规划与图片题目解析，属于 R6；
- 全局学习日和休息日的新数据结构，后续随 R2/R4 增量加入。

因此，本批“计划”和“错题”主页面内部仍主要使用已有 M6、M9、M12、M13 能力；R1 只完成产品外壳和默认路径瘦身。

## 5. 今日

进入“今日”：

- [ ] 页面顶部显示今天的中文日期；
- [ ] 不显示 Workspace、Schema、运行平台或数据库状态；
- [ ] 不显示快速新建任务的标题、科目、时长和优先级表单；
- [ ] 今日计划卡片只显示任务标题、完成状态和完成数量；
- [ ] 今日错题卡片显示当前已完成数量和开始/继续入口；
- [ ] “打开计划”进入计划页；
- [ ] “开始复习”或“继续复习”进入错题页；
- [ ] 没有错题时，“打开习题册”进入习题册页；
- [ ] “刷新今日”可以重新读取任务和错题状态。

任选一条未完成的今日任务：

1. 点击任务；
2. 确认任务变成已完成并显示勾选；
3. 再次点击；
4. 确认任务恢复为待完成；
5. 确认页面显示可读的保存结果提示。

如果今天没有任务，只需确认空状态和“新建或查看计划”按钮，不必为了测试创建无用任务。
