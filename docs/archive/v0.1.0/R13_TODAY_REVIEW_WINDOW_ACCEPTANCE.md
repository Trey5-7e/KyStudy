## 本轮调整

- “今日 → 开始今日错题”先准备全部启用方案，然后直接打开连续复习窗口；
- “今日 → 继续今日错题”直接定位第一道未完成题，不再需要在错题页二次点击；
- 休息日和已全部完成时只进入错题概况，不弹出无意义的作答窗口；
- 离开错题页后会清除本次自动打开请求，之后从侧栏普通进入错题页不会反复弹窗；
- 大尺寸复习窗口中的三个反馈按钮使用吸底操作栏，滚动长题目或 AI 解析时仍保持可见；
- 快捷键继续固定为 `1 = 掌握`、`2 = 模糊`、`3 = 不会`。

## 集中人工验收

1. 回到“今日”，点击“开始今日错题”或“继续今日错题”，确认直接出现复习窗口；
2. 关闭复习窗口，确认停留在错题页并能看到“继续今日错题”入口；
3. 切换到其他页面，再从侧栏普通点击“错题”，确认不会无故自动弹窗；
4. 在复习窗口展开较长的 AI 解析或缩小窗口并向下滚动，确认三个反馈按钮保持在底部可见；
5. 分别按 `1 / 2 / 3`，确认保存掌握、模糊、不会并自动进入下一题；
6. 将今天设为休息日或完成全部题后从“今日”点击查看，确认只显示错题概况。

通过标准：从“今日”开始复习只需一次点击；自动打开仅消费当前一次导航意图；长内容不会把核心反馈操作推离窗口。
