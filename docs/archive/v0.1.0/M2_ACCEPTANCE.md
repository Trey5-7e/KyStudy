## 数据与安全边界复核

- WebView 只能调用 `generate_handler!` 注册的白名单 Command；
- 前端不能传入 SQL、数据库路径、任意存储键或自定义目标状态；
- 任务历史只返回类型化快照，不返回 `before_json` / `after_json` 原文；
- 文件选择路径只在 Rust 侧使用，资料和备份 DTO 不返回绝对路径；
- 任务拆分、状态变化和历史写入使用 SQLite 事务；
- schema v4 只新增 `study_session` 表，不删除或批量改写旧数据；
- v2/v3 备份副本升级到 v4、Blob 完整性及科目/任务/历史/学习记录恢复均有自动测试；
- AI、OCR、PDF 阅读器和思维导图仍未进入正式业务依赖，不会产生 Token 消耗。

## 下一里程碑输入

下一阶段建议先规划 M3“规划资料阅读与个人计划草案”，复用现有本地 Blob、备份和日程能力，按以下顺序推进：
