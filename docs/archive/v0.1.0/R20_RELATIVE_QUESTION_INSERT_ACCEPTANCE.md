# R20 浏览索引时相对补题验收

## 1. 在当前题后补题

1. 打开“习题册 → 浏览题目索引”，选择漏题位置前面的那道题。
2. 点击题目右上角“补题 → 后面插入”。
3. 确认补题窗口已经继承科目、练习册、章节、篇章和题型，并自动打开当前题所在的 PDF 页。
4. 在 PDF 上框选遗漏题目，输入题号；卡片标题应自动生成，仍可手动修改。
5. 点击“插入题目卡片”。返回索引后，新题应自动成为当前题，并出现在原题后面。

## 2. 在当前题前补题

1. 选择漏题位置后面的那道题，点击“补题 → 前面插入”。
2. 框选并保存遗漏题目。
3. 返回后确认新题位于原题之前，其余题目的相对顺序保持不变。

## 3. 异常与持久化

1. 不框选区域、题号为空或标题为空时，不允许保存。
2. 关闭补题窗口后重新打开题目索引，确认插入顺序保持不变。
3. 对新补的题目执行“调整题目区域”“编辑题目”和“删除题目”，确认均可正常使用。

相对补题不会要求重新选择 PDF 或寻找科目分段；插入题目和后续顺序移动在同一个本地数据库事务中完成。
