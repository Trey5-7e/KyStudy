## 本轮调整

- “今日计划”只展示新的周期计划事项，不再混入旧版详细日程任务；
- 首页不再调用旧任务列表接口，减少一次启动数据请求和一套错误状态；
- 今日页面模块从约 9.0 KB 降为约 7.6 KB；
- 删除只服务于首页旧任务排序与计数的两个无引用纯函数及对应测试；
- 旧任务表、历史记录、统计与兼容页面全部保留；
- “设置 → 数据 → 历史详细规划数据”新增“查看旧日程”直接入口，无需先选择旧规划。

## 集中人工验收

1. 打开“今日”，确认今日计划中只出现周期计划事项；
2. 完成或恢复一项周期计划，确认首页数量和状态立即更新；
3. 若数据库中存在旧版日程任务，确认它们不再混入首页；
4. 打开“设置 → 数据”，点击“查看旧日程”，确认旧任务仍可读取和维护；
5. 返回“今日”，确认周期计划与今日错题入口正常；
6. 断网启动，确认首页仍可读取本地周期计划和错题。

通过标准：日常首页不再要求用户理解旧任务体系；旧任务数据不删除，并且仍有明确的低频兼容入口。
