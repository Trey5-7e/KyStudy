## 2. 人工验收前准备

1. 不需要开启网络，也不需要配置真实 API Key；
2. 先在“数据与备份”创建一份完整备份；
3. 建议准备少量可识别记录：一个有预计时长的任务、一条实际学习记录、一题正确作答、一题错误作答，以及一条今日错题复习反馈；
4. 测试时不要直接修改 SQLite。若已有真实学习数据，可以只核对现有记录，无需额外造数据；
5. 关闭旧 KyStudy 窗口后再启动本次统一 `kystudy.exe`。

## 3. 人工综合 Smoke

### A. 启动、导航与离线边界

1. 启动应用，确认运行状态仍为 `Schema v12`，原有日程、资料、导图、题目、错题、规划和 Provider 数据存在；
2. 确认左侧主菜单出现“学习分析 / 进度与薄弱点”，其他菜单顺序和功能不受影响；
3. 进入“学习分析”，确认页面能正常加载且不要求联网、不弹出 AI 外发预览、不增加 AI 调用记录；
4. 切换到其他页面后重新进入，确认页面会根据最新正式记录重新统计。

### B. 周期与上一周期

5. 依次点击 `7 天`、`28 天`、`90 天`，确认选中状态、当前日期范围和上一周期日期范围同步变化；
6. 核对“最近 7 天”包含今天和之前 6 天，上一周期紧接其前且也是 7 天；
7. 快速连续切换周期时页面不崩溃、不混入上一种周期的数据；
8. 某项当前或上一周期没有分母数据时，完成率/正确率/复习率显示“—”，而不是 0%。

### C. 任务与学习时长

9. 核对周期内正常任务的总数与完成数；已取消任务和回收站任务不得计入；
10. 核对任务完成率为“已完成任务 / 有效任务”，并按整数百分比显示；
11. 核对计划时长来自有效任务的预计分钟，没有预计时长的任务不凭空增加分钟；
12. 核对实际学习来自“开始学习/学习记录”产生的正式时长，而不是任务预计时长；
13. 确认“逾期任务”显示当前未完成逾期量，点击“查看日程”可以进入日程页；
14. 在日程页新增或完成一项测试任务、记录一次学习，再回到分析页，确认重新进入后数据更新。

### D. 作答、错题与复习

15. 核对题目正确率只使用真实的正确/错误/不确定作答记录；没有作答的题不进入分母；
16. 核对当前活跃错题、到期复习和今日队列剩余数量；三个值语义不同，不要求彼此相等；
17. 点击“进入错题复习”“处理复习”“继续复习”，均能进入错题复习页；
18. 完成一条今日复习反馈后重新进入分析页，确认今日队列剩余减少，周期复习完成数相应增加；
19. 若存在累计错误至少 2 次或连续未掌握的活跃错题，确认“反复出错题目”显示题目、资料、累计错误、连续未掌握和下次日期；
20. 已放入题目回收站的题不得继续影响正确率、活跃错题和反复出错题列表。

### E. 科目与知识节点

21. 核对“科目投入与任务完成”中的任务数、完成数和实际时长；无科目的正式记录应进入“未分类”；
22. 已归档科目的历史任务或学习记录仍应按原科目显示，不丢失历史归属；
23. 对关联到思维导图节点的题目记录作答后，确认对应节点显示周期正确率和当前活跃错题数；
24. 同一道题关联多个知识节点时可以分别影响节点洞察，但不得使顶部总作答次数重复增加；
25. 点击“打开思维导图”可以进入思维导图页。

### F. 每日图表与 Token

26. 核对每日柱状图中计划与实际投入的相对高低；28/90 天可以横向滚动且日期不重叠；
27. 全部分钟为 0 时图表保持稳定高度，不出现 `NaN`、无限高度或布局跳动；
28. 核对 AI Token 为周期内实际输入与输出用量；缓存命中不新增 Token；
29. 点击“查看预算与调用记录”可以进入 AI 设置页，页面中仍不显示请求正文、路径、SQL、内部 ID 或 Provider 原始错误。

### G. 窄窗口与恢复一致性

30. 把窗口逐步缩窄，确认周期按钮、四项摘要、积压入口、科目、知识节点和错题列表不重叠，长文字能换行；
31. 关闭并离线重启应用，确认分析仍可加载，统计值与重启前一致；
32. 将验收前的完整备份恢复到新目录，打开恢复副本并进入学习分析，确认相同周期的统计与原工作区一致；
33. 确认分析本身没有新增数据库迁移、学习记录、错题、任务、AI 调用或 Token 消耗。

## 4. 通过标准

A～G 的 1～33 全部符合即可回复：`M11 全部通过`。如果某项失败，请提供步骤编号、页面稳定提示和不含隐私的截图；不要展示 API Key、完整资料原文、文件路径或 Provider 原始错误。

## 5. 本批次明确不验收

- M9 AI 对话体验改进；
- OCR、扫描 PDF、图片内容或题目区域识别；
- 自动把计划阶段换算为任务进度；
- AI 自动调整日程、自动写入正式数据或预测考试结果；
- 自定义统计公式、导出报表、批量操作和跨设备同步。
