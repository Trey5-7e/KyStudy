## 1. 本批为什么合并

根据用户要求，R3“图片优先错题卡片”和 R4“周期计划与月历”不再拆成多个小版本。本批完成全部实现、自动回归和 Release 构建后，只进行这一次集中验收。

## 2. 本批交付

### 2.1 图片错题

- 直接从本地习题册 PDF 裁剪已保存题目区域；
- 多区域按原顺序展示，不跳转完整 PDF；
- 点击图片打开大图，可缩放、滚动和拖动；
- 不会、模糊、掌握 3 个大按钮；
- 当前聚焦方案支持 `1 / 2 / 3` 快捷反馈；
- 保存后自动进入下一题；
- 可撤销上一题，并恢复此前复习状态；
- 完成页显示进度，可集中重看当天反馈为“不会”的题；
- 图片按当前题加载，不一次渲染整本 PDF 或全部队列。

### 2.2 周期计划与月历

- 极简表单只填写事项、总数量、单位、开始日、截止日和每个单位所需学习日；
- 默认按固定学习日节奏连续安排；
- 可选均匀分布到截止日；
- 一份内容占多个学习日时，在月历中显示为连续事项；
- 每周休息日可直接在计划页设置，并与错题共用；
- 休息日变化后自动重排未完成事项，已完成历史不改写；
- 苹果日历风格的单月视图、上月、下月、今天和选中日期详情；
- 点击月历事项即可完成或重新打开；
- 每份计划可以显示或隐藏于月历；
- 从选中日期开始，一键顺延后续未完成事项 1 个学习日；
- 超过截止日期时保留原节奏，并提供加快节奏或减少数量建议；
- 每份计划只统计完成数量、百分比和预计完成日期；
- 今日页合并显示周期计划事项，并可以直接完成；
- 旧版详细规划与资料对话收进折叠兼容入口，默认不再干扰快速规划。

### 2.3 统一弹窗编辑

- 默认页面只用于浏览、筛选、进度和快捷操作；
- 新建、编辑周期计划使用独立弹窗；
- 新建、编辑错题方案使用独立弹窗；
- 新建题目和题目详情、OCR、作答管理使用独立弹窗；
- 新增、编辑 API Provider、API Key 和 Token 预算使用独立弹窗；
- 旧版详细规划从页面折叠区改为弹窗兼容入口；
- 弹窗支持 Esc、点击遮罩、窄窗口滚动和背景交互隔离；
- 内容发生变化后关闭弹窗，会先确认是否放弃修改。

## 3. 本批不包含

- AI 图片解析和标准答案生成，属于 R6；
- AI 直接确认周期计划，属于 R6；
- 删除旧计划、旧任务或旧错题数据；
- 云同步、账户和移动端。

## 4. 启动准备

1. 关闭旧 `kystudy.exe`；
2. 启动 `F:\develop\KyStudy\src-tauri\target\release\kystudy.exe`；
3. 直接使用现有工作区，不创建隔离副本；
4. 准备一份已有到期题目的错题方案；
5. 该题至少应有一个来自正常 PDF 的框选区域；
6. 本批全部基础功能均可离线测试。

首次启动会自动从 v15 升级到 v16。原有习题册、题目、复习方案、计划和历史记录都应保留。

## 5. 图片错题集中验收

1. 进入“错题”，打开一份今日有到期题的方案；
2. 点击“开始今天的复习”；
3. 确认题目卡片优先显示 PDF 裁剪图片；
4. 多区域题目应显示多张图片，顺序与习题册中保存顺序一致；
5. 点击图片，确认大图弹窗打开；
6. 调整缩放滑块，并拖动图片查看边缘；
7. 关闭大图后，点击当前方案卡片使其获得焦点；
8. 按 `1`，确认按“不会”保存并自动进入下一题；
9. 按 `2`，确认按“模糊”保存；
10. 按 `3`，确认按“掌握”保存；
11. 多份方案同时存在时，确认快捷键只提交当前聚焦的方案；
12. 点击“撤销上一题”，确认上一题重新成为当前题；
13. 再次完成全部题目，确认出现完成页；
14. 如果当天存在“不会”的题，点击“重看不会的题”，使用上一题、下一题浏览；
15. 重看操作不应新增正式反馈或改变完成数量。

如果图片失败，请确认原 PDF 仍在 KyStudy 资料库中，并记录题目是否包含多个区域。

## 6. 快速创建周期计划

进入“计划”，设置每周休息日，例如周日，然后创建：

```text
事项：数学模拟卷
总数量：20
单位：套
开始日期：今天
截止日期：考试前一天
每个单位占用学习日：2
排程方式：保持节奏
显示在月历：是
```

验收：

- [ ] 不需要创建阶段、优先级、预计时长或逐日任务；
- [ ] 点击“生成并保存”后直接出现完整计划；
- [ ] 每套占据连续 2 个学习日；
- [ ] 休息日不被计入这 2 个学习日；
- [ ] 计划卡显示完成数量、百分比和预计完成日期；
- [ ] 关闭并重启后计划仍然存在。

## 7. 月历

1. 使用上月、下月切换月份；
2. 点击“今天”返回当前月份和日期；
3. 确认非本月日期弱化显示；
4. 确认多学习日事项在连续日期中出现；
5. 点击一个日期，右侧或下方显示当天事项；
6. 点击事项，确认变为已完成；
7. 再次点击，确认恢复为未完成；
8. 点击计划的“从月历隐藏”，确认月历事项消失但计划和进度仍保留；
9. 点击“显示在月历”，确认事项恢复。

## 8. 今日页

1. 创建一份覆盖今天的周期计划；
2. 返回“今日”；
3. 确认“今日计划”中出现周期事项；
4. 点击即可完成；
5. 返回计划页，确认完成数量和百分比同步更新；
6. 原有旧任务仍可读取和完成。

## 9. 顺延与历史保护

1. 先完成周期计划中的第 1 个事项；
2. 在月历选择一个包含后续未完成事项的日期；
3. 点击计划卡中的“从选中日期顺延 1 天”；
4. 确认选中日期之后的未完成事项顺延 1 个学习日；
5. 确认休息日仍被跳过；
6. 确认已完成的第 1 个事项日期和完成状态没有改变；
7. 如果顺延造成超期，确认计划卡出现截止日期警告。

## 10. 超期与重新规划

创建一份故意无法按期完成的计划，例如在 5 个学习日内完成 20 套、每套 2 个学习日。

- [ ] 系统允许保存原节奏，不擅自修改目标；
- [ ] 计划卡明确提示预计超过截止日期；
- [ ] 点击“改为每 N 个学习日”后打开带建议值的重新规划表单；
- [ ] 点击“减少为 N 套”后打开带建议数量的表单；
- [ ] 用户仍需点击“生成并保存”才正式修改；
- [ ] 新总量不能少于已经完成的数量。

再创建或编辑一份计划，将排程方式改成“均匀分布到截止日”，确认事项分散在开始日与截止日之间。

## 11. 休息日联动

1. 在计划页修改休息日并保存；
2. 确认周期计划未完成事项重新排程；
3. 确认已完成事项不改变；
4. 进入“错题”，确认休息日设置一致；
5. 将今天设为休息日时，错题仍不生成新队列。

## 12. 兼容、备份与离线

- [ ] 旧版详细规划与资料对话可从计划页底部折叠入口打开；
- [ ] 原有个人计划、阶段、资料引用和任务仍存在；
- [ ] 创建完整备份并恢复后，周期计划、完成进度、错题方案和题目仍存在；
- [ ] 恢复时不出现 `MIGRATION_HISTORY_INCONSISTENT`；
- [ ] 断网重启后，月历、周期计划、今日事项、图片错题和三按钮反馈均可使用。

## 13. 统一弹窗操作

依次点击周期计划、复习方案、题目和 API Provider 的“新建”或“编辑”：

- [ ] 编辑器以弹窗出现，原页面不再向下插入表单；
- [ ] 弹窗打开后不能误操作背景页面；
- [ ] 内容较长时只在弹窗内部滚动；
- [ ] 保存成功后弹窗关闭，原页面数据刷新；
- [ ] 未修改时可直接关闭；
- [ ] 修改任意字段后按 Esc、点击遮罩或“关闭”，出现放弃修改确认；
- [ ] 选择“继续编辑”返回原输入内容；
- [ ] 选择“放弃修改”关闭弹窗且不保存；
- [ ] 缩窄窗口后弹窗仍可完整填写和点击保存。
