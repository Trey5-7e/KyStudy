# R25 扫描习题册 OCR 索引与降级验收

本轮在 R24 文字层索引适配的基础上，为低文字量或无文字层 PDF 页面增加可选的逐页 OCR
索引通道。目标是让扫描页能够产生可校对的题号、题型和区域候选，同时继续保持 R19～R24
的安全边界：OCR 不是阅读和手动框选的前置条件，空白或不确定结果不自动创建题目，最终
题号、题型、章节、篇章和区域仍由用户确认。本文件记录代码级回归和一次临时合成样本的
结果，不代表真实资料或桌面窗口已经完成验收。

## 1. 本轮决策与实现边界

### 1.1 仅对低文字量页面调用 OCR

索引器先读取 PDF.js 文字层，并过滤页眉、页脚、书签标题和空白。只有正文文字项少于 4
项，或正文归一化字符数少于 32 时，才进入 OCR；文字层足够完整的页面不会调用 OCR。
这使文字型 PDF 继续走 R24 的快速路径，也避免对整本教材重复识别。

### 1.2 固定分辨率、逐页串行和取消

- 每页通过 PDF.js 渲染为 PNG，长边固定为 1800px；Canvas 在页面处理结束后释放。
- 页面按 `pageStart..pageEnd` 顺序串行处理，不并发启动多个渲染或 Worker。
- 渲染、传输和识别都检查 `AbortSignal`；取消时停止当前渲染/Worker，并结束索引流程，
  不写入半成品题目。
- `recognize_pdf_page` 使用不透明 `operationId` 和页码/图片字节请求；Rust 端的
  `recognize_page` 只返回 `OcrPageRecognition` 内存 DTO。

### 1.3 非持久化与数据隔离

页面 OCR 只把文本、置信度和归一化框转换为临时 `PageItem[]`，供题号、题型和区域规则
继续计算；它不会创建 OCR 草稿，也不会写入以下表或流程：

- `resource_page_text`（本地 PDF 文字索引）；
- `question_region_ocr` 及其文字行（题目区域 OCR 草稿/确认）；
- OCR Worker 路径、临时图片路径、storage key 或其他内部诊断字段。

题目候选只有在用户后续确认科目、练习册和索引结果时，才进入既有题库导入事务。
`recognize_pdf_page` 本身不修改题目、区域、作答历史或搜索索引。

### 1.4 缺少组件时的 text-only 降级

只有 `get_ocr_status` 返回 `available` 时才注入页面 OCR 适配器。组件缺失、不完整、
不兼容、识别失败或被取消时，原文字层继续使用；扫描页没有文字层时保留 PDF 阅读和
手动框选能力，结果不因 OCR 失败而静默补题。用户可以安装/修复组件后重试，或直接在
PDF 上人工框选。

### 1.5 OCR 候选必须低置信度并校对

只要题目区域包含 OCR 来源的文字项，索引置信度上限为 `0.72`，即使题型或章节信号
看起来完整，也不能提升到文字层候选的 `0.96`。OCR 识别出来的题号、A～D 选项、公式、
矩阵和跨页边界都只是候选，用户必须在 PDF 上查看并校对；低置信度不会绕过 R21/R22
的缺题防误补和 R23 的异常确认规则。

## 2. 自动化回归目标

本轮目标证据为 Rust 5 条、前端 31 条。自动化应覆盖：

1. Rust `recognize_page` 拒绝零页码和非 PNG 输入，响应取消，不写仓储，并输出只有
   `pageNumber`、`engine`、`meanConfidence`、`lines` 的页面 DTO；
2. 前端桥接使用 `recognize_pdf_page` 的 camelCase request，严格校验页码、置信度、
   非空文字、归一化框和非负 `sortOrder`；
3. `pageNeedsOcr` 只命中稀疏页面；`ocrRecognitionToPageItems` 保留来源与置信度，
   过滤空行和越界框；
4. 索引器在单页 OCR 后继续运行题号、选项、解答题型、区域边界和警告计数；文字层
   足够完整时不调用 OCR；取消发生在打开 PDF 前或页面处理中都会停止；
5. OCR 候选题的 `indexConfidence` 不超过 `0.72`，且页面 OCR 计数可由进度和结果 DTO
   追踪。

Rust 与前端测试数量是本轮目标记录，不把尚未补入日志的完整 `pnpm check`、Rust 全量
测试或桌面构建误记为已执行证据。

## 3. 临时合成 A4 无文字层样本

本轮使用一份本机临时生成的合成 A4 PDF，不含版权资料，不提交为正式题库夹具。PDF.js
文字层抽取为 **0 字符**，只有 1 页，因此应触发且只触发 1 次页面 OCR。

| 指标                 | 临时结果                                 |
| -------------------- | ---------------------------------------- |
| PDF 页面 / 文字层    | 1 页 / 0 字符                            |
| OCR sidecar 墙钟时间 | 2.41988 s                                |
| OCR 返回文字行       | 10 行                                    |
| 题号与版式信号       | 顶层题号 `1`、`2`、`3`，并包含 A～D 选项 |
| 完整索引题数         | 3                                        |
| 题型结果             | `choice`、`solution`、`solution`         |
| `warningCount`       | 0                                        |
| `ocrPageCount`       | 1                                        |
| OCR 题置信度         | 每道题均不高于 `0.72`，需人工校对        |

该结果只证明“无文字层页面 → 临时 OCR PageItems → 题号/题型/区域候选”的链路能够
完成，不证明 OCR 文本或数学语义准确。公式、矩阵、复杂表格、噪声扫描和手写内容仍
应保留原始页面图片，并交给人工校对。

## 4. 与 R24 真实 PDF 的关系

R24 的两份真实 EduEditer 来源 PDF 仍是文字层索引基线，不因本轮 OCR 临时样本而改变：

| 样本                      | 页面与索引基线                                                                                              |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 高等数学习题册            | 296 页、可靠顶层题 787、`warningCount=0`                                                                    |
| 线性代数/概率论混合习题册 | 214 页；线代 PDF 第 3～91 页 / 224 题；概率论第 92～214 页 / 288 题；合计 512 题，两个范围 `warningCount=0` |

两份真实 PDF 未纳入仓库夹具，本轮也未进行自动桌面验收。R24 中关于页眉页脚、水印、
公式矩阵、章节重置、跨页 `(1)/(2)` 小问、非数字题号、空白不等于缺题和人工区域保护
的边界继续有效。

## 5. 人工验收步骤（待负责人执行）

1. 在有 OCR 组件的 Windows 环境导入一页无文字层扫描 PDF，确认进度显示正在 OCR，
   页面只渲染一次且 OCR 计数为 1；检查题号 1/2/3、A～D 选项和三道题的候选类型。
2. 打开每道候选题，确认 OCR 区域覆盖原页面，置信度显示为低置信/需校对；人工调整
   题号、题型和区域后再保存，确认 OCR 不自动覆盖人工区域。
3. 取消正在渲染或识别的页面，确认 Worker 退出、索引显示取消或可重试，题库、
   `resource_page_text` 和 `question_region_ocr` 没有半成品记录。
4. 移除或破坏 OCR 组件后重试同一 PDF，确认回到 text-only：文字层页面仍可索引，
   无文字层页面不自动创建题目，PDF 阅读和手动框选仍可用。
5. 对 R24 两份真实 PDF 重跑文字层索引并抽查章节切换、页眉页脚、水印、矩阵、跨页
   小问和题号重置；只有明确低文字量页面才允许触发 OCR，且所有 OCR 题仍需人工校对。

## 6. 风险与完整验证边界

- 合成 A4 单页只有一个版面，不能代表 R24 的双栏、跨页、章节切换、复杂水印或真实
  扫描噪声；10 行 OCR 输出也不能作为教材准确率承诺。
- 页面 OCR 是索引候选通道，不是 PDF 全文索引、公式识别、答案区检测或自动题目创建。
- `question_region_ocr` 仍是用户明确对题目区域发起的独立流程；本轮页面 OCR 不应复用
  其草稿/确认状态，也不应把临时 PageItems 写入 `resource_page_text`。

## 7. 结论

本轮实现可作为 R24 的条件性扫描页补充：默认优先文字层，只对低文字量页面按需、逐页、
串行调用本地 OCR；结果仅作为低置信度、需人工校对的临时索引候选。缺少组件或 OCR 失败
时保留 text-only 与手动框选，不写入 `resource_page_text` 或 `question_region_ocr`。
临时合成 A4 样本链路结果为 1 页/0 字符、sidecar 2.41988 s、10 行、3 道候选题、
`choice/solution/solution`、`warningCount=0`、`ocrPageCount=1`；真实 R24 PDF 与桌面
验收仍待负责人按上述边界补充。
