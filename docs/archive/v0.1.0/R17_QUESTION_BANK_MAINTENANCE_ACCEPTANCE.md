# R17 题目索引维护集中验收

本轮把“看题、校对、补题、删除”集中到题库窗口中，不再使用旧的独立手动维护页面。

## 一次完成的验收步骤

1. 打开“习题册”，确认主页面只显示科目与练习册树，不再在下方堆放题目列表。
2. 点击“浏览题目索引”，使用筛选条件缩小范围；点击左侧题目，并用“上一题 / 下一题”或键盘左右方向键切换。
3. 点击“编辑题目”，修改章节、篇章、题型、题号或标题，保存后关闭再打开，确认修改仍在。
4. 点击“补充题目区域”，在原 PDF 中框选一个区域并保存，确认当前题目卡片出现新增区域。
5. 从习题册主页点击“手动补题与校对”，选择已经由自动解析建立的科目分段，填写最少索引信息并框选题目，确认新卡片归入所选科目与练习册。
6. 在题目窗口删除一道测试题，确认经过二次确认后题目从索引、快速登记与拼卷范围中消失，分段题目数同步减少。
7. 打开“资料”，删除一份测试资料，确认资料从列表和搜索中消失；如果它已有题目卡片，原题图片仍能正常显示。
8. 重新分析同时含线性代数和概率论的 PDF，确认只返回 2 个科目节点；若之前存在两个概率论分段，重新确认归类后会合并到新的完整分段。
9. 打开“新建科目”和“新建练习册”，确认输入框独占一行，底部取消与创建按钮留有清晰间距。

资料删除采用安全移除：受管理文件仍保留在本地工作区，以免历史题目卡片失去来源；界面不提供立即硬删除。
