# 浏览器 UI 预览

Vite 开发页面在没有 Tauri 后端时会自动启用只读预览数据层，便于检查页面布局、滚动、遮挡和交互状态。预览数据不会读取或写入本地工作区；桌面应用检测到 Tauri 后端后仍使用真实数据。

启动开发页面：

```powershell
pnpm dev
```

在应用内浏览器打开以下地址即可检查对应页面：

- `http://127.0.0.1:1420/#planning`：周期计划日历与进度卡片
- `http://127.0.0.1:1420/#workbook`：题库高密度列表（2343 道演示题）
- `http://127.0.0.1:1420/#library`：资料列表与思维导图预览

预览后端只覆盖 UI 检查所需的读取命令；未覆盖的写入、真实 PDF 读取和 AI 请求会明确返回 `BROWSER_PREVIEW_UNSUPPORTED`，不会静默修改数据。
