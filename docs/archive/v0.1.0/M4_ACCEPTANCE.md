## 1. 本批次结果

M4 完成了不依赖网络、AI 或 OCR 的本地知识结构闭环：

```text
手动创建导图 -> 编辑/移动/排序/折叠节点 -> 保存掌握状态与笔记
       |                                     |
       +---- 持久化撤销/重做 <---------------+
       |
上传 OPML/.mm -> 独立预览草案 -> 用户确认 -> 正式导图
                                      |
节点关联本地资料/PDF 页码 ------------+----> 回到原页复核
```

正式前端只接收类型化导图、节点、资料关联和导入警告。Revision 快照 JSON、草案原始 JSON、SQL、绝对路径和 storage key 都保留在 Rust/SQLite 边界内。

## 3. 人工综合 Smoke

请只使用上面的 M4 Release EXE。整个 Smoke 预计 20～30 分钟，不需要联网，也不需要打开开发者工具。测试时请使用本文提供的自建样本，不要发送工作区数据库或个人资料。

### A. 升级与原有数据

1. 关闭其他 KyStudy 窗口，启动 M4 Release；确认窗口正常打开，运行状态显示 `Schema v6`。
2. 确认 M3 已有科目、任务、个人计划、资料和 PDF 阅读进度仍存在；任选一项打开检查。
3. 若当前工作区为空，先创建默认工作区，并至少创建一个科目。

### B. 手动导图与节点编辑

4. 在“可编辑思维导图”左侧创建 `408 手动导图`，选择一个已有科目；确认新导图出现且默认只有根节点。
5. 在右侧“导图信息”把名称改为 `408 知识树` 并保存；切换到其他导图再切回，确认名称和科目保留。
6. 点击根节点的“+ 子节点”，依次添加 `数据结构`、`操作系统`、`计算机网络`；确认三个节点都显示。
7. 选择 `数据结构`，把笔记改为 `重点复习树、图与排序`，掌握状态设为“薄弱”，重要度设为 `5`，保存后切换节点再切回；确认内容保留。
8. 在 `数据结构` 下添加 `线性表`、`树与二叉树`、`图`；点击数据结构节点左侧的折叠/展开按钮，确认三个子节点隐藏后可以恢复。
9. 使用 `图` 节点的“↑”“↓”按钮调整同级顺序；确认顺序变化，关闭并重启应用后仍保持。
10. 用鼠标把 `图` 节点拖到 `计算机网络` 节点上；确认它成为计算机网络的子节点。拖动根节点应不可用。
11. 点击“撤销”，确认 `图` 回到数据结构下面；点击“重做”，确认它再次移动到计算机网络下面。
12. 尝试把 `计算机网络` 拖到其子节点 `图` 上；确认不会形成循环，正式结构保持不变。

### C. 节点资料关联与删除恢复

13. 若资料库还没有 PDF，导入项目自带的 `experiments/tv-04-pdf-viewer/public/fixtures/mixed-samples.pdf`，打开一次确认显示 `1/6` 页以保存总页数；回到导图区点击“刷新资料与草案”。
14. 选择任一节点，在“关联资料”选择该 PDF，填写起始页 `2`、结束页 `3` 和说明，添加关联；确认显示资料标题和页码。
15. 点击“打开资料”；确认页面滚动到资料阅读器，并打开 PDF 第 `2` 页。
16. 再添加起始页 `6`、结束页 `7`；确认保存被拒绝并提示检查页码范围，原有关联不受影响。
17. 移除步骤 14 的关联，再点击“撤销”；确认关联恢复。点击“重做”；确认关联再次移除。
18. 选择一个包含子节点的非根节点，点击“删除子树”并确认；确认整棵子树消失。点击“撤销”确认完整恢复，再点击“重做”确认再次删除。

### D. 复制与软删除

19. 点击“复制导图”；确认出现名称带“副本”的新导图，节点结构、笔记和资料关联保持一致。
20. 修改副本中的一个节点；切回原导图，确认原导图没有被同步修改。
21. 在副本中点击“删除导图”并二次确认；确认副本从有效导图列表消失，原导图仍在。
22. 重启应用；确认步骤 21 删除的副本不会重新出现在有效列表。

### E. OPML 与 FreeMind 草案

23. 在资料库依次上传：
    - `experiments/m4-mindmap/fixtures/408-knowledge.opml`
    - `experiments/m4-mindmap/fixtures/network.mm`
    - `experiments/m4-mindmap/fixtures/doctype-rejected.opml`
24. 回到“结构化导入草案”，点击“刷新资料与草案”；确认三个文件都可在源文件下拉框中选择。
25. 选择 `408-knowledge.opml` 并生成草案；确认显示 `OPML`、`8 个节点`，预览层级包含“408 → 数据结构 → 线性表”和“操作系统 → 内存管理”。此时正式导图列表不应自动新增。
26. 点击“确认导入”；确认草案变为“已导入”，正式列表新增导图，节点层级和根节点笔记可编辑。
27. 选择 `network.mm` 并生成草案；确认显示 `FreeMind`、`7 个节点`，预览包含“网络层 → IP 协议/路由选择”。
28. 点击“拒绝草案”；确认状态变为“已拒绝”，正式导图列表没有新增这张网络导图。
29. 选择 `doctype-rejected.opml` 并生成草案；确认应用明确拒绝该文件，且正式导图和已有草案不被修改。
30. 如果手边有 XMind 原文件，可选做：上传后刷新并选择它；确认界面提示“先导出为 OPML”，且“生成预览草案”不可用。

### F. 离线、备份与恢复边界

31. 关闭 KyStudy，断开网络后重新启动同一 EXE；确认手动导图、导入导图、节点状态、折叠状态和草案状态仍可离线读取与编辑。
32. 创建一次完整备份；确认成功。若方便，可恢复到一个新的空目录并启动恢复副本，确认 schema v6 导图与草案存在；不要覆盖当前工作区。

## 4. 通过标准

步骤 1～29、31～32 全部符合预期即可回复：`M4 全部通过`。步骤 30 是可选的 XMind 提示检查。若失败，请提供“步骤编号 + 界面提示 + 截图”；无需发送数据库、原始个人资料或绝对路径。

- 图片/PDF 识图、OCR、AI 节点建议、逐节点 AI 差异和 Token 预算；
- XMind ZIP 直接解析、Markdown 大纲和通用导图导出；
- 自由画布坐标、跨树关系线、任务/题目/错题关联和知识图谱推理；
- 导图回收站恢复界面、硬删除、多人协作、云同步；
- 安装包、签名、自动更新、GitHub Release 或公开开源准备。
