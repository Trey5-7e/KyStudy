# R63 思维导图导入容量与预览交互验收

R63 针对思维导图大文件和浏览体验做了两项收敛：把生成导入草案时的源文件安全上限提升到 100 MiB，并优先保证只读预览画布的平移与缩放。

## 1. 本轮变更

- OPML、FreeMind 和 XMind 导入草案的源文件读取上限统一为 100 MiB；XMind ZIP 中的 `content.json` / `content.xml` 解压条目也受同一上限约束。
- 超限提示已同步改为“100 MiB 以内”，避免仍指导用户按旧的 4 MiB 限制处理文件。
- MindElixir 预览保持 `editable: false`，不让节点编辑与浏览手势竞争；节点的添加、编辑仍由右侧编辑面板负责。
- 预览画布支持：
  - 按住鼠标左键拖动空白区域平移；
  - 滚轮按指针位置缩放，范围为 0.35–2.5 倍；
  - 触控设备保留同一套平移手势；
  - “适应窗口”继续恢复完整导图视图；
  - 工具栏旁显示“拖动空白区域平移 · 滚轮缩放”提示。

## 3. 桌面验收（由用户执行）

1. 使用本批最新 Release 启动应用，进入“资料 → 思维导图”，打开一张已有正式导图。
2. 在画布空白处按住鼠标左键拖动，确认导图可平移；拖动节点本身不进入编辑或改变节点层级。
3. 在画布上滚动鼠标滚轮，确认导图围绕指针位置放大或缩小；点击“适应窗口”后确认视图恢复完整导图。
4. 在资料库导入一个大于 4 MiB 且不超过 100 MiB 的 `.xmind` 文件，生成导入草案并确认可以进入预览；超过 100 MiB 时应显示明确的容量提示。
5. 确认原有节点选择、搜索和右侧节点编辑面板仍可用；若某个 MindElixir 版本或输入设备导致节点编辑与拖拽冲突，以稳定预览平移/缩放为验收优先级。

本轮不启动 Release EXE，也不替代桌面人工验收。
