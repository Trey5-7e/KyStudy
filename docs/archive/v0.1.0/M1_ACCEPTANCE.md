## 明确延期而非遗漏

- 当前 schema v1 → v2 只新增基础表，不是破坏性迁移；“高风险迁移前快照”在 M1 没有适用样本。未来首个删除、改写或大批量转换用户数据的迁移，在合并前必须实现并验证迁移前快照。
- M1 Artifact 只用于工程验收，不是面向用户的正式发布。品牌图标、代码签名、安装包、第三方许可证随包清单和自动更新均进入发布里程碑。
- 根目录暂不添加 `LICENSE`；仓库保持非公开状态，直到项目所有者重新启动开源准备工作。
- 全库完整性扫描与修复 UI、删除/回收站和无引用 Blob 清理不属于 M1；现有导入和备份路径已经执行所需的局部完整性校验。

## M2 输入

M2（日程闭环）可以直接依赖：

- schema v2 的迁移框架、外键、事务与备份能力；
- 类型化 Command/DTO 和稳定错误边界；
- application/domain/infrastructure 分层与 Windows CI；
- 默认工作区中的时区、每日错题数量和提前补足设置。

M2 不需要接入 AI、OCR、PDF.js 或思维导图库。应先完成任务、每日清单、实际完成记录和最小统计闭环，再决定 AI 如何提供非默认、需确认的规划建议。
