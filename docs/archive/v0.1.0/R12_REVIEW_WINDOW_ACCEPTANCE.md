## 交互调整

- 方案卡片不再直接展开整道错题，只显示队列状态与“开始复习 / 继续复习”入口；
- 点击入口后，在大尺寸模态窗口中显示题目图片、来源、AI 解析与反馈按钮；
- 默认的今日连续复习同样使用窗口，完成一份方案后在窗口内自动进入下一份；
- 关闭窗口不会改变队列，再次点击“继续复习”回到当前未完成题；
- `1 = 掌握`、`2 = 模糊`、`3 = 不会` 在窗口内继续有效；
- 最后一题提交后，窗口显示完成结果与撤销入口；
- “重看不会的题”也在相同的大尺寸窗口中浏览；
- 小尺寸屏幕下窗口限制在可视区域内，内容区域支持上下滚动。

## 集中人工验收

1. 在“管理复习方案”中选择一份已有队列的方案，确认卡片内不再直接铺开题目；
2. 点击“开始复习”或“继续复习”，确认题目在独立窗口中打开；
3. 在窗口中依次用 `1 / 2 / 3` 提交，确认分别对应掌握、模糊、不会；
4. 中途关闭窗口并重新打开，确认继续显示第一道未完成题；
5. 回到默认“今日连续复习”，确认连续队列也通过窗口完成，并能自动跨方案；
6. 完成最后一题，确认窗口显示完成提示且“撤销上一题”可用；
7. 若存在不会的题，点击“重看不会的题”，确认在窗口内切换上一题和下一题；
8. 缩小软件窗口，确认弹窗内容可上下滚动，底部反馈按钮仍能访问。

通过标准：任何正式错题作答都不再挤进方案卡片；关闭、重开、反馈、撤销和跨方案连续复习均不打乱稳定队列。
