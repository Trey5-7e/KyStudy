# M6：错题状态与每日复习闭环

| 项目     | 内容                                                           |
| -------- | -------------------------------------------------------------- |
| 状态     | accepted                                                       |
| 目标     | 把 M5 的真实作答转化为稳定、可解释、可离线执行的每日复习队列   |
| 验收方式 | 自动门槛完成后，使用统一 `target\release` 执行一次综合 Smoke   |

## 1. 本批次交付

1. 历史和新产生的“错误”作答自动激活错题；用户也能手动加入或退出复习；
2. 每道错题保存 1～5 级用户重要度、当前掌握状态、连续掌握/未掌握次数和到期日；
3. 用户可修改默认每日配额和“到期不足时提前补足”，生成当天稳定快照队列；
4. 队列按固定、逾期、连续未掌握、错误次数、用户重要度、知识节点薄弱度和距上次作答天数排序；
5. 每道题显示结构化入选原因，不向前端暴露内部 SQL、路径或原始评分载荷；
6. 复习反馈支持“掌握 / 不确定 / 未掌握 / 跳过”，并立即给出下次复习日期与原因；
7. 掌握、不确定和未掌握会追加真实作答；跳过只记录复习事件，不伪造作答；
8. 每次复习事件不可修改，队列完成状态、调度前后日期和规则版本均可追溯；
9. 显示当前激活、今日到期、已经逾期、剩余队列和预计清空天数，配额不会隐藏积压；
10. schema v8、历史迁移、完整备份和跨目录恢复覆盖全部复习数据。

## 2. 初始规则（policy version 1）

| 反馈     | 下一次间隔 | 状态变化                               |
| -------- | ---------- | -------------------------------------- |
| 未掌握   | 1 天       | 连续掌握归零，连续未掌握加一           |
| 不确定   | 3 天       | 连续掌握归零，保留已有连续未掌握信息   |
| 首次掌握 | 7 天       | 连续掌握变为 1，连续未掌握归零         |
| 连续掌握 | 14/30/60 天 | 按第 2/3/4 次及以后逐步延长            |
| 跳过     | 1 天       | 不改变掌握与作答聚合，只短期重新进入   |

优先级分数只用于队列生成时排序并作为快照保存：

```text
固定到今天       + 1,000,000
逾期天数         × 10,000
连续未掌握次数   × 1,000
历史错误次数     × 100
用户重要度       × 20
薄弱/学习中节点  + 60 / 30
距上次作答天数   最多 + 365
```

同分时按到期日、最近错误时间和题目 ID 稳定排序。界面展示“逾期 4 天”“连续 2 次未掌握”等原因，而不是要求用户理解分数。

## 3. 队列边界

- 同一工作区同一天只有一个正式队列；重复生成返回同一快照；
- 当日配额在首次生成时确定，已生成队列不因新错题或元数据变化自动重排；
- 到期题不足且启用提前补足时，才选择未到期题并明确标记“提前复习”；
- 用户可以把一条未在队列中的激活错题手动追加到当天末尾，且标明“手动加入”；
- 已完成项目不会回到待处理状态；当天新错题默认进入下一次生成的队列；
- 软删除题目不会进入新队列，已存在的未完成队列项在读取时明确不可继续提交。

## 4. 本批次不实现

- OCR、AI 判题、答案识别、相似题生成或外部题库；
- 让 AI 修改复习顺序、间隔或用户重要度；
- SM-2、FSRS 等复杂记忆模型及用户自定义每一级间隔；
- 修改、删除或作废历史作答与复习事件；
- 跨设备同步、通知提醒、日历集成或云队列；
- 安装包、签名、GitHub Release 或公开开源准备。
