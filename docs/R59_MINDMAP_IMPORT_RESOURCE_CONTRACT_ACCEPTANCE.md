# R59 思维导图导入与资料关联契约验收

R59 收口第六阶段思维导图链路的自动化回归证据。本轮不改变导图数据或命令语义，固定既有的导入草案边界、XMind 降级提示、草案确认流程、PDF 页码校验和资料阅读入口。

## 1. 用户可见范围

- 资料库中只有 `mindmap_source` 才会进入导图导入选择器。
- OPML 与 FreeMind `.mm` 只生成只读草案；草案展示树形预览和警告，必须明确“确认导入”后才创建正式导图，也可以明确拒绝。
- XMind 原文件不直接解析，导入按钮禁用并提示先在 XMind 中导出 OPML；原文件保持不变。
- 节点关联 PDF 时，起始页和结束页必须同时填写，页码为正整数且结束页不早于起始页；错误以可行动的表单告警呈现。
- 已关联资料只有 PDF 或图片显示“打开资料”，并将保存的起始页传给阅读器；其他资料类型不伪装成可浏览资源。

## 3. 桌面验收（由用户执行）

自动门禁通过后，请在最新 Release WebView 中打开“资料 / 思维导图”：

1. 上传或选择 OPML、FreeMind `.mm`，确认只出现“生成预览草案”，草案包含树形预览和警告；确认导入前正式导图列表不增加。
2. 点击“确认导入”，确认生成新的本地导图副本；点击“拒绝草案”，确认草案进入已拒绝状态且不创建正式导图。
3. 选择 XMind 原文件，确认按钮不可用并显示“先导出为 OPML”的提示。
4. 在节点详情关联 PDF：只填一侧页码、填 0/小数、结束页早于起始页均应阻止保存并显示错误；填写合法范围后可添加关联并按页打开资料。
5. 关联图片或普通文档，确认只有图片显示“打开资料”，普通文档不显示伪造的阅读入口。

本轮不启动 Release EXE，也不替代桌面人工验收。
