# M5：PDF 习题册与手动题目闭环

| 项目     | 内容                                                      |
| -------- | --------------------------------------------------------- |
| 状态     | ready-for-acceptance                                      |
| 目标     | 让用户直接在本地 PDF 上框选题目、整理元数据并记录多次作答 |
| 验收方式 | 自动门槛完成后，一次性执行 Release 综合验收               |

## 1. 本批次交付

1. 只选择用途为“习题册”的 PDF，按页阅读并开启手动框选；
2. 框选结果转换成 PDF 页面 0～1 归一化矩形，不保存 Canvas 像素；
3. 一道题可以保存一个或多个有序区域，为跨页题目保留正式模型；
4. 题目保存标题、章节、题号、难度、个人解析和可选知识节点关联；
5. 题目可编辑、软删除和恢复，并能从列表回到 PDF 原页；
6. 同一道题追加多次作答，记录正确、错误或不确定、耗时和复盘；
7. 题目与作答进入 schema v7、完整备份和历史迁移边界；
8. 全部功能离线运行，不接入 OCR、AI 或外部题库。

## 2. 坐标与安全边界

- 前端仅持有 document ID、页码和归一化矩形；
- 使用 PDF.js viewport 在 CSS 坐标和 PDF 点之间双向转换；
- 旋转、缩放、窗口尺寸和 DPR 不进入正式坐标；
- `coordinate_version = 1`，矩形必须完全位于页面范围内；
- 已知总页数时，Repository 拒绝越界页码；
- Command DTO 不返回路径、storage key、SQL、Blob 元数据或内部 JSON；
- 删除 PDF 不在本批次实现，避免题目来源静默失效。

## 3. 本批次不实现

- OCR、文字层题目切分、答案识别和 AI 标签；
- 自动判断对错、公式解析、手写识别；
- 错题优先级、间隔复习和每日队列（进入 M6）；
- 自由多边形区域、页面批注和修改原始 PDF；
- 在线题库、题目分享或受版权保护内容分发。

## 4. 后续版本估计

- M6：错题状态、可解释优先级、每日复习配额和复习事件；
- M7：资料检索、AI 规划/题目辅助、API 配置和 Token 预算；
- M8：统一体验改进、性能、导入导出和长期使用复盘；
- M9（可选）：开源许可证、贡献规范、安装包、签名和公开发布。

因此，从当前状态到核心闭环完整约 3 个大版本，到成熟可长期使用约 4 个；若包含正式开源发布则约 5 个。实际可以根据使用反馈把 M8 拆成两个打磨批次。
