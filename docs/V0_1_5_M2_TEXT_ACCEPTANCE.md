# M2-A 资料研读：人工验收

状态：待用户执行。日期：2026-09-09。本清单只验收新增的只读文字研读，不重复普通 Provider 连接测试。

## 1. 本批范围

入口为“AI 学习助手 → 资料研读”：选择已有会话、已索引 PDF、物理页码和问题，再开始。模型通过原生工具按需读页/页内搜索，结果提供可校验的来源跳转。默认用量策略不强制截断，调整项收在高级选项。

尚未包含扫描页视觉、跨页排名检索、练习草稿/审批、重启后原协议续接或澄清回复按钮。长页面返回带截断标记的片段；图像不会外发。需要补充问题或任务中断时，可先取消该轮，再带上补充信息新开。

## 3. 准备一个可核对的问题

- 使用你已经配置并验证过的 DeepSeek Provider，模型为 `deepseek-v4-flash-vision-exp`，官方端点 `api.deepseek.com`。不需要重新填写 Key 或测试额度。
- 在副本中选择一份已完成文字索引、内容允许发送给该 Provider 的 PDF。建议先用公开教材或你自己的非敏感合成样例；不要为验收发送个人敏感资料。
- 记下一个物理页码及该页的一句明确事实，用一个短问题核对这句事实。不要一开始选整本资料。
- 在“普通对话”准备一个验收会话，再切换“资料研读”。高级选项保持默认即可。

| 编号 | 操作                                                                                  | 通过标准                                                                                                                    |
| ---- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| C1   | 不选 PDF/页码，或输入 0、超出总页数的页码；随后改为有效页码                           | 无效范围不能启动；有效选择显示实际授权页码                                                                                  |

| C3   | 点击回答的来源按钮                                                                    | 打开所选 PDF 的对应物理页；核对原文，不把“能跳转”当作推论必然正确                                                           |
| C4   | 再开一轮，运行中切到普通对话或其他页面，再回到资料研读并选择原会话                    | 找回同一轮任务和已保存步骤；不会因为离开页面重复发起任务。同一会话的普通发送/删除应在 Agent 活动时被拒绝                    |
| C5   | 在一轮仍运行时点击“取消研读”                                                          | 最终为“已取消”，不继续出现新的模型/工具步骤；可以在该会话新开一轮。若模型已先完成，完成状态也可作为竞态结果，不强求改为取消 |

可选边界检查（仅操作副本）：旧回答完成后，改变其 PDF 索引或将该资料移入回收站，再点旧来源，应拒绝打开失效版本；未建立索引的资料不应被自动建索引或自动外发。此项不要求删除正式资料。

模型回答有误、缺少来源、协议失败都需要反馈，不能因为按钮/页面正常就标记 C2 通过。新链路的真实教学质量尚待本次验证；已有的普通连接测试不替代它。
