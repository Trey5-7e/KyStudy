# R39 页面表面与 AI 设置窗口验收

R39 收敛用户截图反馈和低频配置入口：题库与错题页的外层 `PageSurface` 在宽屏主内容列横向扩展至 `96rem` 上限，保留安全 gutter，窄屏保持可用宽度且不横向溢出；外层透明并跟随首页 app background，不设置 viewport 级最小高度，不再留下错误的整页白色空段或第二层大卡片，白色表面仅保留给内部任务卡。AI 设置默认只显示紧凑摘要，详细管理统一进入一个 `EditorDialog`。本轮只调整呈现和交互边界，不改变题库、复习、Provider、Token 或调用历史的数据与命令语义。

本文件记录实现契约和已完成的 focused 证据。当前状态为：自动门禁通过；桌面人工验收待用户执行。

## 1. 用户目标与保留范围

- `QuestionBankPanel` 和 `ReviewPanel` 的 `PageSurface` 在宽屏主内容列横向扩展至 `96rem` 上限并保留 safe-area gutter，窄屏保持可用宽度且不横向溢出；外层只负责布局，不设置 viewport 级最小高度，也不叠加边框、内边距或白色背景，而是透明并跟随首页 app background。白色表面仅由题库树、错题方案等内部任务卡保留；导入/工具/分段回收站、题目编辑与生成试卷，以及今日队列、反馈、撤销和复习窗口继续可用。
- 设置页的 AI 区域默认显示当前 Provider、模型/目的地、密钥状态和 Token 预算摘要；详细内容不再平铺在主设置页。
- “管理 AI 配置”打开一个 `EditorDialog`，在同一窗口内切换 Provider 列表、Provider 新增/编辑、Token 预算、连接与外发测试、调用历史五种模式；返回、关闭和窗口滚动沿用通用弹窗契约。
- Provider 新增、编辑、切换、删除，API Key 保存/删除，Token 预算保存，测试预览与明确确认后的执行，以及历史查看均保留；删除 Provider 或已保存密钥不会静默发生。

## 2. 状态、焦点与响应式契约

- AI 的 `busy` 状态统一禁用当前操作、表单、返回和关闭动作，并通过弹窗 `aria-busy` 与状态/错误播报反馈进展；操作失败继续映射为可行动的本地化错误。
- Provider 删除和“删除已保存密钥”均先显示明确的二次确认；密钥仍只写入或删除 Windows 凭据管理器，页面不展示明文。
- 管理窗口打开时聚焦标题；模式切换后聚焦当前模式标题；关闭或返回时恢复触发器焦点，触发器失效时回退到页面标题。未保存的 Provider/预算草稿沿用 dirty 确认，避免误丢修改。
- Provider 名称、模型 ID、地址、测试文本、历史内容和题库长名称允许断行；`640px` 以下摘要动作改为堆叠，AI 模式标签为两列，`360px` 以下改为单列，`320px` 以下主要按钮全宽，页面和窗口均不得横向溢出。
