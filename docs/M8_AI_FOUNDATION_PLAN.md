## 1. 本批次交付

1. 以 `AiProviderGateway` 隔离业务用例与具体模型协议；
2. 提供完全离线、确定性的测试 Provider，无 API Key 也能验收整个调用链；
3. 提供 OpenAI-compatible Responses API 通道，模型 ID 和 HTTPS 基础地址由用户配置；
4. API Key 只保存到 Windows 凭据管理器，SQLite 仅保存不可逆引用；
5. 每次调用分为“生成外发预览”和“用户明确确认后执行”两个阶段；
6. 预览显示完整外发文本、目标主机、模型、输入 Token 预估和输出硬上限；
7. 支持单次、每日和每月 Token 预算，以及 `warn`/`block` 两种模式；
8. 相同 Provider、地址、模型、提示、输出上限和协议版本生成稳定请求指纹并复用本地缓存；
9. 调用历史只显示 Provider、模型、状态、Token、缓存命中和稳定错误码；
10. 异常退出遗留的 `pending` 调用在下次启动时标记为 `AI_CALL_INTERRUPTED`；
11. schema v10 随完整备份保存非敏感配置、用量和缓存，密钥不进入备份；
12. 前端运行时校验会丢弃 `secret_ref`、请求指纹、路径、SQL 和原始 Provider 错误。

## 2. 安全不变量

- 前端不能读取已经保存的 API Key，也不能从 DTO 判断密钥内容；
- 密钥不写入 SQLite、日志、调用历史、缓存、普通备份或诊断内容；
- 非本机 HTTP 地址被拒绝，远程 Provider 必须使用 HTTPS；
- HTTP 重定向被禁用，避免 Authorization Header 被带往其他主机；
- Provider 错误正文不跨越 Rust Command 边界；
- AI 输出只是文本结果，M8 没有修改任务、计划、导图、题目或复习记录的 Command；
- 离线 Provider 不访问网络，断网时全部既有学习功能仍可使用。

## 3. Token 与缓存规则

输入 Token 在调用前使用确定性本地估算：中文等非 ASCII 字符按更保守粒度计算，ASCII 按字符近似折算，并加入固定协议开销。预算按“输入预估 + 输出上限”的最坏值判断；调用后优先记录 Provider 返回的实际用量，缺失时明确标记为 `estimated`。

缓存命中不再次调用 Provider，新增输入/输出 Token 均记为 0，并以 `cache` 标记。指纹包含协议版本，因此未来改变系统提示或请求结构时不会误用旧缓存。

## 4. M9 连接点

M9 在本层之上增加规划对话和资料上下文清单。M7 的 PDF 搜索结果将先由用户选择，再进入外发预览；`ai_context_ref`、对话消息、规划草案和引用页码在 M9 落地。M8 不自动读取整份 PDF，也不把通用测试结果写回正式学习数据。
