## 来源与边界

- 截图来自合成演示数据，不含个人学习记录、真实文件路径或 API Key；
- 图片保留原始窗口截图尺寸，README 通过页面级缩略布局展示；
- 题库工具窗口截图移至本地 `artifacts/demo-workspace/reference-screenshots/`，不作为公开 README 图片；
- 真实 PDF 阅读、题目区域、组卷、错题反馈和设置页截图等待本地工作区补充；
- 如果最终不使用某张截图，删除对应文件即可，不影响应用代码。
