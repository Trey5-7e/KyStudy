# KyStudy v0.1.3 发布说明

## 已实现

- 练习卷入口提供 A4 纵向 PDF 导出：导出使用当前题目顺序快照，PDF 只写入题型标题、题图和答题空间，不写入试卷标题、姓名、班级、日期、题号文本或页脚；解答题支持 4/8/12 行横线或空白答题空间，默认 8 行横线；其他题型可选择不附加或附加 4 行答题区。
- PDF 生成后先在应用内预览，支持翻页、页码跳转和缩放；确认后才打开系统保存对话框，取消保存会保留预览结果。
- 解答题答题区会记住上次选择的行数和横线/空白模式，下次打开导出设置时自动恢复。
- 练习卷题号总览按作答结果显示颜色：做对为绿色、不全对为黄色、做错为红色；未作答保持中性样式并继续显示文字状态。
- 自动更新下载超时放宽至 10 分钟，降低慢速网络或较大安装包的下载失败概率。
- PDF 使用系统保存对话框写入用户选择的位置，不改动组卷草稿、作答记录或题库数据。
- AI 题目解析和规划回复共用安全 Markdown 渲染，支持标题、加粗、列表、表格、代码块、链接和 KaTeX 行内/块级公式；非法公式回退为原文。
- 题目解析新增 Markdown/纯文本复制和 Provider/模型来源提示；分析来源指纹按 Provider、模型、题目区域和提示词隔离。
- AI 基础设施批次补齐多 Provider 协议、模型列表获取和不保存临时 API Key 的前端入口（详见代码与迁移记录）。

## 已知边界

- 试卷预览缩略图、Logo/水印、自定义纸张和批量多版本导出仍属于 P1/P2。
- 多页、跨页答题区、中文低分辨率题图的可复现视觉 fixture 尚未作为发布资产入库；当前自动化覆盖模型、布局、写出和缺图阻断。
- Provider 的完整桌面人工验收记录尚未归档；协议、模型列表、密钥边界和错误映射已有自动化覆盖。
- 正式 GitHub Release 资产仍需按发布工作流复核后上传；自动化门禁不代替资产签名和清单复核。
- 独立 AI 对话因当前稳定性和交互问题暂缓至后续版本（计划 v0.1.4）；v0.1.3 不提供主导航入口、题目上下文带入或对话操作，现有代码保留用于后续重启开发。
