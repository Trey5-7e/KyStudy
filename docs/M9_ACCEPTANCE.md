## 2. 人工综合 Smoke

开始前请准备一份已经完成 M7 文字索引、且你知道某个关键词所在页码的文字型 PDF。M9 不支持扫描图片 OCR；如果搜索不到正文，请先到“资料”中建立或重新建立文字索引。

### A. 升级与既有数据

1. 关闭旧窗口，启动本次统一 `kystudy.exe`，确认运行状态显示 `Schema v12`。
2. 确认 M8.1 的菜单、Provider、预算，以及既有日程、资料、导图、题目、错题和计划数据仍存在。
3. 进入“规划”，确认上半部分新增“选择资料，再与 AI 完善规划”，下半部分原有手动计划编辑器仍可使用。

### B. 对话与资料选择

4. 保持“离线测试 Provider”为当前 Provider；在规划页输入标题并点击“新建规划对话”。
5. 使用已知关键词搜索本地资料，确认只列出带 PDF 页码的正文结果，不显示只有标题匹配的结果。
6. 勾选一个结果，确认“本轮已选”变为 `1 / 6`；继续选择不同页，确认每页只出现一次。
7. 选择到 6 页后，确认其他未选项不可继续勾选；移除一页后可以改选其他页。
8. 点击某个已选页的移除按钮，确认只移除该页，不删除 PDF 或本地索引。

### C. 外发预览与一致性

9. 输入一个规划问题并生成预览，确认显示目标 Provider、完整组合文本和最坏 Token 数值。
10. 检查完整文本：应包含安全说明、本轮问题、你明确选择的有限资料片段及 `[资料1]` 等标签；不应包含整份 PDF、文件路径、SQL、索引 ID 或请求指纹。
11. 不勾选“我已核对”时发送按钮不可用；勾选后才可发送。
12. 生成预览后修改问题或输出 Token 上限，确认旧预览立即消失。
13. 重新生成预览后增删资料页，确认旧预览立即消失，必须重新核对。
14. 生成预览后切换到另一段对话，再切回原对话，确认旧预览已经清除，必须重新预览。

### D. 离线多轮对话与来源

15. 在预算允许时确认并运行离线测试，确认出现一条用户消息和一条“AI 建议”，页面明确提示尚未写入个人计划。
16. 如果本轮选择了资料，确认 AI 消息下方显示来源按钮；点击按钮应切换到“资料”并打开对应 PDF 页。
17. 回到“规划”和原对话，再提出第二个问题并生成预览，确认预览包含有限的“最近对话”，而不是无限重复全部历史。
18. 执行第二轮后关闭并重新启动应用，确认对话标题、消息和来源仍可恢复。
19. 新建另一段对话，确认两段对话可以独立切换，问题和消息不会混在一起。

### E. 人工保存为计划草案

20. 在有 AI 回复的对话中填写草案标题，点击“把最后一条 AI 回复保存为计划草案”。
21. 确认下方手动计划列表出现新计划，状态为“草案”，总体思路等于所选 AI 回复。
22. 确认该草案自动带有当轮资料页码引用，引用可以回到原 PDF 页。
23. 确认保存草案没有自动改变当前活动计划，没有创建阶段、任务或日程，也没有修改原对话。
24. 手动编辑草案内容并保存，确认仍由你决定是否点击“确认为当前计划”。

### F. Token、预算与缓存

25. 把单次硬预算调低，再生成包含多个资料页的预览，确认预算超限时不能发送；减少资料或输出上限后可重新预览。
26. 在一段空对话中使用不带资料的固定问题执行一次；再新建另一段空对话，使用完全相同的问题和输出上限，确认第二次可命中本地缓存且不新增 Token。
27. 展开 AI 设置中的调用历史，确认规划调用只显示 Provider、模型、状态和 Token，不显示对话问题、资料原文、路径或内部 ID。

### G. 备份与隐私

28. 创建完整备份并恢复到新目录，确认恢复副本为 schema v12，规划对话、消息、来源引用和 AI 计划草案存在。
29. 确认恢复不需要把 PDF 原文重新发送给 AI，API Key 也没有进入备份。
30. 删除或清理本地搜索索引后，既有对话文字和已保存计划草案仍可阅读；新的资料选择需要重新建立索引。

### H. 可选真实 Provider Smoke

31. 只有在愿意消耗少量 Token 时执行：选择 Responses API Provider、1～2 个不含隐私的资料页和较小输出上限，核对完整预览后确认。
32. 确认真实回复能够使用 `[资料N]` 标签；无论模型是否正确引用，界面下方的本地来源按钮都应准确回到用户实际选择的页码。
33. 删除测试 Key 或测试 Provider。不要在截图、反馈或提交中展示 API Key、完整资料原文或 Provider 原始错误。

## 3. 通过标准

A～G 的 1～30 全部符合即可回复：`M9 全部通过`。H 为可选项，不影响通过；如果失败，请提供步骤编号、界面稳定提示和不含隐私的截图。

## 4. 本批次明确不验收

- OCR、图片上下文、扫描版 PDF 识别或视觉模型；
- 自动生成结构化阶段、自动创建任务或直接改写日程；
- 长对话自动摘要、对话删除/归档、分支或版本差异比较；
- 题目识别、错因分析、导图自动修改或向量检索；
- Provider 自动路由、工具调用、流式输出或后台批处理。
