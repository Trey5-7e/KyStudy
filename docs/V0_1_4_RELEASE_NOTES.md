# KyStudy v0.1.4 发布说明

## 已实现

- **独立 AI 学习助手工作区（`ai-chat`）**：接入主导航，支持新建、切换、重命名、删除和恢复通用会话；通用对话直接发送，规划对话保留紧凑预览与确认；输入支持 Enter 发送、Shift+Enter 换行，Markdown/LaTeX/代码块/表格渲染与复制，失败重试和协作式取消。
- **原生 SSE 流式传输与思考链隔离**：实现原生 Server-Sent Events 流式对话响应，字符实时打字机渲染；深度适配 DeepSeek / OpenAI 等模型的思考链（Reasoning / CoT）标记，确保最终正文回答纯净、精准。
- **全面移除 Token 上限约束**：彻底移除所有人为 Token 截断限制与微调输入框，交由 AI 模型自身上下文与自然 EOS 结束符输出，长篇公式、定理证明与详尽题解不再被意外截断。
- **剪贴板图片粘贴与多模态图文发送**：支持直接在输入框内按 `Ctrl + V` 粘贴截图、拖拽添加或点击工具栏选择图片，输入框内提供现代感圆角缩略预览条与一键移除；图片连同提示词一同打包为标准多模态格式发送，对话历史优雅渲染图片缩略图并持久化保存。
- **模型与 API 管理中心（`ai-settings`）**：独立工作区展示 Provider 卡片、连接测试、多模型列表、工作区默认模型和资料能力校准（图片/文件/PDF）；支持主流供应商预设与自动填充（智谱 GLM、Kimi、MiniMax、百度千帆、豆包、SiliconFlow、DeepSeek 等），API Key 始终由 Rust 凭据层隔离管理，不进入 WebView、日志或普通数据库字段。
- **对话资料绑定与本地索引传输**：`＋` 菜单提供从软件本地资料库选择和上传电脑资料，展示资料就绪/处理/过期状态；Provider 具备原生文件能力时走受控 Base64 传输，不支持时稳定降级为本地 PDF 文本索引并携带页数与阻断诊断，未索引资料或无权限时不外发未受控内容。
- **电脑本地 PDF 智能阅读与纯净图文解析**：支持在对话中直接上传电脑本地 PDF 文件。文字版 PDF 采用自适应二维坐标与版面重构引擎提取纯净 Markdown；扫描件/纯图片版 PDF 自动通过离线 Canvas 提取高清视觉图元并走底层多模态通道直传大模型。
- **对话流与 SQLite 数据库零膨胀**：彻底解耦多模态视觉图元与对话文本历史，消除单条消息塞入巨大 Base64 引起的 SQLite 数据过载和数据库锁异常，确保对话与存储轻量、稳定、高速。
- **做题本 PDF 结构化识别与诊断基线**：针对做题本版式建立独立 Profile（李永乐 660 高数篇 / 660 线概篇、李艳芳 900 题数一高数 / 线代概率、张宇 1000 题数一高数篇 / 线概篇，共六册），支持无标点题号识别、子章节与测试卷上下文、篇章/题型分类映射与稀疏页面按需本地 OCR 回退；导入确认界面提供诊断指标卡片和标准化 JSON 基线导出。
- **做题本解析健壮性**：题号 `0` 与换行碎片幻影过滤、同上下文题号递增序列校验、题号风格逐页持久化与按书优先级配置（`plainBeforeParenthesized`）、短中文题干起始词不再被误判为重复水印；分段回收站新增“彻底删除”与“一键清空”，便于安全重建错误导入的数据。
- **低干扰 Token 预算**：默认模式调整为“仅警告”，保留用量统计、预估和手动硬阻止选项，历史默认未自定义预算自动平滑迁移（v29/v30 迁移）。
- **协作式取消与临时文件清理**：请求携带 `operationId`，取消后丢弃结果并恢复输入状态；临时附件流式哈希、受控目录落盘、删除清理与应用重启自动标记过期。

## 已知边界

- 原生文件传输仅对校准支持的 OpenAI Responses 等兼容协议生效，单文件上限 24 MiB；其他协议统一降级为本地文本索引或在本地预览阶段解释性阻断。
- SenseNova 直连协议暂作为内部 Spike 保留，1.4 统一使用成熟的 OpenAI 兼容网关与标准化协议。
- 做题本 PDF 适配仅针对做题本 PDF，不直接支持整本教材、答案解析合订本或无题号排版。
- 自动化门禁不代替用户的真实 Windows 桌面 EXE 人工验收。
