# M12：规划阶段展开到日程实施计划

| 项目    | 内容                                                   |
| ------- | ------------------------------------------------------ |
| 状态    | implemented，等待人工验收                              |
| Schema  | v14                                                    |
| 目标    | 把当前计划的阶段按明确规则、安全地展开为正式日程任务   |
| AI 消耗 | 无；预览、冲突判断和确认写入完全在本地执行             |

## 1. 本批次交付

1. 在“个人规划”中增加“展开到日程”，不新增主菜单层级；
2. 只有状态为 `active` 的当前计划可以生成任务，草稿和已归档计划只显示稳定说明；
3. 用户选择阶段、科目、阶段内日期范围、执行星期、标题、说明、预计分钟和优先级；
4. 后端按周一为 `0`、周日为 `6` 计算精确日期并返回预览；
5. 预览逐日显示“待创建”或“已存在”，用户明确点击“确认写入日程”后才创建任务；
6. 确认操作在一个 SQLite 事务中创建任务、`created` 变化历史和阶段来源关系；
7. 成功后可直接进入日程页查看结果，并刷新预览为“已存在”；
8. 所有 Command 只返回受限 DTO，不暴露 SQL、来源表内部字段、文件路径或内部错误。

## 2. 规则与边界

| 规则               | 实现边界                                                       |
| ------------------ | -------------------------------------------------------------- |
| 日期范围           | 必须完全位于所选阶段内，单次跨度最多 366 天                    |
| 执行星期           | 至少选择一天，不允许重复值，只接受周一 `0` 至周日 `6`          |
| 批量上限           | 一次预览最多 200 个候选日期                                    |
| 科目               | 可不分类；选择科目时必须是当前工作区中未归档的有效科目         |
| 任务字段           | 继续复用正式日程任务的标题、说明、时长和优先级校验             |
| 当前计划           | 预览和确认时都重新校验，避免预览后计划状态变化造成越权写入     |
| 前端输入           | 前端只提交规则和任务公共字段，不能提交自行构造的任务列表       |

预览不是数据库锁。若预览后数据发生变化，确认时以后端事务内的最新状态为准，并安全跳过已经存在的日期。

## 3. 幂等与历史保留

- 每个 `(stage_id, generated_date)` 最多有一个来源关系；
- 重复点击确认或用同一规则再次展开，只返回已跳过数量，不重复创建任务；
- `generated_date` 是首次生成日期。任务后来延期时只更新任务当前 `planned_date`，来源日期保持不变；
- 取消、恢复或把生成任务放入回收站不会删除来源关系，因此不会意外补回一项新任务；
- 删除阶段时来源记录保留但 `stage_id` 置空，已经确认的任务及其变化历史继续存在；
- 永久删除任务时才级联移除其来源记录。

## 4. 数据与恢复

schema v14 新增 `plan_stage_task`，只保存任务 ID、可空阶段 ID、原始生成日期和创建时间。它不复制计划正文、任务内容或内部快照。

完整备份继续覆盖 SQLite 一致快照，因此会自然包含任务、变化历史和来源关系。历史 v2/v3/v13 工作区或恢复副本在打开时按既有迁移流程升级到 v14。

## 5. 测试范围

- 周一基准的星期计算与跨日期生成；
- 阶段外日期、空星期、非法字段和超大批次拒绝；
- 预览保留全部候选日期并正确标记已存在项；
- 确认生成经过领域校验的正式任务；
- SQLite 事务同时写入任务、变化历史和来源关系；
- 重复确认幂等，删除阶段后正式任务保留；
- 非当前计划不能生成任务；
- IPC 请求拒绝前端自带 `tasks` 字段，返回 DTO 不包含来源内部字段。

## 6. 本批次不包含

- AI 自动选择日期、自动调整日程或后台静默写入；
- 根据任务完成情况自动计算阶段完成百分比；
- 每天多次、隔周、自定义节假日等复杂重复规则；
- 修改已生成任务后批量同步标题、科目、时长或优先级；
- M9 AI 对话体验优化；
- 自动切题、图片导图识别、跨设备同步和发布准备。
